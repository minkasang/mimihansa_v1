1. 对应版本号：v2.2.0.1，最后更新 2026-05-17
2. 改动内容：
   - 修复Bug：NPCManager.normalizePersonality() 未从 身体素质.外貌 映射 颜值 到 personality（导致感知系统无法识别高颜值NPC）
   - 修复Bug：NPCManager.normalizePersonality() 未从 欲望.色欲 映射 好色 到 personality（导致搭讪/追求欲望无法触发）
   - 修复Bug：BrainEngine 的 dialogue 输出 text 字段被 main.ts 忽略（对话气泡不显示）
   - 新增 DialogueSystem.addCustomDialogue() —— 直接显示自定义文本气泡
   - 优化：决策间隔从 2000ms 降到 1000ms（NPC反应更快）
3. 根因分析：
   - 齐琳琳 JSON 中"外貌:9"在 身体素质 下，不在 性格 下
   - normalizePersonality(raw.性格) 直接透传34维，不含颜值
   - 感知系统读 this.data.personality.颜值 → undefined → 5
   - 欲望计算器 看到高颜值NPC = 颜值>=7 → 永远false
   - 即使欲望触发，BrainEngine输出 text 字段被 main.ts 忽略，对话气泡不显示
4. 修复后数据流：
   齐琳琳.json 身体素质.外貌=9 → NPCManager补充personality.颜值=9
   → 云飞感知齐琳琳 颜值=9 → 欲望"看到高颜值(>=7)"=true
   → 好色=6>=5 满足 → want_chat_up 触发(0.4概率)
   → GOAP生成搭讪指令 → ModuleRegistry执行say
   → main.ts addCustomDialogue → 对话气泡显示
