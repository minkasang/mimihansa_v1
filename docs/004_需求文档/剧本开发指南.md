# 剧本开发指南

## 概述

本指南说明如何使用"指令模块"（乐高积木）来搭建NPC行为剧本。所有剧本都是数据驱动的，无需修改代码即可创建新的NPC行为。

---

## 核心概念

### 1. 指令模块（积木）

每个指令模块是一个独立的功能单元，通过组合这些模块可以创建复杂的NPC行为。

**模块格式：**
```json
{
  "module": "模块ID",
  "params": {
    "参数名": "参数值"
  }
}
```

### 2. 剧本（蓝图）

剧本是一组状态机，每个状态包含触发条件和指令序列。

**剧本格式：**
```json
{
  "id": "剧本唯一标识",
  "角色": "角色名",
  "行为状态机": {
    "状态名": {
      "id": "状态ID",
      "触发条件": "条件描述",
      "指令序列": [模块1, 模块2, ...]
    }
  }
}
```

---

## 指令模块详解

### 移动类

#### `move_to` - 移动到指定位置
```json
{
  "module": "move_to",
  "params": {
    "target": [45, 75],
    "speed": 1.0
  }
}
```
**参数：**
- `target`: 目标坐标 [x, y]
- `speed`: 速度倍率（可选，默认1.0）

#### `move_in_area` - 在区域内随机移动
```json
{
  "module": "move_in_area",
  "params": {
    "center": [45, 75],
    "radius": 5,
    "min_stay": 2000,
    "max_stay": 5000
  }
}
```
**参数：**
- `center`: 区域中心坐标 [x, y]
- `radius`: 活动半径（格数）
- `min_stay`: 最小停留时间（毫秒）
- `max_stay`: 最大停留时间（毫秒）

**用途：** 让NPC在固定范围内活动，如商人守在店铺周围

---

### 对话类

#### `say` - 直接说话
```json
{
  "module": "say",
  "params": {
    "text": "欢迎光临！",
    "duration": 3000,
    "type": "speak"
  }
}
```
**参数：**
- `text`: 对话内容
- `duration`: 显示时长（毫秒）
- `type`: 对话类型 - `speak`(说话)/`thought`(想法)/`action`(动作)/`emotion`(情绪)

#### `say_from_template` - 从模板库说话
```json
{
  "module": "say_from_template",
  "params": {
    "template_id": "merchant_greeting",
    "duration": 3000
  }
}
```
**参数：**
- `template_id`: 对话模板ID
- `duration`: 显示时长（毫秒）

**用途：** 使用预设的对话模板，支持随机选择和变量替换

---

### 商铺类

#### `open_shop` - 开店
```json
{
  "module": "open_shop",
  "params": {
    "shop_id": "fruit_shop",
    "greeting": true
  }
}
```
**参数：**
- `shop_id`: 商铺ID
- `greeting`: 是否播放欢迎语

#### `close_shop` - 关店
```json
{
  "module": "close_shop",
  "params": {
    "shop_id": "fruit_shop",
    "farewell": true
  }
}
```
**参数：**
- `shop_id`: 商铺ID
- `farewell`: 是否播放告别语

#### `attract_customer` - 招揽顾客
```json
{
  "module": "attract_customer",
  "params": {
    "range": 8,
    "template_id": "merchant_attract"
  }
}
```
**参数：**
- `range`: 招揽范围（格数）
- `template_id`: 招揽用语模板ID

---

### 动画类

#### `play_animation` - 播放动画
```json
{
  "module": "play_animation",
  "params": {
    "animation": "wave",
    "duration": 2000
  }
}
```
**参数：**
- `animation`: 动画名 - `idle`( idle)/`walk`(行走)/`wave`(挥手)/`sit`(坐下)/`sleep`(睡觉)
- `duration`: 持续时间（毫秒），-1表示无限

---

### 控制类

#### `wait` - 等待
```json
{
  "module": "wait",
  "params": {
    "duration": 3000
  }
}
```
**参数：**
- `duration`: 等待时间（毫秒）

#### `look_at` - 看向目标
```json
{
  "module": "look_at",
  "params": {
    "target": "player"
  }
}
```
**参数：**
- `target`: 目标 - 可以是NPC ID或 `player`

## 触发条件语法

触发条件使用自然语言描述，系统会自动解析：

| 条件格式 | 含义 | 示例 |
|---------|------|------|
| `时间 >= HH:MM` | 游戏时间达到 | `时间 >= 08:00` |
| `时间 >= HH:MM 且 未营业` | 时间到达且未开店 | `时间 >= 08:00 且 未营业` |
| `营业中` | 店铺正在营业 | `营业中` |
| `附近无顾客` | 周围没有NPC | `附近无顾客` |
| `顾客进入范围` | 有NPC进入范围 | `顾客进入范围` |
| `概率X.X` | 概率触发 | `概率0.3` |

**组合条件：**
- `且` - 同时满足
- `或` - 满足其一

## 完整示例：商人剧本

```json
{
  "id": "huqian_daily",
  "角色": "胡倩",
  "商铺": "clothes_shop",
  "商铺位置": [47, 18],
  "活动范围": {
    "中心": [47, 18],
    "半径": 5
  },
  "行为状态机": {
    "开店准备": {
      "id": "open",
      "触发条件": "时间 >= 08:00 且 未营业",
      "指令序列": [
        { "module": "move_to", "params": { "target": [47, 18] } },
        { "module": "open_shop", "params": { "shop_id": "clothes_shop", "greeting": true } },
        { "module": "say_from_template", "params": { "template_id": "shop_open", "duration": 3000 } }
      ]
    },
    "营业中_招揽": {
      "id": "attract",
      "触发条件": "营业中 且 附近无顾客",
      "指令序列": [
        { "module": "move_in_area", "params": { "center": [47, 18], "radius": 3, "min_stay": 2000, "max_stay": 4000 } },
        { "module": "attract_customer", "params": { "range": 8, "template_id": "clothes_attract" } },
        { "module": "play_animation", "params": { "animation": "wave", "duration": 1500 } }
      ]
    },
    "关店": {
      "id": "close",
      "触发条件": "时间 >= 20:00",
      "指令序列": [
        { "module": "say_from_template", "params": { "template_id": "shop_close", "duration": 3000 } },
        { "module": "close_shop", "params": { "shop_id": "clothes_shop", "farewell": true } }
      ]
    }
  }
}
```

## 开发流程

### 1. 创建对话模板（可选）

如果NPC需要特殊对话，先在 `对话模板库.json` 中添加：

```json
{
  "templates": {
    "my_custom_dialogue": {
      "id": "my_custom_dialogue",
      "类别": "自定义",
      "适用角色": ["角色名"],
      "对话列表": [
        "第一句话",
        "第二句话",
        "第三句话"
      ]
    }
  }
}
```

### 2. 创建剧本文件

在 `data/libraries/` 下创建新的JSON文件，如 `角色剧本_我的角色.json`

### 3. 加载剧本

在 `main.ts` 的 `loadScripts()` 方法中添加：

```typescript
const myScript: RoleScript = {
  id: "my_script",
  角色: "我的角色",
  // ... 剧本内容
};
this.scriptEngine.loadRoleScript(myScript);
```

### 4. 初始化NPC

在 `NPC_DEFINITIONS` 中添加NPC数据：

```typescript
{
  id: "my_npc",
  name: "我的NPC",
  x: 50, y: 50,
  color: "#FF0000",
  personality: { 乐观: 5, 社交欲: 5 },
  state: { 饥饿: 5, 疲劳: 3 },
  perceptionRange: 8,
  controllable: false,
  roleType: "merchant",  // 或 "villager", "farmer"
  shopId: "my_shop",
  activityCenter: [50, 50],
  activityRadius: 5,
  speedMultiplier: 0.5,  // 商人移动较慢
}
```

## 最佳实践

### 1. 速度设置
- **商人**: `speedMultiplier: 0.3-0.5`（守在店铺，移动慢）
- **村民**: `speedMultiplier: 0.8-1.0`（正常速度）
- **玩家**: `speedMultiplier: 1.0-1.2`（稍快）

### 2. 活动范围
- **商人**: 半径 3-5 格（店铺周围）
- **农民**: 半径 8-12 格（农田区域）
- **村民**: 半径 15-20 格（整个村庄）

### 3. 剧本设计原则
1. **状态要完整**: 每个剧本至少包含"开始工作"、"工作中"、"结束工作"三个状态
2. **条件要互斥**: 不同状态的触发条件不能同时满足
3. **循环要合理**: 循环状态（如招揽顾客）要有退出条件
4. **对话要丰富**: 每个模板至少准备3-5条对话，避免重复

---

## 调试技巧

1. **查看NPC状态**: 点击NPC，侧边栏会显示当前状态
2. **查看营业状态**: 商人头顶会显示"营业中"或"已关店"
3. **查看对话**: NPC头顶会显示当前对话气泡
4. **控制台日志**: 打开浏览器控制台查看详细日志

## 文件位置

- **指令模块定义**: `data/libraries/指令模块库.json`
- **对话模板**: `data/libraries/对话模板库.json`
- **角色剧本**: `data/libraries/角色剧本_*.json`
- **NPC数据**: `web/map-demo/src/main.ts` 中的 `NPC_DEFINITIONS`
- **剧本加载**: `web/map-demo/src/main.ts` 中的 `loadScripts()`
