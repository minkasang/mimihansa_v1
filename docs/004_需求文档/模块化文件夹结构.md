## 核心设计原则

### 1. NPC数据独立
每个NPC有自己的文件夹，包含：
- `个人信息.json` - 静态属性（性格、身体素质等）
- `朋友.json` - 动态关系（好感度等）
- `记忆/` - 历史记录（按类型和时间分文件）

### 2. 库文件集中管理
所有"剧本"、"动作"、"对话"都放在 `data/libraries/`，便于统一维护：
- 新增动作 → 改 Actions_Library.json
- 新增对话 → 改 Dialogues_Library.json
- 新增决策逻辑 → 改 Brains_Library.json

### 3. 大脑决策库（关键！）
根据NPC性格选择不同的行为模式：
```json
{
  "大脑类型": "乐观追求者",
  "适用性格": {"情绪基调_积极倾向": ">=7"},
  "行为模式": ["主动搭讪", "失败后继续", "送礼挽回"]
}
```

云飞（乐观+好色）→ 使用"乐观追求者"大脑 → 被拒绝后继续送礼
刘坤（普通村民）→ 使用"被动观望者"大脑 → 不会主动搭讪

### 4. 指令模块即插即用
动作由指令模块组合而成：
```json
{
  "动作id": "action_搭讪",
  "执行步骤": [
    {"指令": "cmd_移动到目标", "参数": {}},
    {"指令": "cmd_播放动画", "参数": {}},
    {"指令": "cmd_触发对话", "参数": {}}
  ]
}
```

新增动作 = 组合已有指令，无需改代码。

## 数据流转示例

### 云飞看到齐琳琳

```
1. 引擎感知系统
   ↓ 发现齐琳琳进入视野
   
2. 查询 Brains_Library
   ↓ 云飞性格：积极倾向7（乐观追求者）
   ↓ 匹配大脑类型：乐观追求者
   
3. 大脑决策
   ↓ 查询 Desires_Library
   ↓ 触发欲望：desire_搭讪异性
   ↓ 效用打分：195分（超过当前晒太阳30分）
   ↓ 决策：执行搭讪
   
4. 查询 Actions_Library
   ↓ 获取动作：action_搭讪
   ↓ 执行步骤：cmd_移动 → cmd_动画 → cmd_对话
   
5. 查询 Dialogues_Library
   ↓ 加载模板：dialogue_搭讪开场
   ↓ 根据云飞性格选择开场白
   
6. 齐琳琳回应
   ↓ 查询齐琳琳的Brains_Library
   ↓ 齐琳琳性格：心气高
   ↓ 决策：拒绝
   
7. 云飞处理拒绝
   ↓ 查询 Brains_Library（乐观追求者）
   ↓ 决策：不放弃，生成任务quest_追求齐琳琳
   ↓ 查询 Quests_Library 执行后续
```

## 增量维护方式

### 新增一个NPC
1. 在 `NPC/` 下新建文件夹
2. 复制模板文件，修改属性
3. 系统自动根据其性格匹配大脑类型

### 新增一种性格类型
1. 在 `Brains_Library.json` 添加新大脑类型
2. 定义适用性格条件
3. 定义行为模式

### 新增一个动作
1. 在 `Actions_Library.json` 添加
2. 使用已有指令模块组合
3. 如需新指令，先在 `Commands_Library.json` 添加

### 新增一段对话
1. 在 `Dialogues_Library.json` 添加模板
2. 定义分支条件和效果

## 关键文件说明

| 文件 | 作用 | 修改频率 |
|------|------|----------|
| NPC/xxx/个人信息.json | 角色属性 | 低（初始化时） |
| NPC/xxx/记忆/ | 历史记录 | 高（运行时） |
| Brains_Library.json | 决策逻辑 | 中（新增性格时） |
| Desires_Library.json | 欲望定义 | 中（新增玩法时） |
| Actions_Library.json | 动作定义 | 高（经常新增） |
| Commands_Library.json | 基础指令 | 低（引擎级） |
| Dialogues_Library.json | 对话模板 | 高（经常新增） |
| Quests_Library.json | 任务链 | 中（新增剧情时） |
