# Demo需求文档 - 地图与规划

> 本文档记录Demo阶段的具体需求，包括NPC数据结构、地图物品、建筑等。
> 所有性格维度采用1-10分制，10分为最高/最强。

## 情绪系统

### 极端情绪

#### 狂怒
- **触发条件**：愤怒值达到 8分以上（可被性格调节，冲动的人阈值更低）
- **数据效果**：攻击欲望提升，移动速度提升
- **衰减速度**：每游戏小时衰减 20%

#### 极度悲伤
- **触发条件**：悲伤值达到 8分以上
- **数据效果**：使得所有[工作/娱乐]动作得分强制上限为 0.2（什么都不想干）
- **恢复速度**：每游戏小时恢复 5%

#### 狂喜
- **触发条件**：开心值达到 9分以上
- **数据效果**：[大方]性格维度临时 +5，社交得分 × 2.0
- **衰减速度**：每游戏小时衰减 20%

## 任务与想做的事的优先级规则

```
决策优先级：
1. 极端情绪（如狂怒、极度悲伤）- 强制覆盖所有行为
2. 生理需求紧急（饥饿>8、疲劳>8等）- 生存优先
3. 任务（优先级1-N）
4. 想做的事（优先级1-N，受好奇心影响）
```

### 好奇心对行为的影响

| 好奇心分值 | 行为倾向 |
|------------|----------|
| 高（7-10） | 容易放弃任务去探索新事物，想做的事优先级提升 |
| 中（4-6） | 正常执行，偶尔被有趣事物分心 |
| 低（1-3） | 严格按计划执行，不易分心 |

### 示例

NPC林晓（好奇心6，中等）：
- 任务：买苹果（优先级1）→ 先执行
- 想做的事：看麦田（优先级1）→ 任务完成后，如果路过麦田可能会去看看

NPC小明（好奇心9，很高）：
- 任务：买苹果（优先级1）
- 想做的事：看麦田（优先级1）→ 如果麦田方向有趣，可能先去麦田

## 记忆系统

### 记忆库标签

| 标签 | 说明 | 效果 |
|------|------|------|
| 标签_攻击过我 | 权重 -50 | 相遇时触发逃跑或警戒动作 |
| 标签_偷过我东西 | 权重 -30 | 记仇属性高的人触发报复欲望 |
| 标签_救过我的命 | 权重 +100 | 永久提升忠诚度 |
| 标签_愉快聊天 | 权重 +5 | 2天后衰减 |
| 标签_目击犯罪 | 权重 -100 | 当看到高道德的人犯罪时触发，导致关系彻底破裂 |

### 记忆文件命名规则

```
记忆/
├── 双人对话/
│   └── [年]_[月]_[日]_[时]_[分]_[秒]_[自己ID]_[对方ID].json
│       示例：2026_06_01_10_30_20_npc01_npc02.json
└── 多人对话/
    └── [年]_[月]_[日]_[时]_[分]_[秒]_多人.json
        示例：2026_06_01_10_30_20_多人.json
```

### 记忆内容格式

```json
{
  "时间": "2026-06-01 10:30:20",
  "类型": "双人对话",
  "参与者": ["npc_01", "npc_02"],
  "内容": "npc_02对npc_01说：今天天气真好",
  "情绪": "开心",
  "重要度": 30,

}
```

#### 苹果

| 水肥条件 | 生长速度 |
|----------|----------|
| 两者都 ≥60% | 1.5/天 |
| 两者都 ≥30% 且至少一个 <60% | 1/天 |
| 至少一个 <30% | 0.5/天 |

| 水肥条件 | 生长速度 |

| 两者都 ≥60% | 2/天 |
