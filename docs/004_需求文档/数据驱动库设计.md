## 1. 欲望与动机库

**文件**: `data/libraries/Desires_Library.json`

**功能**: 定义"什么样的人、在什么条件下、想干什么"。这是NPC大脑生成目标的库。

### 字段格式

```json
{
  "版本": "1.0",
  "欲望列表": [
    {
      "欲望id": "desire_搭讪异性",
      "欲望名称": "搭讪异性",
      "描述": "当感知到高颜值异性时，产生搭讪欲望",
      
      "触发条件": {
        "感知条件": {
          "目标类型": "NPC",
          "目标属性": {"外貌": ">=7"},
          "距离": "<=10"
        },
        "自身条件": {
          "性格维度": {"情绪基调_积极倾向": ">=5"},
          "生理状态": {"精力": ">=3"}
        },
        "环境条件": {
          "时间": "白天",
          "天气": "非暴雨"
        }
      },
      
      "效用打分": {
        "基础分": 50,
        "性格加成": {
          "情绪基调_积极倾向": {"系数": 5, "说明": "越乐观分越高"},
          "欲望_色欲": {"系数": 8, "说明": "越好色分越高"}
        },
        "目标加成": {
          "目标外貌": {"系数": 10, "说明": "目标越漂亮分越高"}
        }
      },
      
      "生成目标": {
        "目标动作": "action_搭讪",
        "目标参数": {
          "目标": "感知到的异性"
        }
      },
      
      "互斥欲望": ["desire_睡觉", "desire_吃饭"],
      "优先级": 80
    }
  ]
}
```

### 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| 欲望id | 字符串 | 唯一标识符，格式：desire_xxx |
| 欲望名称 | 字符串 | 人类可读的名称 |
| 描述 | 字符串 | 详细说明 |
| 触发条件 | 对象 | 包含感知/自身/环境三个维度的条件 |
| 效用打分 | 对象 | 定义如何计算该欲望的优先级得分 |
| 生成目标 | 对象 | 欲望触发后生成的具体动作目标 |
| 互斥欲望 | 数组 | 不能同时存在的欲望id列表 |
| 优先级 | 数字 | 基础优先级（1-100） |

## 2. 动作与规则执行库

**文件**: `data/libraries/Actions_Library.json`

**功能**: 定义"动作的具体步骤和对世界产生的影响"。系统通过组合指令模块来执行动作。

          "参数": {"距离": "1"}
        },
        {
          "步骤id": "step_2",
          "指令": "cmd_播放动画",
          "参数": {"动画": "挥手", "时长": 1000}
        },
        {
          "步骤id": "step_3",
          "指令": "cmd_触发对话",
          "参数": {
            "对话模板": "dialogue_搭讪开场",

## 增量维护指南

### 如何新增一个欲望

1. 在 `Desires_Library.json` 中添加新条目
2. 定义触发条件（感知/自身/环境）
3. 定义效用打分规则
4. 指定生成的目标动作

### 如何新增一个动作

1. 在 `Actions_Library.json` 中添加新条目
2. 定义前置条件
3. 使用指令模块组合执行步骤
4. 定义效果结算

### 如何新增指令模块

1. 在 `Commands_Library.json` 中添加新指令
2. 定义参数列表
3. 在引擎中实现对应的执行代码

### 如何新增对话模板

1. 在 `Dialogues_Library.json` 中添加新模板
2. 定义适用场景和条件
3. 编写多分支对话流程
4. 定义每个分支的效果
