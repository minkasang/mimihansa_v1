# 名词术语表

> 本文档定义项目中所有核心概念，确保所有开发人员（包括AI Agent）对概念理解一致。
> ⚠️ **此文件需要实时更新，新增术语时必须同步添加**

---

## 时间系统

| 术语 | 定义 | 备注 |
|------|------|------|
| **Tick** | 游戏逻辑的最小时间单位，1 Tick = 游戏内 1 秒 | 可配置修改 |
| **现实时间** | 真实世界的时间，用于存档、日志记录等 | 格式：2026-05-11 22:30:00 |
| **游戏时间** | 游戏内的虚拟时间，由 Tick 累积推进 | 包含：年、月、日、时、分、秒 |
| **昼夜循环** | 游戏内24小时制的日夜变化 | 影响NPC行为（白天活动、晚上睡觉） |

## 世界系统

| 术语 | 定义 | 备注 |
|------|------|------|
| **世界** | 整个游戏空间的统称 | |
| **网格/格子** | 世界的基本组成单元，每个格子有独立属性 | 坐标表示：[x, y] |
| **地形** | 格子的基础属性，如：草地、泥土、石头、水面 | |
| **建筑** | 占据一个或多个格子的固定设施 | 如：房子、农田、商店、床铺、政府机构 |
| **区域** | 多个格子组成的逻辑区域 | 如：村庄、农田区、商业区 |

## 角色系统

| 术语 | 定义 | 备注 |
|------|------|------|
| **NPC** | 非玩家角色，由AI驱动的智能体 | |
| **玩家** | 游戏的观察者/操控者 | 本项目中玩家主要是观察者 |
| **角色属性** | 角色的数值化特征 | 如：生命值、攻击力、速度 |
| **动态需求** | 随时间变化的角色需求 | 如：饥饿度、疲劳度、社交值 |
| **好感度** | 角色对其他角色的情感倾向 | 范围：-100 ~ +100 |
| **记忆库** | 角色存储历史事件的列表 | 用于决策和对话生成 |

## 物品系统

| 术语 | 定义 | 备注 |
|------|------|------|
| **物品** | 游戏中可交互的对象 | 如：苹果、锄头、金币 |
| **标签** | 物品的属性标记，用于 GOAP 条件匹配 | 如：[可食用]、[工具]、[武器] |
| **背包** | 角色持有的物品集合 | |
| **持有者** | 物品当前所属的角色或容器 | 值为"无"表示物品在地图上 |

## AI系统

| 术语 | 定义 | 备注 |
|------|------|------|
| **GOAP 引擎** | 基于得分计算的行为决策系统 | 核心驱动机制 |
| **痛点** | 角色当前最紧迫的需求 | 如：饥饿度 > 80 |
| **动作打分** | 对可选动作进行效用评估的过程 | 得分最高的动作被执行 |
| **性格权重** | 性格维度对动作得分的修正系数 | |
| **欲望库** | 定义角色"想做什么"的JSON数据 | `Desires_Library.json`，19条欲望 |
| **动作库** | 定义角色"怎么做"的JSON数据 | `Actions_Library.json`，14个动作 |
| **ScoreCalculator** | 34维性格效用分计算器 | 加载 `Brains_Library.json` |
| **ActionLibrary** | 动作定义库，提供指令序列 | 按目标类型匹配候选动作 |
| **WorldDynamics** | 世界动力学引擎 | 性格变化+好感度+知识传递 |
| **PathFinder** | A*寻路引擎 | 替代直线移动 |
| **GOAP规划** | 目标导向动作规划 | 把目标拆解为指令序列 |
| **弹性性格** | 性格随经历微变+每天回弹 | WorldDynamics实现 |
| **好感度** | 角色对其他角色的情感倾向 | 范围：-100~+100，存储在已知人物字段 |
| **知识图谱** | NPC间传递已知地点信息 | 社交时随机分享一条 |
| **LLM接管** | 大语言模型接管角色决策的模式 | 仅在特定场景触发 |

## 角色精灵与动画

| 术语 | 定义 | 备注 |
|------|------|------|
| **精灵 (Sprite)** | 角色的像素图像，由多个像素点组成 | 当前为 32×64 像素 |
| **精灵表 (Sprite Sheet)** | 包含所有动画帧的单张大图片 | AI 生成 936×1664，游戏内 128×384 |
| **动画帧** | 动画中的单张静态图像 | 站立 4 帧（含呼吸），走路 4 帧 |
| **朝向** | 角色面对的方向 | 4 方向：上、下、左、右；侧面 60度斜视角 |
| **外观** | 角色的视觉特征组合 | 包括发型、肤色、衣服颜色等 |
| **锚点** | 精灵的定位参考点 | 精灵底部中心对齐格子中心 |
| **帧时长** | 每帧动画显示的时间 | 毫秒为单位 |
| **呼吸动画** | 站立时的身体轻微起伏 | 模拟活人感 |
| **斜视角** | 非90度的侧面角度 | 60度角能看到部分正脸 |
| **NPC AI** | 非玩家控制角色的 AI 系统 | 随机巡逻、平滑移动 |
| **巡逻范围** | NPC 可移动的区域 | [[minX, minY], [maxX, maxY]] |
| **平滑移动** | 格子间插值移动 | 0.05 格/帧，约 1 秒走一格 |
