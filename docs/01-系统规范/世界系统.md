## 网格系统

世界由**网格**组成，每个格子有独立属性。

### 格子属性

```json
{
  "坐标": [10, 20],
  "地形": "草地",
  "可通行": true,
  "建筑id": null,
  "物品列表": ["item_01", "item_02"]
}
```

### 地形类型（示例）

| 地形 | 可通行 | 说明 |
|------|--------|------|
| 草地 | 是 | 基础地形 |
| 泥土 | 是 | 农田基础 |
| 道路 | 是 | 行走速度提升 |
| 石头 | 否 | 障碍物 |
| 水面 | 否 | 需要桥梁 |
| 建筑 | 否 | 固定设施 |
| 围墙 | 否 | 边界阻挡 |

## 道路系统

道路是特殊地形，支持直线和曲线两种类型。

### 道路数据结构

```json
{
  "道路id": "road_01",
  "类型": "curve",
  "起点": [10, 30],
  "终点": [90, 30],
  "宽度": 3,
  "控制点": [[50, 28]]
}
```

### 道路类型

| 类型 | 说明 | 控制点数量 |
|------|------|-----------|
| horizontal | 水平直线 | 0 |
| vertical | 垂直直线 | 0 |
| path | 斜向路径 | 0 |
| curve | 贝塞尔曲线 | 1-2个 |

### 曲线道路说明

- **二次贝塞尔曲线**：1个控制点，生成平滑弧线
- **三次贝塞尔曲线**：2个控制点，生成S形曲线
- 控制点决定道路弯曲程度和方向
- 道路宽度以格子为单位（1-3格）

### 当前地图道路布局（幸福镇）

| 道路名称 | 类型 | 起点 | 终点 | 宽度 | 控制点 |
|---------|------|------|------|------|--------|
| 东西主街 | curve | [10, 30] | [90, 30] | 3 | [[50, 28]] |
| 南北主街 | curve | [50, 10] | [50, 90] | 3 | [[48, 50]] |
| 北侧商业街 | curve | [25, 15] | [75, 15] | 2 | [[50, 14]] |
| 南侧住宅街 | curve | [25, 60] | [75, 60] | 2 | [[50, 61]] |
| 东侧小路 | curve | [75, 25] | [75, 55] | 2 | [[76, 40]] |
| 西侧小路 | curve | [25, 25] | [25, 55] | 2 | [[24, 40]] |
| 连接小路×6 | curve | 各交叉口 | 各交叉口 | 1 | [] |

## 地图演示程序（浏览器）

> **源代码不得放在 `docs/` 下**；本节目录与运行方式见下表，实现须与《UI设计规范》16px 格子及本文件地形表一致。规范变更时，须同步更新 `web/map-demo/` 内对应常量与渲染语义。

### 目录与运行

| 项 | 说明 |
|----|------|
| 代码根路径 | 项目根目录下 `web/map-demo/`（Vite + TypeScript + Canvas） |
| 地图尺寸 | **100×100** 格（宽 100、高 100） |
| 单格像素 | **32×32** 屏幕像素（渲染时），与 [UI设计规范.md](../03-UI与工具/UI设计规范.md) 一致 |
| 本地运行（有 Node） | 安装 [Node.js LTS](https://nodejs.org/)（安装时勾选 **Add to PATH**，装完重开终端）后执行：`cd web/map-demo` → `npm install` → `npm run dev` |
| 本地运行（无 Node） | 用 Chrome / Edge **直接打开** `web/map-demo/standalone.html`：当前为**纯地形**漫游（与程序化地形语义同步）。**含 NPC、WASD、读取根目录 `NPC/`** 须使用下方 Vite 方式。 |
| 职责边界 | 地形 + **玩家角色**（俯视角 32×32 像素，程序生成精灵表）+ **NPC AI 角色**（随机巡逻，平滑移动）+ **WASD 连续格子移动**（演示）；**不实现** Tick、完整背包、效用 AI、存档写入；可走格与「可通行」一致（草地、泥土、道路可走；石头、水面、建筑不可）；**镜头**为**鼠标拖拽平移** + **滚轮缩放**；窗口尺寸变化时自适应 |

### Node 装在非默认路径、或已安装仍提示找不到 npm

常见原因：**只装了 `node.exe` 的目录没进 PATH**，或 **PATH 里排在前面的是别的 `node`（例如编辑器自带的）**，导致 `npm` 对不上。

1. **确认目录**  
   - `npm.cmd` 与 `node.exe` 应在**同一目录**，例如：`E:\ARUANJIAN\node\` 下同时有 `node.exe`、`npm.cmd`。  
   - 要加入 PATH 的是**文件夹路径** `E:\ARUANJIAN\node`，**不要**写成带 `\node.exe` 的文件路径。

2. **写入用户 PATH（推荐）**  
   - Windows：**设置 → 系统 → 关于 → 高级系统设置 → 环境变量**  
   - 在「**用户变量**」里选中 **Path → 编辑 → 新建**，填入：`E:\ARUANJIAN\node`  
   - 若列表里有多条与 Node 相关的路径，把 **`E:\ARUANJIAN\node` 移到最上面**（避免先命中编辑器自带的 `node` 却没有 `npm`）。  
   - **完全退出 Cursor（及所有终端）再打开**，否则旧 PATH 仍会缓存。

3. **验证**（新开 PowerShell）  
   - `where.exe node`：第一行应是 `E:\ARUANJIAN\node\node.exe`  
   - `where.exe npm`：应能列出 `...\npm.cmd`  
   - `node -v`、`npm -v` 有版本号即正常。

4. **不改全局 PATH、临时本窗口有效**（PowerShell 先执行再 `cd`）：  
   `$env:Path = "E:\ARUANJIAN\node;" + $env:Path`

5. **不改 PATH、直接写全路径**（在 `web/map-demo` 目录下执行）：  
   `& "E:\ARUANJIAN\node\npm.cmd" install`  
   `& "E:\ARUANJIAN\node\npm.cmd" run dev`

### 演示代码分层（与《角色系统》NPC 单文件约定对齐）

| 路径（均在 `web/map-demo/` 下） | 职责 |
|--------------------------------|------|
| `src/interaction/gridMovement.ts` | 可走地形判定、`tryStepTile` |
| `src/interaction/continuousWasd.ts` | WASD **长按**连续走格（定时格步）；忽略 `keydown` 的 `repeat`，用自研间隔 |
| `src/interaction/edgeScrollCamera.ts` | 玩家接近屏幕边距时**自动卷镜头**（世界坐标平移） |
| `src/npc/spriteSheetGenerator.ts` | **32×64** 像素精灵表生成工具，支持 AI 生成 936×1664 精灵表自动缩放到游戏尺寸 |
| `src/world/terrainGen.ts` | 与下文 `terrainAt` / 调色板一致的程序化地形 |
| `src/main.ts` | 组装画布、摄像机、滚轮缩放、`resize` 时居中 |
| `vite.config.ts` | `server.fs.allow` 放行仓库根目录，以便 `import` 根下 `NPC/*.json` |

### 地形与实现对齐

- 演示中四种地形与上文「地形类型（示例）」表一致：**草地、泥土、石头、水面**；可走规则与「可通行」列一致：**草地、泥土**可走，**石头、水面**不可走（与 `web/map-demo` 内 `gridMovement` 一致）。
- 演示用地形为**确定性函数** `terrainAt(格子x, 格子y)`（与实现代码同名语义即可），便于截图对比；正式 `世界数据.json` 落地后，渲染应改为读存储或由引擎下发快照（参见《UI模块化与引擎接口规范》`ui.snapshot.world_canvas`）。

### 与主工程关系

- 本演示是**表现层原型**，不替代 Engine/API；日后可抽离为正式 `web/` 客户端的一部分或替换为其他宿主。
