# 时间系统规范

> 本文档定义游戏的时间机制。

---

## 核心配置

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| 1 Tick | 1秒（游戏内） | 可在配置.json中修改 |
| 现实时间格式 | 2026-05-11 22:30:00 | 用于存档、日志 |
| 游戏时间格式 | 年-月-日 时:分:秒 | 由Tick累积 |

---

## 时间系统说明

### 现实时间
- 真实世界的时间
- 用途：存档时间戳、日志记录、调试追踪

### 游戏时间
- 游戏内的虚拟时间
- 由Tick累积推进
- 包含完整的年、月、日、时、分、秒

---

## 昼夜循环

| 时段 | 游戏时间 | 行为影响 |
|------|----------|----------|
| 早晨 | 06:00-09:00 | 起床、早餐、开始工作 |
| 上午 | 09:00-12:00 | 主要活动时间 |
| 中午 | 12:00-14:00 | 午餐、休息 |
| 下午 | 14:00-18:00 | 继续工作 |
| 傍晚 | 18:00-20:00 | 晚餐、社交 |
| 夜晚 | 20:00-06:00 | 睡觉、减少外出 |

### 特殊情况
- 紧急事件（如物品丢失）可能打破昼夜规律
- 角色性格会影响对时间的敏感度

---

## 记忆库时间对应

记忆库中的"时间"字段记录**游戏时间**，格式示例：
```json
{
  "时间": "第1年-春-3日-上午",
  "事件": "被npc_03抢了苹果",
  "情绪": "愤怒"
}
```
