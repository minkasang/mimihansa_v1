## 战斗机制

### 实时战斗

非回合制，类似英雄联盟的实时战斗：

```
每次攻击间隔 = 基础间隔 / 攻击速度
实际伤害 = 攻击力 × (1 - 目标防御减免) × 暴击系数
```

### 伤害计算

```python
def 计算伤害(攻击者, 防御者):
    基础伤害 = 攻击者.攻击力
    
    防御减免 = 防御者.防御力 / (防御者.防御力 + 100)
    实际伤害 = 基础伤害 * (1 - 防御减免)
    
    if random() < 攻击者.暴击率:
        实际伤害 *= 攻击者.暴击伤害
    
    if random() < 防御者.闪避率:
        实际伤害 = 0
    
    return 实际伤害
```

## 战斗流程

```
1. 触发战斗（切磋或生死斗）
2. 双方进入战斗状态
3. 循环执行：
   - 攻击冷却结束的一方发起攻击
   - 计算伤害并扣除生命值
   - 检查是否有一方生命值归零
4. 战斗结束，判定胜负
5. 根据战斗类型处理后果
```

## 战斗触发条件

### 切磋触发
- 双方同意切磋
- 争夺物品时的协商失败
- 友好的比试

### 生死斗触发
- 深仇大恨（好感度 < -80）
- 特殊事件触发
- 一方发起生死斗且对方接受
