## 物品数据结构

```json
{
  "物品id": "item_01",
  "物品名": "烤肉",
  "坐标": [10, 20],
  "持有者": "无",
  "标签": ["可食用", "熟食", "香气"],
  "效果": {
    "饥饿度": -50,
    "生命值": 10
  },
  "价值": 15,
  "耐久": 100,
  "堆叠数": 1
}
```

---

## 标签系统

标签是物品的核心属性，用于效用AI匹配。

### 标签分类

| 类别 | 标签示例 | 用途 |
|------|----------|------|
| 功能 | [可食用]、[可穿戴]、[工具] | 匹配需求 |
| 类型 | [食物]、[武器]、[材料] | 分类管理 |
| 品质 | [普通]、[精良]、[传说] | 价值判断 |
| 状态 | [生食]、[熟食]、[腐烂] | 效果差异 |

---

## 物品效果

物品使用后对角色属性的影响：

```json
{
  "效果": {
    "饥饿度": -50,
    "生命值": 10,
    "疲劳度": -5
  }
}
```

效果值为负表示减少需求，正表示增加属性。

## 物品持有状态

| 持有者值 | 说明 |
|----------|------|
| "无" | 物品在地图上 |
| "npc_01" | 被角色持有 |
| "building_01" | 在建筑内 |
