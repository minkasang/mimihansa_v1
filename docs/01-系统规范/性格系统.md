# 性格系统规范（已废弃）

---

## 实现状态

✅ **已实现**。包括：
- **34维性格从NPC文件加载**：`NPCManager.normalizePersonality()` 读取 `NPC/*/个人信息.json` 的 `性格` 字段（34维）
- **性格驱动动作打分**：`ScoreCalculator` 加载 `Brains_Library.json`，按必要条件/加分项/减分项对每个动作计算效用分
- **弹性性格**：`WorldDynamics` 引擎在动作完成后修改性格值，每天黎明向中性值(5)回弹
- **好感度**：`WorldDynamics.modifyFavor()` 在社交/送礼/搭讪后将变化写入 `已知人物` 字段

---

## 设计原则

1. **可扩展**：支持任意数量的性格维度，程序自动兼容
2. **配置驱动**：所有维度定义在JSON文件中，修改无需改代码
3. **权重映射**：性格维度映射到动作打分的乘数

## 性格→行为映射机制

### 映射表结构

```json
{
  "映射规则": [
    {
      "维度id": "道德水准_利他意愿",
      "动作类型": "偷窃",
      "乘数": -0.5,
      "说明": "利他意愿越高，偷窃得分越低"
    },
    {
      "维度id": "胆魄气量_勇气阈值",
      "动作类型": "攻击",
      "乘数": 0.3,
      "说明": "勇气越高，攻击得分越高"
    }
  ]
}
```

### 计算公式

```
最终得分 = 基础分 × Π(1 + 维度值/100 × 乘数)
```

### 示例

角色A想偷窃物品，基础分80：
- 道德水准_利他意愿 = 80（乘数-0.5）
- 胆魄气量_勇气阈值 = 60（乘数0.2）

```
最终得分 = 80 × (1 + 80/100 × -0.5) × (1 + 60/100 × 0.2)
        = 80 × 0.6 × 1.12
        = 53.76
```

## 弹性性格系统（已实现）

### 事件触发变化

动作完成时触发（定义在 `Brains_Library.json` 的 `性格弹性系统.变化规则`）：

| 事件 | 性格变化 |
|------|---------|
| 被拒绝 | 乐观 -0.03, 社交欲 -0.02 |
| 被接受 | 乐观 +0.02, 社交欲 +0.01 |
| 成功送礼 | 乐观 +0.05, 大方 +0.02 |
| 放弃追求 | 乐观 -0.05, 意志力 -0.03 |
| 完成工作 | 勤奋 +0.02 |
| 长期闲逛 | 勤奋 -0.01 |

### 每日回弹

每天凌晨（游戏日切换时），所有NPC的性格向中性值(5)回弹一步：

```
新值 = 当前值 + (5 - 当前值) × 0.01
```

引擎实现：`WorldDynamics.dailyReversion()`，由 `updateGameTime()` 在 `gameDay` 变化时触发。
