# 性格系统规范

> 本文档定义34维度性格基座系统，是角色行为差异化的核心。

---

## 设计原则

1. **可扩展**：支持任意数量的性格维度，程序自动兼容
2. **配置驱动**：所有维度定义在JSON文件中，修改无需改代码
3. **权重映射**：性格维度映射到动作打分的乘数

---

## 性格维度定义文件

文件位置：`data/personality_base.json`

```json
{
  "版本": "1.0",
  "维度列表": [
    {
      "维度id": "情绪基调_长期心境",
      "维度名": "长期心境",
      "分组": "情绪基调",
      "描述": "角色的基础情绪状态",
      "取值范围": [-100, 100],
      "默认值": 0
    }
  ]
}
```

## 性格→行为映射机制

### 映射表结构

```json
{
  "映射规则": [
    {
      "维度id": "道德水准_利他意愿",
      "动作类型": "偷窃",
      "乘数": -0.5,
      "说明": "利他意愿越高，偷窃得分越低"
    },
    {
      "维度id": "胆魄气量_勇气阈值",
      "动作类型": "攻击",
      "乘数": 0.3,
      "说明": "勇气越高，攻击得分越高"
    }
  ]
}
```

### 计算公式

```
最终得分 = 基础分 × Π(1 + 维度值/100 × 乘数)
```

### 示例

角色A想偷窃物品，基础分80：
- 道德水准_利他意愿 = 80（乘数-0.5）
- 胆魄气量_勇气阈值 = 60（乘数0.2）

```
最终得分 = 80 × (1 + 80/100 × -0.5) × (1 + 60/100 × 0.2)
        = 80 × 0.6 × 1.12
        = 53.76
```

## 性格标签系统

性格标签是性格维度的简化表示，便于快速理解：

```json
{
  "性格标签": ["勤劳", "暴躁", "守财奴"],
  "标签映射": {
    "勤劳": {"行动意愿": 80, "心性勤惰": -60},
    "暴躁": {"情绪稳定性": -50, "情绪基调_当下情绪": 30},
    "守财奴": {"获取欲望": 90, "分享意愿": -80}
  }
}
```
