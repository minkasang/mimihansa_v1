## 核心属性

| 属性 | 说明 | 范围 |
|------|------|------|
| 生命值 | 角色健康状态 | 0-100 |
| 攻击力 | 战斗伤害基础 | - |
| 防御力 | 减少受到的伤害 | - |
| 速度 | 移动速度、攻击速度 | - |

---

## 动态需求

| 需求 | 说明 | 紧急阈值 |
|------|------|----------|
| 饥饿度 | 越高越饿 | > 80 紧急 |
| 社交值 | 越高越需要社交 | > 80 紧急 |
| 疲劳度 | 越高越累 | > 80 紧急 |

需求值随时间自然增长，通过对应行为减少。

---

## 好感度系统

| 范围 | 关系 | 行为倾向 |
|------|------|----------|
| +80 ~ +100 | 密友 | 主动帮助、分享 |
| +30 ~ +80 | 朋友 | 友好互动 |
| -30 ~ +30 | 陌生人 | 中立 |
| -80 ~ -30 | 厌恶 | 回避、拒绝 |
| -100 ~ -80 | 仇敌 | 敌对、报复 |

## 记忆库

存储角色经历的重要事件，用于：
- 决策参考
- 对话生成
- 好感度变化依据

```json
  "时间": "第1年-春-3日-上午",

  "涉及角色": ["npc_03"],
  "情绪": "愤怒",
  "重要度": 80
}
```

## NPC 单文件存储（一人一文件）

> 与「角色数据结构」章节互补：此处约定**磁盘上如何拆文件**；字段仍以 JSON **中文键**为准。

### 存储路径与命名

| 规则 | 说明 |
|------|------|
| 目录 | 仓库根目录 **`NPC/`**（与 `docs/`、`web/` 并列；**不放**在 `docs/` 内） |
| 文件 | **每个 NPC 一个主 JSON 文件**，直接放在 `NPC/` 下；建议文件名与 `角色id` 一致，例如 `npc_demo_01.json` |
| 扩展目录（预留） | 同一 NPC 的**记忆、日志、大块附件**等，日后可放在 `NPC/{角色id}/` 子目录下，与主 JSON 并存；本阶段可不创建空目录 |
| `角色id` | 全游戏**唯一**字符串；须与 JSON 内 `"角色id"` 字段一致，便于引擎按 id 查找 |
| 最小内容 | 地图演示阶段可仅含：`角色id`、`姓名`、`坐标`；其余字段随本规范其它章节逐步补齐 |

### 与地图演示的关系

- `web/map-demo` 通过构建工具 **import** 根目录 `NPC/` 下单个文件作为起点（当前示例：`npc_demo_01.json`）。  
- 日后多 NPC 时：由引擎或构建脚本汇总多文件，再注入 UI 快照；本阶段不要求在演示里遍历全目录。

### 地图演示用可控角色（占位）

- **美工**：当前为 **32×64** 像素**AI 生成精灵表**方案，见 [UI设计规范.md](../03-UI与工具/UI设计规范.md)「可控角色占位精灵」与 [角色精灵与动画规范.md](../03-UI与工具/角色精灵与动画规范.md)。AI 生成 936×1664 像素精灵表（6行×4列），程序自动缩放到 32×64 像素。  
- **操作**：WASD 为**浏览器演示专用**——支持**长按连续走格**（固定时间间隔一格）；正式输入仍以《UI模块化与引擎接口规范》为准。  
- **镜头**：演示为**边缘自动卷屏**（角色靠近屏幕边安全区时移动摄像机）；**不**用鼠标拖拽平移地图；窗口尺寸变化时仍会**一次性居中**到角色便于首屏
- **动画**：支持呼吸动画（站立时身体轻微起伏）和走路动画（4帧循环，手臂和腿部摆动），移动时自动播放，停止时回到空闲状态。
- **朝向**：4方向（上、下、左、右），侧面采用 60度斜视角（非90度纯侧面），能看到部分正脸。

### NPC AI 角色

- **数据文件**：`NPC/npc_villager_01.json` 等，格式与玩家角色相同，但由 AI 控制
- **AI 行为**：随机巡逻，在指定范围内移动
- **移动机制**：平滑移动（0.05 格/帧），约 1 秒走一格
- **决策间隔**：2-5 秒随机决定下一步
- **碰撞检测**：自动避开石头、水面等不可通行地形
- **渲染排序**：根据 Y 坐标自动排序（在玩家前面或后面）
- **详细信息**：见 [角色精灵与动画规范.md](../03-UI与工具/角色精灵与动画规范.md)「NPC AI 行为系统」
