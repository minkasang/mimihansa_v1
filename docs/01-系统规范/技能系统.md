## 技能效果

技能等级影响相关动作：

| 技能 | 影响的动作 | 效果 |
|------|------------|------|
| 种田 | 种植、收获 | 速度+等级×5%，产量+等级×3% |
| 打铁 | 锻造、修理 | 速度+等级×5%，品质+等级×2% |

## 天赋系统

天赋是角色对某技能的先天加成：

| 天赋值 | 说明 |
|--------|------|
| 0.5 | 极差，学习速度减半 |
| 0.8 | 较差 |
| 1.0 | 普通 |
| 1.2 | 有天赋 |
| 1.5 | 天才 |

### 天赋影响
- **经验获取**：实际获得 = 基础经验 × 天赋值
- **动作效果**：最终效果 = 基础效果 × 天赋值

---

## 经验获取

通过执行相关动作获得经验：

```python
def 获取经验(角色, 技能名, 基础经验):
    天赋 = 角色.技能[技能名].天赋加成
    实际经验 = 基础经验 * 天赋
    角色.技能[技能名].经验 += 实际经验
    
    检查升级(角色, 技能名)
```
