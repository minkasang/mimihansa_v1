# 经济系统规范

> 本文档定义货币、交易和定价机制。

---

## 货币系统

### 货币定义

```json
{
  "货币名称": "金币",
  "货币符号": "G",
  "初始发放": 100,
  "政府库存": 10000
}
```

### 货币发行
- 由**政府机构**统一发行
- 初始每个NPC获得基础货币
- 政府可调节货币流通量

## 定价系统

### 基础定价

```json
{
  "物品id": "item_01",
  "物品名": "苹果",
  "基础价格": 5,
  "当前价格": 6,
  "库存": 50
}
```

### 动态定价因素

| 因素 | 影响 | 说明 |
|------|------|------|
| 库存数量 | 库存↓ 价格↑ | 供需关系 |
| 购买频率 | 频率↑ 价格↑ | 热门商品涨价 |
| 季节 | 季节匹配↓ 价格↓ | 当季农产品便宜 |
| 商店老板性格 | 守财奴→价格↑ | 性格影响定价 |

### 定价公式

```
当前价格 = 基础价格 × 供需系数 × 季节系数 × 商店加成
```

## 交易系统

### 交易流程

```
1. NPC A 向 NPC B 发起交易请求
2. 双方确认交易内容（物品+金钱）
3. 检查双方物品和金钱是否足够
4. 执行物品转移和金钱转移
5. 记录交易日志
```

### 交易数据结构

```json
{
  "交易id": "trade_001",
  "买方": "npc_01",
  "卖方": "shop_01",
  "物品": {"物品id": "item_01", "数量": 1},
  "金钱": 6,
  "时间": "第1年-春-3日-上午",
  "状态": "已完成"
}
```

### 显性对话

交易通过显性对话进行：

```json
{
  "对话模板": {
    "发起": "我想买一个{物品名}，多少钱？",
    "报价": "这个{物品名}要{价格}金币。",
    "接受": "好的，成交！",
    "拒绝": "太贵了，我不买。",
    "讨价": "能不能便宜点？",
    "还价": "最低{价格}金币，不能再少了。"
  }
}
```

## 商店系统

### 商店数据结构

```json
{
  "商店id": "shop_01",
  "商店名": "老李杂货铺",
  "店主": "npc_05",
  "库存": {
    "item_01": {"数量": 50, "价格": 6},
    "item_02": {"数量": 30, "价格": 15}
  },
  "金钱": 500,
  "标签": ["商店", "杂货"]
}
```

### 商店类型

| 类型 | 说明 | 商品示例 |
|------|------|----------|
| 杂货店 | 日常用品 | 食物、工具 |
| 武器店 | 武器装备 | 剑、盾 |
| 药店 | 药品 | 草药、药水 |
| 农具店 | 农业用品 | 锄头、种子 |
