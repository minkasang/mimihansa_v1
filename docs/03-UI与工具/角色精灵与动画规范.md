# 角色精灵与动画规范

> 本文档定义角色精灵的视觉风格、动画系统和外观定制规则。
> **参考风格**：星露谷物语（Stardew Valley）

---

## 精灵尺寸

### 基础尺寸

| 属性 | 值 | 说明 |
|------|-----|------|
| **精灵宽度** | 16 像素 | 与地图格子宽度对齐 |
| **精灵高度** | 32 像素 | 占两格高度，有更丰富的细节表现 |
| **锚点** | 底部中心 | (8, 32) 像素位置，用于定位到格子中心 |

### 尺寸对比

```
旧版 16×16：          星露谷风格 16×32：
┌────────┐           ┌────────┐
│ 头发   │           │ 头发   │ ← 4px
│ 头部   │           │ 头部   │ ← 8px（眼睛、表情）
│ 身体   │           │ 身体   │ ← 10px（衣服、手臂）
│ 腿部   │           │ 腿部   │ ← 10px（裤子、鞋子）
└────────┘           └────────┘
  16×16                 16×32
```

## 角色结构分解

### 像素级结构（16×32）

```
行号    内容              像素范围
─────────────────────────────────
0-3     头发/帽子         顶部 4 像素
4-11    头部/脸部         中上 8 像素
12-21   身体/衣服         中部 10 像素
22-31   腿部/鞋子         底部 10 像素
```

### 身体部位像素分布

| 部位 | 行范围 | 高度 | 说明 |
|------|--------|------|------|
| 头发 | 0-3 | 4px | 发型、发色可定制 |
| 头部 | 4-11 | 8px | 脸型、肤色、眼睛 |
| 身体 | 12-21 | 10px | 衣服、手臂、配饰 |
| 腿部 | 22-31 | 10px | 裤子、裙子、鞋子 |

## 朝向系统

### 四方向朝向

| 朝向 | 英文键 | 说明 |
|------|--------|------|
| 下 | `down` | 正面，显示脸部 |
| 上 | `up` | 背面，显示后脑勺 |
| 左 | `left` | 左侧面 |
| 右 | `right` | 右侧面（左侧面镜像） |

### 镜像规则

- **右朝向** = 左朝向水平镜像
- 节省 50% 的精灵资源
- 程序运行时自动翻转

## 动画系统

### 动画类型

| 动作 | 帧数 | 帧时长(ms) | 说明 |
|------|------|------------|------|
| **空闲/站立** | 2 | 400 | 轻微呼吸/晃动 |
| **走路** | 4 | 150 | 循环行走 |
| **跑步** | 4 | 100 | 更快的腿部动作 |
| **蹲下** | 1 | - | 蹲伏状态 |
| **蹲走** | 4 | 200 | 蹲下移动 |
| **跳跃** | 3 | 100 | 起跳-空中-落地 |

### 动画帧命名规则

```
{动作}_{朝向}_{帧号}

示例：
- walk_down_0, walk_down_1, walk_down_2, walk_down_3
- idle_up_0, idle_up_1
- jump_left_0, jump_left_1, jump_left_2
```

### 动画状态机

```
┌─────────┐    移动指令    ┌─────────┐
│  空闲   │ ────────────→ │  走路   │
└─────────┘               └─────────┘
     ↑                         │
     │    停止移动             │ 跑步指令
     └─────────────────────────┘
     
┌─────────┐    跳跃指令    ┌─────────┐
│  任意   │ ────────────→ │  跳跃   │
└─────────┘               └─────────┘
                               │
                               │ 落地
                               ↓
                           返回之前状态
```

## 渲染规则

### 格子定位

角色精灵底部中心对齐到格子中心：

```
格子 (16×16)          角色精灵 (16×32)
┌────────┐           
│        │           ┌────────┐
│        │           │  头发  │
│        │           │  头部  │
│        │    →      │  身体  │
│        │           │  腿部  │
└────────┘           └────────┘
  锚点 ●               锚点在底部中心
```

### 渲染坐标计算

```typescript
// 角色底部中心对齐到格子中心
const spriteX = tileX * TILE_PX + (TILE_PX - SPRITE_WIDTH) / 2;  // 水平居中
const spriteY = tileY * TILE_PX + TILE_PX - SPRITE_HEIGHT;        // 底部对齐格子底部
```

### 遮挡规则

- 角色精灵高度为 2 格，上半部分会遮挡后方格子
- 渲染顺序：先绘制地形 → 按Y坐标排序绘制角色 → 绘制前景建筑

## 动画实现方案

### 方案 A：程序化绘制（当前阶段）

- 使用 Canvas 矩形拼接绘制
- 便于快速迭代和调整
- 支持运行时换色

### 方案 B：精灵表绘制（正式阶段）

- 加载预制的精灵表图片
- 更精细的像素表现
- 支持专业美术资源

### 方案 C：分层绘制（高级阶段）

- 头发、身体、衣服分层绘制
- 支持任意组合外观
- 内存占用较高

在 `NPC/*.json` 中新增外观字段：

```json
{
  "角色id": "npc_01",
  "姓名": "老王",
  "坐标": [10, 20],
  "外观": {

    "肤色": "#f2d3b4",
    "上衣": { "id": "shirt_01", "颜色": "#c45c4a" },
    "下装": { "id": "pants_01", "颜色": "#3d5a80" }
  }
}
```

### 与动画状态同步

角色系统中的 `当前状态` 字段决定播放哪个动画：

| 当前状态 | 对应动画 |
|----------|----------|
| 空闲 | idle |
| 移动 | walk / run |
| 工作 | work（待定义） |
| 休息 | rest（待定义） |
| 战斗 | fight（待定义） |
