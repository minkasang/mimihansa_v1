# 角色精灵与动画规范

> 本文档定义角色精灵的视觉风格、动画系统和外观定制规则。
> **参考风格**：星露谷物语（Stardew Valley）

---

## 精灵尺寸

### 基础尺寸

| 属性 | 值 | 说明 |
|------|-----|------|
| **精灵宽度** | 32 像素 | 与地图格子宽度对齐（格子 32×32） |
| **精灵高度** | 64 像素 | 占两格高度，有更丰富的细节表现 |
| **锚点** | 底部中心 | (16, 64) 像素位置，用于定位到格子中心 |

### AI 生成尺寸

| 属性 | 值 | 说明 |
|------|-----|------|
| **AI 画布尺寸** | 936×1664 像素 | Midjourney/即梦等 AI 工具的限制尺寸 |
| **精灵表布局** | 6行×4列 | 每格 234×277 像素 |
| **游戏内缩放** | 234×277 → 32×64 | 程序自动缩放，保持像素清晰 |

## 角色结构分解

### 像素级结构（32×64）

```
行号     内容              像素范围
──────────────────────────────────
0-7      头发/帽子         顶部 8 像素
8-23     头部/脸部         中上 16 像素
24-43    身体/衣服         中部 20 像素
44-63    腿部/鞋子         底部 20 像素
```

### 身体部位像素分布

| 部位 | 行范围 | 高度 | 说明 |
|------|--------|------|------|
| 头发 | 0-7 | 8px | 发型、发色、刘海、鬓角 |
| 头部 | 8-23 | 16px | 圆脸、五官、眼睛高光 |
| 身体 | 24-43 | 20px | 衣服、手臂、配饰 |
| 腿部 | 44-63 | 20px | 裤子、鞋子、走路动作 |

## 朝向系统

### 四方向朝向

| 朝向 | 英文键 | 说明 | 角度 |
|------|--------|------|------|
| 下 | `down` | 正面，显示完整脸部 | 0° |
| 上 | `up` | 背面，显示后脑勺 | 180° |
| 左 | `left` | 左侧面，能看到部分正脸 | 60°（非90°） |
| 右 | `right` | 右侧面（左侧面镜像） | 60°镜像 |

### 60度斜视角说明

```
90度纯侧面（不好）：     60度斜视角（好）：
    ┌──┐                    ╭──╮
    │  │  完全看不到脸      │  │  能看到左眼+左脸
    └──┘                    ╰──╯
```

**为什么用60度**：
- 能看到角色的表情（眼睛、嘴巴）
- 身体有立体感，不是纸片人
- 走路时手臂摆动更明显

## 动画系统

### 动画类型

| 动作 | 帧数 | 帧时长(ms) | 说明 |
|------|------|------------|------|
| **空闲/站立** | 4 | 400 | 呼吸动画（身体轻微起伏） |
| **走路** | 4 | 120 | 循环行走，手臂和腿部摆动 |
| **跑步** | 4 | 80 | 更快的腿部动作（预留） |
| **蹲下** | 1 | - | 蹲伏状态（预留） |

### 动画帧详细说明

#### 第1行：站立-正面（Y: 0-277）

| 帧 | 姿势 | 说明 |
|----|------|------|
| 1 | 双脚并拢，双手下垂 | 标准站立 |
| 2 | 双脚并拢，身体下沉3px | 呼吸下沉 |
| 3 | 同帧1 | 呼吸上升 |
| 4 | 同帧2 | 呼吸下沉 |

#### 第2行：站立-背面（Y: 278-555）

同第1行姿势，显示背面，长发在脑后。

#### 第3行：站立-左侧面（Y: 556-833）

角度：身体向左转60度，能看到左脸和左眼。

| 帧 | 姿势 | 说明 |
|----|------|------|
| 1 | 左脚在前右脚在后，左手下垂 | 丁字步站立 |
| 2 | 身体下沉3px | 呼吸下沉 |
| 3 | 同帧1 | 呼吸上升 |
| 4 | 同帧2 | 呼吸下沉 |

#### 第4行：走路-正面（Y: 834-1111）

| 帧 | 姿势 | 说明 |
|----|------|------|
| 1 | 左脚前跨（抬起），右脚后，左臂后摆，右臂前摆 | 迈步1 |

#### 第5行：走路-背面（Y: 1112-1389）

同第4行姿势，显示背面，头发随动作摆动。

#### 第6行：走路-左侧面（Y: 1390-1664）

角度：身体向左转60度。

| 帧 | 姿势 | 说明 |
|----|------|------|
| 1 | 左脚大步前跨（抬起），右脚后，左臂后摆，右臂前摆 | 迈步1 |

| 4 | 右脚着地，左脚稍抬，双臂下垂 | 着地 |

## 精灵表处理流程

### 步骤1：AI 生成

使用上述提示词生成 936×1664 像素的精灵表。

### 步骤2：程序处理

```typescript
// 1. 加载 AI 生成的精灵表
const aiSpriteSheet = await loadImage('ai_generated.png');

// 2. 切割成 24 帧
const frames = cutSpriteSheet(aiSpriteSheet, {
  rows: 6,
  cols: 4,
  frameWidth: 234,
  frameHeight: 277
});

// 3. 缩放到游戏尺寸 32×64
const gameFrames = frames.map(frame => 
  resizePixelArt(frame, 32, 64)
);

// 4. 重新拼接成游戏精灵表
const gameSpriteSheet = createSpriteSheet(gameFrames, {
  rows: 6,
  cols: 4,
  frameWidth: 32,
  frameHeight: 64
});
```

### 步骤3：游戏内使用

```typescript
// 根据动画状态和朝向获取对应帧
const animIndex = animState === "idle" ? 0 : 1;
const dirIndex = facing === "down" ? 0 : facing === "up" ? 1 : 2;
const frameIndex = (animIndex * 3 + dirIndex) * 4 + currentFrame;

// 绘制
ctx.drawImage(
  gameSpriteSheet,
  frameX, frameY, 32, 64,
  screenX, screenY, 32, 64
);
```

## 渲染规则

### 格子定位

角色精灵底部中心对齐到格子中心：

```
格子 (32×32)          角色精灵 (32×64)
┌────────────────┐
│                │           ┌────────────────┐
│                │           │     头发       │
│                │           │     头部       │
│                │    →      │     身体       │
│                │           │     腿部       │
│                │           └────────────────┘
└────────────────┘              锚点在底部中心
```

### 渲染坐标计算

```typescript
// 角色底部中心对齐到格子中心
const spriteX = tileX * TILE_PX + (TILE_PX - SPRITE_WIDTH) / 2;  // 水平居中
const spriteY = tileY * TILE_PX + TILE_PX - SPRITE_HEIGHT;        // 底部对齐格子底部
```

### 遮挡规则

- 角色精灵高度为 2 格，上半部分会遮挡后方格子
- 渲染顺序：先绘制地形 → 按Y坐标排序绘制角色 → 绘制前景建筑

## 动画实现方案

### 当前方案：AI 生成 + 程序缩放

- AI 生成高分辨率精灵表（936×1664）
- 程序自动切割和缩放到游戏尺寸（32×64）
- 使用最近邻缩放保持像素清晰
- 支持动态换色（通过调色板映射）

### 备选方案：手绘精灵表

- 美术师直接绘制 32×64 像素精灵表
- 更精细的像素控制
- 文件体积更小

## NPC AI 行为系统

### NPC 类设计

```typescript
class Npc {
  tileX: number;           // 当前格子 X（支持小数，实现平滑移动）
  tileY: number;           // 当前格子 Y（支持小数，实现平滑移动）
  facing: Facing;          // 当前朝向
  animState: AnimationState; // 动画状态
  isMoving: boolean;       // 是否正在移动
  patrolRange: [[number, number], [number, number]] | null; // 巡逻范围
  targetX: number | null;  // 目标格子 X
  targetY: number | null;  // 目标格子 Y
  
  update(now: number, grid: Uint8Array, mapW: number, mapH: number): void {
    // 1. AI 决策：随机巡逻
    // 2. 平滑移动：每帧移动 0.05 格
    // 3. 动画同步：移动时播放 walk，停止时播放 idle
  }
}
```

### 移动机制

| 属性 | 值 | 说明 |
|------|-----|------|
| **移动速度** | 0.05 格/帧 | 约 20 帧走一格（1 秒） |
| **巡逻间隔** | 2-5 秒 | 随机决定下一步 |
| **移动方式** | 格子间平滑插值 | 不是瞬间跳转 |
| **碰撞检测** | 检查地形 | 避开石头、水面 |

### AI 行为流程

```
┌─────────┐    间隔 2-5 秒    ┌─────────┐
│  空闲   │ ────────────────→ │  决策   │
└─────────┘                   └─────────┘
                                     │
                                     │ 随机选择方向
                                     ↓
                              ┌─────────┐
                              │ 检查地形 │
                              │ 是否可通行│
                              └─────────┘
                                     │
                    不可通行         │         可通行
                         ↓           │           ↓
                    ┌─────────┐      │      ┌─────────┐
                    │ 保持空闲 │      │      │ 开始移动 │
                    └─────────┘      │      └─────────┘
                                            │
                                            │ 每帧移动 0.05 格
                                            ↓
                                     ┌─────────┐
                                     │ 到达目标 │
                                     │ 停止移动 │
                                     └─────────┘
```
