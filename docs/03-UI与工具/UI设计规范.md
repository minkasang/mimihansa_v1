> 定义游戏界面的视觉风格、布局原则和交互规范。  
> **引擎数据如何进入界面（模块化接口、快照、扩展位）**见同目录 [UI模块化与引擎接口规范.md](./UI模块化与引擎接口规范.md)。

## 视觉风格

### 像素风格与参考

- **参考气质**：星露谷物语式 — 清晰描边、暖色点缀、控件像木牌/便签叠在画面上；避免商务扁平大渐变。  
- **与架构文档关系**：配色、字号、分区以本文件为准；接口与实时变量订阅以《UI模块化与引擎接口规范》为准。

### 像素风格
- **基础单位**：16x16 像素为一个基础格子单位
- **色彩深度**：限制调色板，参考经典像素游戏
- **分辨率**：可缩放，基础画布 800x600 像素；浏览器全屏时画布随窗口缩小但不超过 800×600 逻辑上限（见 `web/map-demo` 实现）。

## 交互规范

### 鼠标操作
| 操作 | 功能 |
|------|------|
| 左键点击 | 选择/确认 |
| 右键点击 | 取消/返回 |
| 滚轮 | 缩放地图 |
| 拖拽 | 移动视角（**地图演示 `web/map-demo` 例外**：不设拖拽平移，镜头为边缘自动卷屏，见《世界系统》地图演示程序） |

> **地图演示**：主画布上 **WASD 长按**为连续走格；角色靠近屏幕边「安全边距」时自动卷镜头；滚轮仍可缩放。
| 按键 | 功能 |
|------|------|
| 空格 | 暂停/继续 |
| 1-5 | 游戏速度切换 |
| ESC | 关闭面板 |

## 组件规范

### 可控角色占位精灵（地图演示）

- **格内尺寸**：**32×64** 像素，宽度与单格对齐（格子 32×32），高度占两格，便于表现更丰富的角色细节。  
- **风格**：星露式 — 清晰轮廓、少渐变；当前实现为 **AI 生成精灵表 + 程序缩放** 方案。  
- **AI 生成尺寸**：936×1664 像素（6行×4列，每格 234×277 像素），程序自动缩放到 32×64。  
- **与数据关系**：起始格、显示名从 `NPC/{角色id}.json` 读取；外观（发型、肤色、衣服颜色等）从 `外观` 字段读取；精灵表路径从 `精灵表` 字段读取。  
- **动画**：支持呼吸动画（站立时身体起伏）和走路动画（4帧循环，手臂和腿部摆动）。
- **朝向**：4方向（上、下、左、右），侧面采用 60度斜视角（非90度纯侧面），能看到部分正脸。

**详细规范**见 [角色精灵与动画规范.md](./角色精灵与动画规范.md)。

### 按钮
- 最小尺寸：80x32 像素
- 状态：正常、悬停、按下、禁用
- 圆角：4像素

### 文本
- 标题：16px，粗体
- 正文：12px，常规
- 注释：10px，浅色
