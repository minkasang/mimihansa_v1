# 调试工具规范

> 定义开发和测试阶段的调试面板和工具。  
> **面板如何订阅引擎数据、接口 ID 命名与扩展位**见 [UI模块化与引擎接口规范.md](./UI模块化与引擎接口规范.md)（`ui.snapshot.debug_bundle` 等）。

---

## 调试面板

### 1. 世界状态面板
**功能**：实时查看世界运行状态

**显示内容**：
- 当前Tick数
- 游戏时间（年/月/日 时:分:秒）
- 活跃NPC数量
- 活跃事件数量
- FPS/性能数据

### 2. NPC调试面板
**功能**：查看和修改NPC状态

**显示内容**：
- NPC基本信息（ID、姓名、位置）
- 实时需求状态条
- 当前行为/意图
- 性格维度雷达图
- 记忆库摘要

**操作**：
- 选中任意NPC查看详情
- 手动修改属性值（调试用）
- 强制触发特定行为

### 3. 效用AI调试面板
**功能**：可视化效用AI决策过程

**显示内容**：
- 当前痛点（最高优先级需求）
- 候选动作列表
- 每个动作的得分计算过程
- 最终选中的动作

### 4. 日志面板
**功能**：显示游戏运行日志

**日志级别**：
- DEBUG - 调试信息
- INFO - 一般信息
- WARN - 警告
- ERROR - 错误

**筛选功能**：按模块、按NPC、按级别筛选

---

## 快捷键

| 按键 | 功能 |
|------|------|
| F1 | 显示/隐藏调试面板 |
| F2 | 切换日志级别 |
| F3 | 单步执行（暂停模式下） |
| F4 | 导出当前世界状态 |
| ` | 打开控制台（预留） |
