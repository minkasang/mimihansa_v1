# 水产行为规范（鱼）

> ⚠️ 规范研究文档。鱼是全部生活在水中的动物。设计比陆地动物极简——它们不能上岸，人类也无法徒手抓。
> 复用人类 GOAP 引擎。感知范围极窄（水底看不清远处）。

---

## 一、鱼的参数

| 素质 | 值 | 说明 |
|:-----|:--:|:-----|
| 移动速度 | 5 | 在水中灵活 |
| 耐力 | 3 | 短冲刺 |
| 力量 | 1 | 无攻击力 |
| 视觉 | 6格 | 水底能见度低 |
| 听觉 | 15格 | 水传导声音好 |
| 嗅觉 | 10格 | 能闻到水中的食物气味 |
| 震动感知 | 20格 | **极灵敏**——通过侧线感知水波，远处有人踏水就知道 |

### 特殊限制

```
- 只能在[水域]格内移动 ← 不能上岸
- 不能离开水超过 3 Tick → 立即死亡（搁浅）
- 不能和陆地动物/人发生近战攻击——人在岸上，鱼在水里，永远隔着一格
- 人类获取鱼的唯一方式：钓鱼竿（后期）或渔网/鱼笼
```

## 二、鱼的欲望（5条，极简）

```
want_flee (优先级 10):
  条件: 感知到震动（人踏水 / 水中有大型物体靠近）
  目标: 朝反方向快速游走 → 躲到水底深水区

want_eat (优先级 9):
  条件: 饥饿度 > 5
  目标: 吃水中的浮游生物/水草/小虫
  效果: 饥饿度 -3

want_breed (优先级 7):
  条件: 发情季(春/夏) + 附近有异性同种鱼
  目标: 游到一起 → 产卵（水中产生大量鱼卵→孵化成鱼苗）

want_shoal (优先级 4):
  条件: 附近有同种鱼 + 自己不饿不逃
  目标: 游向最近的同种鱼 → 形成鱼群

默认: want_swim (优先级 2):
  条件: 无
  目标: 在周围水域中随意游动
```

---

## 三、鱼群的从众行为

```
鱼群: 同种鱼自动聚在一起
  → 鱼群中任何一条鱼感知到威胁（震动）→ 整群同时转向逃跑
  → 不需要通讯——侧线感应是纯物理反应，不是社交

鱼群大小: 5~30条
  太少：形不成群 → 各自游各自的
  太多：分群（鱼太多→随机分成两个子群）

鱼群对人类的反应:
  人靠近水边：震动感知 20格 → 鱼群早就游远了
  → 这就是"鱼很难徒手抓"的原因
  → 只有钓鱼竿/网才能在不引起震动的情况下获取鱼
```

---

## 四、鱼的繁殖

```
季节: 春、夏两次产卵季
每次产卵: 50~200颗卵 → 极少数活到成年（被其他鱼吃/环境淘汰）
鱼苗: 0~14天极微小（几乎不可见）→ 14天后可见 → 2~3月成年

自然界中:
  鱼是食物链最底层之一
  几乎没有防御能力
  靠数量多+跑得快活下来
```
