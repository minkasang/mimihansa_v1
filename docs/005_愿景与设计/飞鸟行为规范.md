# 飞鸟行为规范（鹰）

> ⚠️ 规范研究文档。鹰大部分时间在空中盘旋——不占地面格。极难被猎杀。
> 复用人类 GOAP 引擎。视觉 60格是游戏中最远的。

---

## 一、鹰的参数

| 素质 | 值 | 说明 |
|:-----|:--:|:-----|
| 移动速度 | 10 | 空中极快 |
| 耐力 | 6 | 可以长时间翱翔 |
| 力量 | 7 | 可以抓起小动物 |
| 视觉 | **60格** | 游戏最远——俯视全地图 |
| 听觉 | 15格 | 空中风大、听不清 |
| 嗅觉 | 5格 | 不重要 |

### 特殊：飞行状态

```
鹰有两种状态:
  飞行中（默认）:
    - 不占地面格（位置是"空中投影"）——相当于在更高层
    - 猎人和狼无法攻击飞行中的鹰
    - 鹰可以看到并锁定地面目标

  降落（仅在树上/岩石上休息或进食时）:
    - 占地面格
    - 可以被攻击
```

## 二、鹰的欲望（5条）

```
want_hunt (优先级 9):
  条件: 饥饿度 > 5 + 在地面上发现猎物（从60格高空看到的！）
  猎物偏好: 兔子(最优)→小鸡/小鸭→鱼(俯冲入水)→极小概率抓走人类婴儿
  目标: 俯冲 → 抓取 → 飞回高处进食
  
  俯冲判定:
    命中率: 0.5 + (猎物大小=小+0.2 / 中-0.1)
    兔子: 70%抓住
    鸡/鸭: 80%抓住（更慢）
    鱼: 50%（水会挡住一些）
    人类婴儿: 5%（极罕见，更多是被人类赶走）

want_eat_from_kill (优先级 10):
  条件: 刚刚猎杀了猎物 → 在爪下
  目标: action_eat（在高处吃，不被干扰）

want_sleep (优先级 6):
  条件: 疲劳度 > 7 OR 天黑
  目标: 飞到高树上 → 收起翅膀 → 睡觉

want_flee (优先级 10):
  条件: 感知到威胁靠近（人举弓/人靠近巢穴）
  目标: 立即起飞 → 盘旋到安全高度

默认: want_soar (优先级 2):
  条件: 无
  目标: 在空中以地图为中心盘旋，自动沿圆形轨迹飞行
```

## 三、鹰在生态系统中的角色

```
鹰对地面生态的冲击（重要！）:
  鹰的主要猎物是兔子和小型家禽
  → 如果玩家养鸡没有棚顶 → 鹰会抓走小鸡
  → 玩家需要建鸡舍防鹰
  → 这是"文明对抗自然"的一环

鹰对兔子的控制:
  兔子太多 → 鹰更容易猎到 → 鹰数量上升 → 兔子数量下降
  → 鹰和狼共享兔子这个食物源

鹰几乎不被猎杀:
  只有弓箭/弩可以射鹰（极难）
  鹰死亡后尸体掉在地上 → 鹰羽是贵重物品（可以做箭羽）
```
