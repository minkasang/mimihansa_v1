## 一、核心设计原则

### 1.1 游戏视角的铁律

```
NPC不是全知全能的撮合系统，他们是独立个体：
  - 只能"喜欢"自己认识的人（知识库/感知范围内的异性）
  - 好感是单向积累的（A喜欢B，B可能完全不知道）
  - 追求可能失败，失败的体验影响后续行为（乐观者继续，悲观者放弃）
  - 一切都是自发涌现的，没有"配对算法"
```

### 1.2 已有参数复用

恋爱系统不需要新增性格维度，全部依赖现有参数：

| 现有参数 | 在恋爱中的作用 |
|:---------|:--------------|
| 色欲 | 驱动"注意异性"的强度 |
| 外貌分 | 第一印象的核心 |
| 好感度 | 关系深度的数值表达 |
| 书生气 | 特殊气质加成 |
| 财富/社会地位 | 现实考量 |
| 情绪稳定性 | "会不会因为被拒绝而崩溃" |
| 乐观/积极倾向 | "被拒后要不要再试" |

## 二、择偶偏好：每个人心里有个"理想型"

### 2.1 设计思路

择偶偏好 = **通用默认偏好（固定）** + **个性化偏好（随机生成）**

**第一层：通用默认偏好（人类普适，所有人都有）**

```
默认偏好1：外貌分  权重 20%（漂亮/帅气的人天然受青睐）
默认偏好2：责任心  权重 10%（找靠谱的伴侣是本能）
```

**第二层：个性化偏好（18岁时随机生成，各NPC不同）**

```
偏好1（30%权重）— 由NPC自己最看重的品质决定：
  如果NPC的审美高 → 偏好"外貌分"（再加一层）
  如果NPC的求知欲高 → 偏好"书生气"
  如果NPC的贪婪高 → 偏好"财富"
  如果NPC的社交欲高 → 偏好"社交属性"（口才好、会聊天）
  如果NPC的安全感高 → 偏好"责任心"

偏好2（25%权重）— 通用偏好，多数人都在意：
  随机从 [外貌分, 责任心, 情绪稳定性] 中选一个

偏好3（15%权重）— 独特口味，完全随机：
  随机从所有评估维度中选一个
  （可能偏好"幽默感""行动意愿""乐观"这种不常见的）
```

> 这样既有真实感（好看的人天然受青睐），又有个体差异（有人偏爱书生气、有人偏爱幽默感）。

### 2.2 理想型评分公式

```
// NPC A 评估 NPC B 的"理想度"
理想型评分 = Σ(偏好i的权重 × B在偏好i维度的得分/10)

示例：
  张文博偏好：[外貌分 50%, 乐观 30%, 书生气 20%]
  李秀兰：[外貌8, 乐观4, 书生气3]
  
  理想型评分 = 0.5×(8/10) + 0.3×(4/10) + 0.2×(3/10)
             = 0.40 + 0.12 + 0.06 = 0.58（满分1.0）
  
  理想型评分 > 0.5 → "我觉得这人不错"
  理想型评分 > 0.8 → "这就是我的理想型！"
```

## 三、从注意到喜欢：好感度的积累

> ⚠️ v2.0 重写：删除了"注意概率"机制——太复杂且与信息壁垒矛盾。
> NPC不需要一个公式来决定"是否注意别人"——他只要感知到异性，就会自然地在互动中产生好感。

### 3.1 好感度的自然积累

好感度来自**实际互动**（聊天、帮忙、一起干活），不是凭空打分：

| 互动类型 | 好感增加量 | 说明 |
|:---------|:----------|:-----|
| 打招呼/寒暄 | +(对方社交欲/10)×1 | 聊得投不投机 |
| 帮助对方 | +2~5 | 雪中送炭好感倍增 |
| 送礼物 | +(礼物价值/10)×1~3 | 重礼不如投其所好 |
| 一起干活/做事 | +1~3 | 日久生情 |
| 被拒绝后 | -3~5 | 好心被当驴肝肺 |
| 冲突/吵架 | -5~10 | 严重伤害感情 |
| 时间流逝（长期不见面）| -(距上次见面天数/30)×1 | 感情会淡 |

### 3.2 好感度背后的"理想化"——随了解加深而更新

> ⚠️ v2.0 修正：初见时 NPC 只能看到外貌，不知道对方的性格。
> 理想型评分应该是一个**动态更新的评估**，每次互动后都可能变化。

```
首次见面（Step 2 感知到陌生人）:
  NPC 对陌生人的理想型评分 = 仅基于外貌分
    外貌评分权重 = 100%（唯一能看到的）
    
  ← 信息壁垒：看不到对方的性格数值，不能用来计算

后续互动（每次Step 6聊天或Step 5互动后）:
  NPC 逐步了解对方 → 他"以为"对方的性格是什么
  
  实际流程:
    1. NPC 通过聊天得知对方的一些事
       → 知识库.我知道的事: "她很乐观"、"他有点小气"
    2. 这些"我知道的事"里如果有关于性格的判断
       → NPC 更新"我估计的对方性格值":
         { 我估计的乐观值: 7, 我估计的财富: 3 }
    3. 理想型评分更新:
       = 外貌分权重 × 0.5 + 我估计的性格值 × 0.5
  
  ← 关键：NPC用的不是系统里的真实性格数值，而是他"估计"的。
    "我以为她很善良" ≠ "她真的很善良"
    一个人可能伪装——NPC的认知可以不准。
    这天然产生误解、错失、以及"看错人"的故事。
```

### 3.3 want_socialize（社交欲）的触发条件

> ⚠️ v2.0 新增：社交欲和好感驱动是两个独立的东西。

```
want_socialize（一般社交——想跟人说话，不一定有好感）:
  触发条件:
    1. 附近有任何人（感知范围内有实体）
    2. NPC.性格.社交属性_自我坦露 > 4（社交欲望中等以上）
    3. 当前非[战斗中]、非[分娩中]、非[极度疲劳]（疲劳度<8）
  
  效果:
    随便找人聊天、寒暄、交换信息
    → 可能顺便积累好感

want_pursue（恋爱追求——好感驱动）:
  触发条件:
    1. NPC对某异性的好感度 >= 60
    2. 对方在自己的知识库里有辨识符映射
  
  效果:
    见 §四 追求阶段
  
两者的关系:
  want_socialize → 聊天互动 → 好感自然积累 → 可能触发 want_pursue
  ↑ 社交是途径，好感是结果，追求是好感的下一步
```

### 3.4 好感度转化为"喜欢"

```
好感度 0~20   → 普通认识
好感度 20~40  → 熟人/朋友
好感度 40~60  → 好朋友，开始有一点点暧昧
好感度 60~80  → 喜欢 / 暗恋
好感度 80+    → 爱 / 非他不嫁/非她不娶

⚠️ 好感是单向的——A对B好感80 ≠ B对A好感80
   单相思是这个世界里自然存在的现象
```

## 四、追求阶段：从暗恋到行动

### 4.1 什么时候去追

```
NPC A 对 B 的好感度 ≥ 60 → 触发"想追求B"的欲望

追求意愿 = 色欲/10 × 0.4
         + 胆魄气量_无畏程度/10 × 0.3  // 胆子大才敢追
         + 情绪基调_积极倾向/10 × 0.2  // 乐观的人觉得有希望
         + (1 - 人际关系_猜疑程度/10) × 0.1  // 不多疑

追求意愿 > 0.5 → 展开追求行动
```

### 4.2 追求怎么做（指令序列）

```
追求过程不是一次性的，是一系列互动：

Step 1：找机会接近
  - 去对方常去的地方"偶遇"
  - 一起参加集体活动

Step 2：表达好感（根据性格选择方式）
  ├─ 社交欲+坦露度高 → 直接表白："我喜欢你"
  ├─ 社交欲高但谨慎 → 通过朋友传话
  ├─ 书生气高 → 写情诗/送书
  ├─ 大方+有钱 → 送贵重礼物
  └─ 沉默内向 → 默默对对方好（帮助、照顾）

Step 3：等对方回应
  B收到A的表白/示好后：
    回应得分 = B对A的好感度/100 × 0.6
            + B当前的社交状态 × 0.2  // 有没有喜欢别人？
            + B的情绪基调料当 × 0.2  // 心情好时更容易答应
    回应得分 ≥ 0.5 → 接受交往
    回应得分 < 0.5 → 拒绝
  
  A被拒绝后：
    乐观/积极倾向≥6 → "不放弃，继续追"（好感暂时-5，但不放弃）
    乐观/积极倾向<6 → "算了，没缘分"（好感-10，放弃）
    → 可能触发 §四（出生系统）中"想送礼挽回"的欲望
```

### 4.3 竞争

```
如果多个人同时追B：
  B比较所有人的好感度+理想型评分 → 选最高的
  落选者的反应：
    - 记仇度高 → 记恨获胜者
    - 嫉妒心高 → 暗中破坏
    - 乐观/大度 → 接受现实，祝福
```

## 五、交往阶段：恋爱中

### 5.1 确立关系

```
双方互相好感度 ≥ 60 → 自动进入"交往"状态
标签变化：双方获得 [情侣] [XXX的爱人]
关系公开化（双方知识库更新，朋友可能听说）
```

### 5.2 恋爱中的互动

| 互动 | 效果 | 频率 |
|:-----|:-----|:-----|
| 约会 | 双方开心+2~5 | 每周1~2次 |
| 送小礼物 | 好感+1~3 | 看性格 |
| 共同活动 | 好感+1，书生气高者喜欢一起读书 | 日常 |
| 争吵 | 好感-5~10（性格不合触发概率更高） | 偶尔 |
| 亲密接触 | 触发好感小增 | …… |

### 5.3 分手

```
分手触发条件（满足其一）：
  1. 一方好感度 < 30（长期感情破裂）
  2. 一方发现对方背叛/出轨
  3. 一方遇到"更好的选择"（理想型评分远超现任，且好感度已上60）

分手时的行为：
  - 记仇度+嫉妒高 → 可能报复
  - 情绪稳定 → 和平分手
  - 受伤害者：心情-20，记忆加标签[被分手]
```

## 六、结婚

### 6.1 求婚条件

```
一方向另一方求婚需满足：

条件1：双方好感度 ≥ 80（互相深爱）
条件2：双方当前在[情侣]状态，交往超过N个月
条件3：求婚方评估"我能给对方幸福吗？"
  ┌─ 是否有自己的住所（有房）？
  │   有 → +30分
  │   无但有钱 → +10分
  │   无且无钱 → -30分（没信心）
  ├─ 是否有稳定收入？
  │   有 → +30分
  │   无 → -30分
  └─ 综合分 > 0 → 敢求婚
      综合分 < 0 → 不敢求（先攒钱）

求婚方性格修正：
  大胆≥7 → 即使综合分<0也敢求（赌一把）
  谨慎≥7 → 综合分<20都不敢求
```

### 6.2 对方是否答应

```
被求婚方的判定：
  答应得分 = 对求婚方好感度/100 × 0.5
           + 求婚方的理想型评分 × 0.3
           + 求婚方综合条件分(住所+收入)/60 × 0.2  // 现实考量
  
  答应得分 ≥ 0.65 → 答应 ✅
  答应得分 < 0.65 → 说"还不ready，再等等"或拒绝
```

### 6.3 婚后变化

```
数据变化：
  双方关系标签：[夫妻]
  家的定义：共享住所（以后谁买的/租的房子当婚房）
  财务：可以共享（但各自仍有个人资产）
  社会认知：周围NPC知道"他们结婚了"
```

## 七、婚姻中的日常与危机

### 7.1 婚姻维持

```
婚后好感度的自然演变：
  每周好感变化 = 基础衰减(-0.5) + 互动加分 + 事件影响

  基础衰减：不互动的话，感情会缓慢变淡
  互动加分：约会/聊天/送礼物/共同活动 → 保持感情
  事件影响：一起经历大事（生子/买房）→ 好感突增
```

### 7.2 出轨

```
出轨条件：
  1. 已婚NPC的色欲 ≥ 7（好色本性）
  2. 遇到理想型评分 > 现任的异性
  3. 当前婚姻不幸福（好感度<50）
  AND 对方愿意（见周公之礼判定）
  
出轨被发现概率：
  时间越长 / 同村人越多 / 对方社交欲越高（更爱打听） → 更容易被发现
  
被发现后果：
  被出轨方：心情-30，信任崩溃
  出轨方：社会评价降低
  可能导致离婚
```

### 7.3 离婚

```
离婚触发条件（满足其一）：
  1. 一方好感度 < 10（长期感情枯竭）
  2. 出轨被发现 + 被出轨方不能原谅
  3. 长期分居（一方外出打工不归）

离婚效果：
  关系标签变回 [前夫/前妻]
  财产分割（简单处理：谁买的归谁）
  孩子抚养权（跟母亲，除非母亲放弃）
  双方心情大幅下降
  社会认知：周围NPC知道"他们离了"
```

## 八、与现有系统的衔接

### 8.1 与出生系统的关系

恋爱系统是出生系统**严格的逻辑前置**：
- 不恋爱 → 不结婚 → 不会触发【想要孩子】
- 恋爱中满足了性欲 → 可能发生周公之礼（但不一定怀孕，见出生系统）
- 非婚生子 → 受社会道德约束（出生系统 §4.1）

### 8.2 与色欲/性欲系统的关系

```
色欲(性格) → 驱动力：
  ├─ 驱使人去"注意异性"
  ├─ 驱使人去"追求"
  └─ 可能驱使"出轨"

性欲(生理状态) → 具体行为触发：
  └─ 周公之礼（见出生系统 §二）

两者配合：
  色欲高 = "我对异性感兴趣"（态度/倾向）
  色欲高 + 暧昧环境 + 亲密对象 → 性欲值上升 → 周公之礼（具体行动）
```

### 8.3 涉及的新参数/标签

| 参数/标签 | 说明 | 归属 |
|:---------|:-----|:-----|
| `择偶偏好` | 每个NPC的偏好列表(3项) | NPC个人信息 |
| `[情侣]` | 正在交往中 | 标签 |
| `[夫妻]` | 已结婚 | 标签 |
| `[暗恋]` | 偷偷喜欢某人 | 标签（NPC才知道，系统用） |
| `[被拒绝]` | 追求/表白被拒 | 标签（记忆） |
| `[前任]` | 前夫/前妻/前情侣 | 关系标签 |
| `[出轨]` | 记忆：出轨行为 | 标签（记忆） |

全部标签只在现有的"标签"维度中扩展，不需要新系统。

## 九、一条完整流程示例

```
张文博（男，18岁，色欲7，乐观8）

Step 1：进入择偶偏好生成
  → 偏好：[外貌分50%][乐观30%][书生气20%]

Step 2：感知范围内出现李秀兰（外貌8，乐观4，书生气3）
  → 理想型评分 = 0.58 → "这人不错"
  → 注意概率 = 0.6 → 注意到了

Step 3：张文博主动搭讪（action_搭讪）
  → 几次寒暄后，好感度积累到 35

Step 4：张文博继续接触，帮李秀兰干活、聊天
  → 好感度到 65 → 触发"喜欢"

Step 5：张文博追求意愿 = 0.7 → 展开追求
  → 送苹果（被嫌廉价）→ 好感-5
  → 不放弃（乐观8）→ 继续 → 打工赚钱 → 买玫瑰
  → 再次送礼 → 好感+20

Step 6：李秀兰对张文博好感到 65 → 互相喜欢 → [情侣]

Step 7：交往半年后，张文博好感度90，李秀兰好感度85
  → 张文博有房子（自己建的）、有稳定收入 → 敢求婚
  → 李秀兰答应 → [夫妻]

Step 8：婚后一年 → 触发生育意愿 → 想要孩子 → 受孕（见出生系统）
```
