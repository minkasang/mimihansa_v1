## 一、视角选择

采用**斜 45° 菱形等距（2.5D）**，而非正俯视或真 3D。

| | 正俯视 | 2.5D 等距 | 真 3D |
|:-----|:-----|:-----|:-----|
| 地形深度感 | ❌ 看不到 | ✅ 面高差+侧面 | ✅ |
| 水深度感 | ❌ 看不到 | ✅ 水面层半透明 | ✅ |
| 挖土效果 | ❌ 只能换颜色 | ✅ 侧面方块消失 | ✅ |
| 开发难度 | 低 | 中 | 高 |
| 像素风适配 | 好 | 经典 | 需要额外处理 |
| 参考游戏 | RimWorld | 星露谷/帝国时代2 | — |

## 二、坐标系统

### 2.1 三层坐标

```
逻辑层 (mx, my)         →   世界层 (wx, wy)        →   屏幕层 (sx, sy)
  格子索引                  菱形瓦片像素位置              Canvas 像素位置
  mx: 0~MapW-1              wx = (mx-my)×32            sx = wx × zoom + tx
  my: 0~MapH-1              wy = (mx+my)×16            sy = wy × zoom + ty
                              - elev × 4
```

### 2.2 变换公式

```typescript
// 逻辑格 → 世界像素 (菱形顶端)
function toWorld(mx: number, my: number, elev: number): [number, number] {
  return [(mx - my) * 32, (mx + my) * 16 - elev * 4];
}

// 世界像素 → 屏幕像素
function toScreen(wx: number, wy: number, zoom: number, tx: number, ty: number): [number, number] {
  return [wx * zoom + tx, wy * zoom + ty];
}
```

### 2.3 菱形参数

| 参数 | 值 | 说明 |
|:-----|:--|:-----|
| 菱形宽 | 64px | 瓦片左右跨度 |
| 菱形半高 | 16px | 瓦片上下半跨度 |
| 全高 | 32px | 顶到脚的完整高度 |
| 地势缩放 | 4px/单位 | elev=10 → 侧面高 40px |

## 三、渲染顺序（Z 序）

**对角线扫描**——从后往前，后面的瓦片自然被前面的遮挡。

```typescript
// sum = mx + my, 从小到大
// sum=0: (0,0)  → 最远
// sum=200: (100,100) → 最近
for (let sum = 0; sum <= maxSum; sum++) {
  for (mx = max(0, sum - maxY); mx <= min(maxX, sum); mx++) {
    drawTile(mx, sum - mx);
  }
}
```

## 四、瓦片绘制

### 4.1 一个菱形瓦片 = 3 个面

```
　　　 顶面 (topY)        ← 地形主色
　　  ╱　　　╲
　　╱　 顶面　 ╲
  ╱　        　╲
 左面         右面        ← 比顶面暗 15-30%
 　╲　　      ╱
   ╲　　    ╱
　  ╲　　  ╱
　　 ╲   ╱
　　  底边
```

### 4.2 地势映射（elev 0-10）

| CellTerrain | elev | 顶面色 | 左面色 | 右面色 |
|:-----|:---|:-----|:-----|:-----|
| WATER | 0 | #4a80b8 | #3a6898 | #2e5888 |
| DIRT | 3 | #8d6e63 | #7d5e53 | #6d4c41 |
| ROAD_CENTER | 4 | #b8a898 | #a89888 | #988878 |
| GRASS | 5 | #7cb342 | #5c9a28 | #4a8a1a |
| STONE | 8 | #a0a0a0 | #808080 | #707070 |

### 4.3 水面层

水域格在顶面上方叠加**半透明蓝色菱形**：

```
水面菱形在顶面之上偏移 waterDepth × 4px
alpha = 0.55 (可看到下方地形)
+ 白色高光 (alpha=0.04)
```
