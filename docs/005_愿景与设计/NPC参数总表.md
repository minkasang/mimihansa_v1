| **情商** | 1-10 | 社交能力、情绪感知 | ✅ 已有 |
| **健康** | 1-10 | 整体健康状态 | ✅ 已有 |
| **饥饿速度** | 1-10 | 每小时增加多少饥饿度 | ✅ 已有 |
| **低落抗性** | 1-10 | 情绪低谷抗性 | ✅ 已有 |

**哪些受环境影响？**
- 体力/精力：动态消耗，受活动影响
- 健康：受疾病、营养、环境灾害影响
- 智商/情商：基本稳定，但读书/经历可能微调

**体力爆发-恢复机制（追逐/快跑/重体力关键）：**
```
三种移动模式（NPC在每个时刻选择一种）：

  快跑：
    速度 = 移动速度 × 1.5
    每秒体力消耗 = 2点
    用途：追猎物、逃跑、紧急赶路

  慢走/行走：
    速度 = 移动速度
    每秒体力消耗 ≈ 0.2点（可忽略）
    用途：日常行走、逛圈、巡逻

  静止/休息：
    速度 = 0
    每秒体力恢复 = 体力恢复速度 点
    用途：喘口气、恢复

  体力上限 = 耐力值（恒定）

  例：耐力8的人 → 体力上限8 → 快跑4秒→体力耗尽→必须喘气
      耐力12的人→ 体力上限12→ 快跑6秒→体力更持久
```

## 十一、后天气质（新增）

> **区别于天生性格**：气质是后天习得的，由经历塑造，不是天生的性格维度。
> 气质的核心特点是：**由行动积累而来，反过来影响他人对NPC的感知和偏好**。

| 参数 | 范围 | 说明 | 积累方式 | 确定状态 |
|:----:|:----:|------|:--------:|:--------:|
| **书生气** | 1-10 | 读书积累的文化气质。越重越显得儒雅/有学识 | **每读一本书 +0.X**，长期积累 | ✅ **本决定新增** |

**书生气详解：**
- **来源**：读书（阅读书籍），不是上学
- **上学和读书的关系**：学校本身不增加书生气——上学只是因为学校里有书读，真正加书生气的是"读书"这个行为本身
- 没上过学但自学读书的人，书生气同样会增长
- **气质效果**：书生气高的NPC可能被某些异性偏好（"喜欢有书卷气的人"）
- 它和"智商/智力"不同：智商高不一定书生气重，书生气重的人一定读了很多书

## 参数之间的映射关系

某些参数之间存在交叉引用，这里记录一下：

```
素质参数 ↔ 天赋参数
  智力/智商 ←→ 智力天赋（几乎等同）
  力量 ←→ 力量天赋（几乎等同）

性格参数 ↔ 欲望参数
  色欲（性格/欲望）→ 影响生理状态中的性欲值
  社会属性_自我坦露 ←→ 社交欲（高度相关）

生理状态 ↔ 性格影响
  疲劳度 → 影响行动意愿
  开心值 → 影响积极倾向的临时修正

天赋参数 → 技能学习速度
  智力天赋高 → 学什么都快
  手工天赋高 → 锻造/建筑技能学得快

后天气质 ← 行为积累
  书生气 → 每读一本书积累，与上学无关

标签 ←→ 参数
  [怀孕中] → 对应"是否怀孕=true"
  [婴儿] → 对应"年龄段"分类
```

## 各参数的"可变性"

> ⚠️ **大部分参数都是可变的，只是变化速度不同。** 除了极少数"固定值"，绝大多数参数都会随年龄、经历、环境而变化。

| 可变性等级 | 说明 | 包含参数 |
|:---------:|------|---------|
| 🔒 **几乎不变** | 出生后基本固定，极难改变 | 性别 |
| 🐢 **非常缓慢变化** | 数年甚至数十年才变一次 | 发色、肤色、部分性格基线 |
| 📈 **随年龄渐变** | 随着年龄增长自然变化 | **身高**（生长发育期）、**长相分**（年轻→巅峰→衰老）、**智商发育曲线**、**体力上限**（先升后降）、**健康**（随年龄下降）、**耐力**（先升后降） |
| 📊 **动态波动** | 每Tick/每天变化 | **饥饿度、疲劳度、开心值、愤怒值、精力、体力**、经期进度、压力值 |
| 🛠️ **通过练习增长** | 用得越多越强 | **力量**、**身手敏捷**、**移动速度**、**技能等级**（种田/锻造/交易/战斗等）、**见识/知识库** |
| 🔄 **事件触发变化** | 特定事件后改变 | 好感度、记忆库、关系状态、债务、家族、性格（弹性性格机制） |
| ⚡ **环境即时影响** | 环境变化立即反映 | 生病状态、受伤/疼痛、醉酒、压力值、天气暴露 |

**重要修正：**
- 我之前写的"体力上限是缓慢变化"是对的，但**当前的体力值**是动态波动的（每Tick都在变）
- 健康不是固定的——**生病会下降，恢复会上升**
- 长相分不是固定的——年轻时候好看，老了就没那么好看
- 身高在生长发育期会变化，成年后基本不变
