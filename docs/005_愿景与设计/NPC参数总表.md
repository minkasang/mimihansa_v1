| **智力/智商** | 1-10 | 学习能力、决策质量 | ✅ 已有 |
| **情商** | 1-10 | 社交能力、情绪感知 | ✅ 已有 |
| **健康** | 1-10 | 整体健康状态 | ✅ 已有 |
| **饥饿速度** | 1-10 | 每小时增加多少饥饿度 | ✅ 已有 |
| **低落抗性** | 1-10 | 情绪低谷抗性 | ✅ 已有 |

**哪些受环境影响？**
- 体力/精力：动态消耗，受活动影响
- 健康：受疾病、营养、环境灾害影响
- 智商/情商：基本稳定，但读书/经历可能微调

**体力爆发-恢复机制（追逐/快跑/重体力关键）：**
```
三种移动模式（NPC在每个时刻选择一种）：

  快跑：
    速度 = 移动速度 × 1.5
    每秒体力消耗 = 2点
    用途：追猎物、逃跑、紧急赶路

  慢走/行走：
    速度 = 移动速度
    每秒体力消耗 ≈ 0.2点（可忽略）
    用途：日常行走、逛圈、巡逻

  静止/休息：
    速度 = 0
    每秒体力恢复 = 体力恢复速度 点
    用途：喘口气、恢复

  体力上限 = 耐力值（恒定）

  例：耐力8的人 → 体力上限8 → 快跑4秒→体力耗尽→必须喘气
      耐力12的人→ 体力上限12→ 快跑6秒→体力更持久
```

## 十一、后天气质（新增）

> **区别于天生性格**：气质是后天习得的，由经历塑造，不是天生的性格维度。
> 气质的核心特点是：**由行动积累而来，反过来影响他人对NPC的感知和偏好**。

| 参数 | 范围 | 说明 | 积累方式 | 确定状态 |
|:----:|:----:|------|:--------:|:--------:|
| **书生气** | 1-10 | 读书积累的文化气质。越重越显得儒雅/有学识 | **每读一本书 +0.X**，长期积累 | ✅ **本决定新增** |

**书生气详解：**
- **来源**：读书（阅读书籍），不是上学
- **上学和读书的关系**：学校本身不增加书生气——上学只是因为学校里有书读，真正加书生气的是"读书"这个行为本身
- 没上过学但自学读书的人，书生气同样会增长
- **气质效果**：书生气高的NPC可能被某些异性偏好（"喜欢有书卷气的人"）
- 它和"智商/智力"不同：智商高不一定书生气重，书生气重的人一定读了很多书

> ⚠️ v1.3 合并：原"知识库"和"记忆库"已统一为一个数据结构。区别不再用两个数组，而是用每条知识条目的 `来源` 字段区分。
> - `来源: "亲眼"` → 原来的"记忆库"（亲身经历）
> - `来源: "听说"` → 原来的"知识库"（信息传播）
> - `来源: "习得"` → 技能知识（如学会石刀配方）

| 参数 | 范围/类型 | 说明 | 确定状态 |
|:----:|:---------:|------|:--------:|
| 知识库 | `KnowledgeItem[]` | NPC知道的所有信息（事实+经历+技能），按来源区分可信度 | ✅ 已有（知识图谱） |
| 对某人认知 | 知道/不知道/听说过 | 对特定NPC的认知状态 | 📝 待细化 |
| 对某地认知 | 知道/不知道/去过 | 对地点的认知 | 📝 待细化 |
| 八卦/谣言 | 字符串列表 | 听说的不确定信息 | 📝 待加 |

```typescript
// 知识库条目（统一格式，替代原 知识库+记忆库 双数组）
interface KnowledgeItem {
  id: string;              // 本条目的唯一标识
  类型: "事实" | "经历" | "技能" | "人物" | "概念" | "地点";
  辨识符?: string;          // ← v1.4 新增。人物类型专属，NPC自己世界里给另一个人的"内部代号"（如"r_001"）
  称呼?: string;            // ← v1.4 新增。人物类型专属，NPC对这个人的称呼（随着了解加深而进化）
  内容: string;             // 条目内容（非人物类型的通用字段）
  来源: "亲眼" | "亲耳" | "亲身" | "听说" | "习得";
  可信度: number;           // 0~1。亲眼=1.0，听说第三手=0.5，随传播递减
  时间戳: number;           // 获得时的时间
  情绪?: string;            // 经历类型才有（"开心""悲伤"等）
  相关NPC?: string[];       // 与哪些NPC相关（用辨识符引用）
  
  // === 以下为"人物"类型专属 ===
  我眼中的TA?: {            // ← v1.4 新增
    外貌: {
      颜值: number;          // 1-10，我觉得TA多好看
      身高: string;          // 我的感觉
      体型: string;          // 我的感觉
    };
    标签: string[];          // 我给TA贴的标签
  };
  见面记录?: {              // ← v1.4 新增
    次数: number;
    时间: string;
    地点: string;
    TA在干什么: string;
  }[];
  我知道的事?: {            // ← v1.4 新增
    内容: string;
    来源: "亲眼" | "亲耳" | "亲身" | "听说";
    可信度: number;
  }[];
}
```

## 十四、标签系统（快照标记）

> 标签是"轻量级标记"，和数值参数不同——标签只有"有"或"没有"，用于快速筛选。
> 
> ⚠️ v1.5 重大审计：标签分为三类，仅第一类写入NPC.标签数组。

### 14.1 标签分类

| 类别 | 写入 NPC.标签[]？ | 说明 |
|:-----|:----------------:|:-----|
| **外部可见标签** | ✅ 是 | 任何 NPC 通过 Step 2 感知可判断。如年龄、受伤、醉酒 |
| **认知标签** | ❌ 否 | NPC 的主观认知，存在于知识库中。如"他是我的朋友"、"她是寡妇" |
| **环境标签** | ❌ 否 | 不属于 NPC 状态，是环境/情景。如"独处""夜晚""安静"——应评估时即时判断 |

### 14.2 外部可见标签表（写入 NPC.标签[]）

| 标签维度 | 标签值 | 判定 |
|:--------:|:------|:----:|
| 年龄段 | `[婴儿]` `[幼儿]` `[学龄]` `[青少年]` `[成年]` `[老年]` | 外部可见 |
| 身体状态 | `[受伤]` `[残疾]` `[醉酒]` `[生病]` | 外部可见 |
| 情绪极端 | `[狂怒]` `[极度悲伤]` `[狂喜]` | 外部可见（表情/行为） |
| 状态 | `[忙碌]` `[空闲]` `[战斗中]` `[休息中]` | 外部可见（行为） |
| 怀孕/哺乳 | `[怀孕中]` `[哺乳期]` | 外部可见（肚子大/抱婴儿） |
| 年龄段切换 | `[临产]` `[分娩中]` | 外部可见（行为异常） |

### 14.3 认知标签（不在 NPC.标签[]中——在知识库中）

| 标签维度 | 标签值 | 在哪 |
|:--------:|:------|:-----|

| 教育身份 | "这个人是我的老师"、"我是学生" | 知识库.人物条目.标签 |

### 14.4 环境标签（不在 NPC.标签[]中——评估时即时判断）

| 标签 | 用途 | 如何判定 |
|:-----|:-----|:---------|
| `[独处]` | 性欲值计算、暧昧条件 | 计算周围N格内有几个NPC——即时算，不需要存标签 |
| `[夜晚]` | 性欲值、睡眠欲望 | 读 World.时间.是否白天 反向 |
| `[室内]` | 性欲值、隐私 | NPC与目标在同一建筑内 |
| `[安静]` | 性欲值 | 周围没有"喊叫""打斗"等听觉事件 |

**这些标签从 NPC参数总表 §十四中删除**，不再作为"标签系统"的一部分。它们存在于相关的计算公式中（出生系统、暧昧系统），但不需要写成标签。

## 参数之间的映射关系

某些参数之间存在交叉引用，这里记录一下：

```
素质参数 ↔ 天赋参数
  智力/智商 ←→ 智力天赋（几乎等同）
  力量 ←→ 力量天赋（几乎等同）

性格参数 ↔ 欲望参数
  色欲（性格/欲望）→ 影响生理状态中的性欲值
  社会属性_自我坦露 ←→ 社交欲（高度相关）

生理状态 ↔ 性格影响
  疲劳度 → 影响行动意愿
  开心值 → 影响积极倾向的临时修正

天赋参数 → 技能学习速度
  智力天赋高 → 学什么都快
  手工天赋高 → 锻造/建筑技能学得快

后天气质 ← 行为积累
  书生气 → 每读一本书积累，与上学无关

标签 ←→ 参数
  [怀孕中] → 对应"是否怀孕=true"
  [婴儿] → 对应"年龄段"分类
```

## 各参数的"可变性"

> ⚠️ **大部分参数都是可变的，只是变化速度不同。** 除了极少数"固定值"，绝大多数参数都会随年龄、经历、环境而变化。

| 可变性等级 | 说明 | 包含参数 |
|:---------:|------|---------|
| 🔒 **几乎不变** | 出生后基本固定，极难改变 | 性别 |
| 🐢 **非常缓慢变化** | 数年甚至数十年才变一次 | 发色、肤色、部分性格基线 |
| 📈 **随年龄渐变** | 随着年龄增长自然变化 | **身高**（生长发育期）、**长相分**（年轻→巅峰→衰老）、**智商发育曲线**、**体力上限**（先升后降）、**健康**（随年龄下降）、**耐力**（先升后降） |
| 📊 **动态波动** | 每Tick/每天变化 | **饥饿度、疲劳度、开心值、愤怒值、精力、体力**、经期进度、压力值 |
| 🛠️ **通过练习增长** | 用得越多越强 | **力量**、**身手敏捷**、**移动速度**、**技能等级**（种田/锻造/交易/战斗等）、**见识/知识库** |
| 🔄 **事件触发变化** | 特定事件后改变 | 好感度、记忆库、关系状态、债务、家族、性格（弹性性格机制） |
| ⚡ **环境即时影响** | 环境变化立即反映 | 生病状态、受伤/疼痛、醉酒、压力值、天气暴露 |

**重要修正：**
- 我之前写的"体力上限是缓慢变化"是对的，但**当前的体力值**是动态波动的（每Tick都在变）
- 健康不是固定的——**生病会下降，恢复会上升**
- 长相分不是固定的——年轻时候好看，老了就没那么好看
- 身高在生长发育期会变化，成年后基本不变

## 十五、NPC数据结构定义（TypeScript interface）

> ⚠️ 本章节是代码实现的直接映射。所有参数的嵌套层级、持久化/运行时区分在此定义。
> 对应代码文件：`web/map-demo/src/types/npcTypes.ts`

### 15.1 嵌套结构总览

```typescript
interface NPC {
  // === 持久化字段（存JSON） ===
  id: string;
  姓名: string;
  性别: "男" | "女";
  年龄: number;

  生理状态: PhysiologicalState;     // §四 + §五
  性格: Record<string, number>;     // §七（34维）
  技能: Record<string, number>;     // §十
  物品栏: Item[];                   // §物品
  金钱: number;
  标签: string[];                   // §十四
  社会关系: SocialRelations;         // §十二
  择偶偏好: MatePreferences;         // 恋爱系统
  知识库: KnowledgeItem[];           // §十三（统一格式，含事实+经历+技能）
  家坐标: [number, number] | null;
  工作场所ID: string | null;

  // === 运行时计算值（不存JSON，每Tick更新） ===
  当前位置: [number, number];
  当前动作: string;
  当前目标: any;
  意图栈: PersistentIntent[];        // 持续性意图
}
```

### 15.2 持久化 vs 运行时区分

| 字段 | 类型 | 持久化？ | 说明 |
|:-----|:-----|:--------:|:-----|
| id / 姓名 / 性别 / 年龄 | 基础 | ✅ | 身份标识 |
| 生理状态.* | number | ✅ | 每Tick变化但需持久化 |
| 性格.* | number | ✅ | 34维性格 |
| 技能.* | number | ✅ | 技能等级 |
| 物品栏 | Item[] | ✅ | 背包内容 |
| 金钱 | number | ✅ | 当前金钱 |
| 标签 | string[] | ✅ | 状态标签 |
| 社会关系.* | various | ✅ | 关系数据 |
| 择偶偏好 | object | ✅ | 3项偏好+权重 |
| 知识库 | KnowledgeItem[] | ✅ | 已知信息（事实+经历+技能，按来源区分） |
| 家坐标 | tuple/null | ✅ | 住所位置 |
| 工作场所ID | string/null | ✅ | 工作地点 |
| **当前位置** | tuple | ❌ | 运行时，由移动系统更新 |
| **当前动作** | string | ❌ | 运行时，由BrainEngine更新 |
| **当前目标** | any | ❌ | 运行时，由欲望系统更新 |
| **意图栈** | PersistentIntent[] | ❌ | 运行时，持续性意图管理 |

### 15.3 新增字段说明（v1.1 新增）

| 字段 | 来源 | 说明 |
|:-----|:-----|:-----|
| `生理状态.口渴` | 原始生存系统 | 1-10，口渴度。1=不渴，10=极度口渴 |
| `社会关系.好感度` | 恋爱系统/社交系统 | `Record<string, number>`，目标NPC_ID → -100~+100 |
| `社会关系.配偶ID` | 恋爱系统 | `string | null` |
| `社会关系.父母ID` | 出生系统 | `string[]` |
| `社会关系.子女ID` | 出生系统 | `string[]` |
| `社会关系.师徒ID` | 教育系统 | `string[]` |
| `择偶偏好` | 恋爱系统 | 3项偏好+权重，每个NPC独立 |
| `家坐标` | 建房系统 | `[x,y] | null`，null表示无住所 |
| `工作场所ID` | 职业系统 | `string | null` |
| `意图栈` | 引擎架构 | `PersistentIntent[]`，持续性意图管理 |

### 15.4 参数范围统一确认

| 参数 | 精确范围 | 说明 |
|:-----|:--------|:-----|
| 饥饿度 | 1-10 | 1=很饱，10=极度饥饿 |
| 口渴度 | 1-10 | 1=不渴，10=极度口渴 |
| 疲劳度 | 1-10 | 1=精力充沛，10=濒临崩溃 |
| 性欲值 | 0-100 | ⚠️ 注意：范围与其他生理状态不同 |
| 好感度 | -100~+100 | 负数=厌恶，正数=好感 |
| 健康值 | 0-100 | 0=死亡，100=完全健康。⚠️ 死亡系统寿命公式中的"健康值0-10"应理解为健康值/10的整数部分 |
| 性格维度 | 1-10 | 34维统一 |
| 技能等级 | 0-100 | ⚠️ 统一为0-100，不再用1-10 |
| 开心值 | 1-10 | 1=极度悲伤，10=极度开心 |
| 精力 | 0-100 | 0=精疲力竭，100=精力充沛。与疲劳度互补：精力≈(10-疲劳度)×10 |

> ⚠️ **全局方向约定（P0，覆盖§四旧定义）**：
> 所有生理状态参数，**高值=危险/负面**（饥饿高=饿、疲劳高=累、口渴高=渴），
> 唯一例外是**精力**（高值=正面）和**健康值**（高值=正面）。
> 效果路由表中负值=减少该参数（`"饥饿": -3` = 饥饿度降低3点 = 更不饿了）。
> §四中"1=快饿死，10=很饱"为旧版定义，**已废弃，以本表为准**。
