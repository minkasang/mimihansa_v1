# 世界能发生什么 —— 全部可能事件清单

> 本文档是项目愿景的起点。穷举这个世界里所有可能发生的事情，再从事件倒推引擎能力，最后才定数据账本格式。
> ⚠️ 这是规范研究文档，不直接映射当前代码。内容需要反复与设计师确认。
> 设计师（用户口述）→ 辅助角色（AI整理）→ 设计师检查确认

## 一、NPC 人生阶段

### 1.1 出生
- NPC由父母生育产生
- 遗传父母的基因/DNA特征（外貌、部分性格倾向、天赋）
- 出生家庭的财富/社会地位影响起点

### 1.2 童年期
- 父母决定是否让小孩上学（依赖：附近有没有学堂/老师）
- 如果村子没有学堂条件 → 聪明的人可能自学，或伐木做家具谋生
- 没条件上学的NPC → 可能走向体力劳动路线

### 1.3 青少年期
- 开始形成独立认知和世界观
- 学习技能、帮家里干活
- 天赋开始显现：聪明的人做东西快，笨的人可能五天才能做个板凳
- 对异性产生好感，开始情感探索

### 1.4 成年期（核心阶段）
- 结婚生子（选择配偶基于自己的性格和偏好）
- 选择职业/谋生方式
- 可能经历多次感情（先遇到合适的人，也可能后来遇到更好的）
- 积累财富、建立社交圈
- 性格驱使决策，大脑负责决策执行

### 1.5 中年期
- 根据家庭和孩子变化调整人生目标
- 可能变得懒惰、拖延——知道该做什么但不想做，直到最后一刻
- 可能变得麻木——知道该努力但已经没动力了（像真实的人一样）
- 朋友关系随时间加深或恶化

### 1.6 老年期
- 身体状况下降
- 可能依赖子女
- 知识/经验可传给下一代

### 1.7 死亡
- 自然死亡（老死）
- 意外死亡（被杀害、饿死、病死）
- 角色永久消失，但子女延续

## 二、NPC 认知与信息传播

### 2.1 个人认知（核心机制！）
- 每个NPC有自己独立的知识存储
- 信息滞后性：A今天知道B有手机，但B明天换了新手机，A不知道
- 信息传播链条：B告诉C → C知道了 → 但A不知道（除非C告诉A）
- 一个人的记忆不会在他不了解的情况下自动更新
- NPC可能一直"以为"某种情况，但实际已经变了

### 2.2 信息传播方式
- 直接对话（B告诉A）
- 亲眼目睹（A看到B做了什么）
- 道听途说（C告诉A关于B的事，可能失实）
- 书面记录（如果未来有文字/报纸系统）

### 2.3 认知影响行为
- NPC只知道自己的钱够不够 → 心里想要新衣服但不买，因为觉得不值
- NPC只根据自己的认知做决策（不知道的事不会影响他）
- 认知偏差可能导致误解、谣言

## 三、制作与生产（简化流程）

### 3.1 设计原则：抽象化生产
- 不模拟真实物理，改用**材料 + 时间 + 技能 = 产出**的模式
- 保留过渡阶段感，但跳过微观步骤
- 示例：有木头 + 木匠做了X时间 → 得到凳子/桌子

### 3.2 材料需求
- 每种制品定义所需材料种类和数量
- 桌子需要多少木头 → 预设值
- 凳子需要多少木头 → 预设值
- 材料来源：自然界采集 / 购买 / 拆解旧物

### 3.3 个体差异
- 同一件物品，不同NPC制造效率不同
- 聪明的人（高智商天赋）→ 做得快
- 笨的人 → 五天才做一个板凳
- 工匠技能等级影响产出质量和速度

### 3.4 预设的通用性
- 制作配方必须是通用的、可扩展的
- 新增物品 = 新增一条配方JSON（材料+时间+技能要求）

## 四、交易与经济

### 4.1 基础交易
- 种地 → 收获 → 卖钱 → 增加收入
- 农作物：苹果、桃子、小麦、黄瓜、西红柿等
- 从自然界直接获取资源
- 通过劳动获得收入

### 4.2 商铺系统
- 有人开商铺买卖
- 有政府时 → 需要营业执照、交税
- 无政府时 → 随便摆摊（像古代一样）
- 商铺需要政府批准或默认允许

### 4.3 跨区域贸易
- 有人用马车从低价区拉货到高价区卖
- 需要计算差价 + 运费（差马费）
- 需要设计一套价格计算机制
- 贸易路线可能自然形成

### 4.4 商品多样性
- 不同种类的衣服（上衣、裤子、内裤等）
- 不同等级的衣服（粗布 → 丝绸）
- 不同价格的衣服
- 价格受供需影响（未来）
- NPC喜欢买新衣服 → 消耗金钱 → 带动经济

### 4.5 金钱流转
- NPC收入来源：劳动、交易、继承、借贷
- NPC支出：购物、纳税、被偷、被抢
- 借钱是必要的——标记借款关系，到期需还
- 可能发展出借贷/利息机制

## 五、人际关系

### 5.1 友情
- 人与人之间发展朋友关系
- 随着年龄增长，情感可能加深或产生矛盾
- 性格差异导致冲突：有人做了伤害朋友的事
- 朋友知道后用自己的方式处理——可能决裂

### 5.2 恋爱与婚姻

#### 择偶偏好
- NPC根据自己的性格特征去喜欢特定类型
- 女性可能更偏好：充满活力、身高高大、长相帅气、包容力强的男性
- 有人不善表达感情（笨拙型），有人乐观主动追求
- NPC自己做决策——选择谁、是否追求、是否等待更好的人

#### 婚姻
- 找到合适的人 → 结婚
- 可能后来遇到更好的 → 产生矛盾（是否出轨/离婚）
- 可能一直遇不到 → 终身单身
- 性格决定忠诚度

### 5.3 生育与遗传
- 生育产生新的NPC
- 孩子遗传父母的基因/DNA
- 外貌有相似性
- 部分性格倾向遗传
- 需要一个遗传模块

### 5.4 负面关系
- **背叛**：标记哪些行为是背叛的
- **记仇**：记仇属性高的人记住伤害并可能报复
- **借钱不还**：伤害关系
- **欺骗**：可能破坏信任

### 5.5 认大哥 / 帮派
- 较少发生但可能存在
- 形成条件：某人能给其他人实质好处
- NPC认大哥的动机：获得保护、资源、利益
- 帮派形成后可能争夺地盘和资源

## 六、群体行为

### 6.1 村庄/城镇管理
- 没有政府时 → 帮派争斗、抢地盘
- 有政府时 → 选举产生管理者
- 村庄可能自然选举出一个人来管理

### 6.2 贸易路线
- 车辆运输（从步行到马车到自行车）
- 贸易路线自然形成（哪里便宜去哪买，哪里高价去哪卖）
- 需要道路基础设施

### 6.3 教育与文化
- 有人成立学堂 → 其他人可以上学
- 没有人成立 → 聪明的人自学
- 学校提高整体智能水平
- 聪明的人可以伐木做家具、搞科研

### 6.4 科技/文明演进
- 技术解锁：步行 → 自行车 → 马车 → 汽车？（未来）
- 科技内容需要预设（我们设计解锁树）
- NPC通过读书提升见识
- 读书不一定提升智商，但开阔眼界

## 七、自然灾害与疾病

### 7.1 天气灾害
- **干旱**：影响农作物、饮水
- **暴雨**：可能改变地形、淹没低洼地（复杂，先留白）
- 天气影响NPC行为（暴雨时找地方躲雨）

### 7.2 地震
- 可能破坏建筑
- 比较复杂，先留白

### 7.3 瘟疫/疾病
- 病毒传播机制
- 有人可能生病，有人免疫
- 医生的角色：阻断传播、治疗病人
- 瘟疫影响经济和社会秩序

## 八、玩家参与方式

### 8.1 观察者模式（玩法A）
- 不创建角色
- 以上帝视角观看世界演化
- 点击任意NPC查看完整履历：性格、经历、关系网、一生轨迹
- 类似"上帝数据面板"

### 8.2 创建者模式（玩法B）
- 创建一个NPC投入世界
- 创建后可能经历：
  - 统治别人（拉帮结派、当镇长、当奴隶主、当地主）
  - 被统治（被聪明NPC征服、被剥削）
  - 当个普通人
- 玩家角色也有寿命限制
- 未来可通过"修仙"延长寿命，持续观察世界演化
- 玩家的自由：做好人/做坏人/做普通人，都影响世界

## 九、NPC 人性的模拟（关键！）

### 9.1 性格驱动的决策
- 每个NPC的性格底色 + 生活经历 → 影响所有决策
- 大脑/决策系统负责做出选择（统一术语）
- NPC不是理性机器，有人性弱点

### 9.2 懒惰与拖延
- 知道该做但不想做
- 拖延到最后一刻才去做
- 可能一直不做——像真实的人一样麻木了

### 9.3 欲望与克制
- 心里想要但不买（因为没钱/觉得不值）
- 克制不是因为不能，而是权衡后的选择

### 9.4 攀比心
- 看到邻居盖了大楼房 → 也想盖
- 攀比驱动消费和生产

## ⚠️ 已知矛盾/待澄清点

1. **智商是天赋还是性格？** 当前系统中"智商"在「身体素质」里，但聪明程度也影响制作效率和决策质量——需要明确智商的定位。
2. **"读书提升见识" vs "读书提升智商"** —— 当前说法是不提升智商，但开阔眼界。开阔眼界在系统中如何体现？（知识库扩大？决策质量变高？）
3. **简化流程的"度"在哪里？** 制作一件东西 = 材料+时间，是否还需要中间步骤？（比如砖头需要先挖泥→烧制？）
