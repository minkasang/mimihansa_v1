## 二、兔子的参数

```
兔子在人类引擎中的有效参数:

  生理状态:
    饥饿度, 口渴度, 疲劳度, 健康度, 性欲值(发情用)

  素质（仅速度和耐力有用）:
    移动速度: 8（比普通人快——跑得快是兔子唯一的武器）
    耐力: 4（体力上限低——跑不久）
    体力: 4

  性格（仅1维有意义）:
    胆魄气量_风险规避: 1（极低——稍有动静就跑）
    其他33维: 全部 = 1（不被欲望库引用，不参与计算）

  感知:
    视觉半径: 15格
    听觉半径: 40格（大耳朵）
    嗅觉半径: 20格
    震动感知: 10格（地面震动 → 提前察觉靠近的捕食者）

  知识库（极简——只有2~3条）:
    类型:"地点", 名称:"水源", 位置:[x,y]
    类型:"地点", 名称:"窝", 位置:[x,y]
    类型:"事实", 内容:"上次在东北方向的草地有好吃的草"

  技能: 全部 = 0
  物品栏: 无
  社会关系: 无（兔子是独居或松散的群体，没有等级）
```

## 二、兔子的感官——为什么难抓

兔子几乎是猎物中最难抓的——不是因为它快，而是因为它**感知早**。

```
人类的接近方式 vs 兔子的反应:

  人快跑（速度 1.5× → 震动感知 10×2 = 20格:
    人在25格外跑步 → 兔子已经知道了 → 提前跑掉

  人正常走（速度 1.0× → 震动感知 10格）:
    人在12格外走路 → 兔子警觉 → 抬头、停止进食
    → 如果人继续靠近到8格 → 兔子跑了

  人潜行（速度 0.3× → 震动感知 10-8 = 2格）:
    人几乎贴到2格 → 兔子才发现 → 此时人冲刺攻击
    → 兔子来不及跑 → 被猎杀

  兔子在进食时（分心）:
    感知全部 -30%
    震动感知: 7格、听觉: 28格、视觉: 10格
    → 更容易被潜行接近
```

## 三、兔子的日常作息

```
兔子不是全天活动的——它们有固定的出没时间:

05:00~08:00（清晨）: 觅食高峰 ← 最容易看到兔子的时间
  - 从窝里出来
  - 在草地/灌木丛吃草和嫩叶
  - 顺便去水源喝水

08:00~11:00（上午）: 休息
  - 在窝附近晒太阳
  - 偶尔出来啃几口草

11:00~16:00（中午）: 躲藏
  - 太阳大了，回到窝里或灌木丛下面
  - 避开正午的高温

16:00~20:00（黄昏）: 第二次觅食高峰
  - 再次出来吃草
  - 这是第二个狩猎窗口

20:00~05:00（夜晚）: 在窝里休息
  - 兔子是晨昏性动物——白天和黑夜都在窝里
  - 除非被捕食者赶出窝
```

## 四、兔子的欲望（5条）

```
want_flee (优先级 10, 最高):
  条件: 感知到捕食者（狼/人）在靠近
       （震动感知触发 OR 视觉看到 OR 嗅觉闻到）
  目标: action_flee
  策略: 反方向快跑 → 跑到最近灌木丛/窝 → 躲起来

want_eat (优先级 9):
  条件: 饥饿度 > 5 + 是清晨或黄昏
        （中午太热了不出来，即使饿也忍着）
  目标: action_forage（吃草/嫩叶）
  效果: 饥饿度 -4

want_drink (优先级 8):
  条件: 口渴度 > 6
  目标: action_go_to_water
  效果: 口渴度 -5

want_sleep (优先级 5):
  条件: 疲劳度 > 7 + 在窝附近
  目标: action_sleep
  效果: 疲劳度 -4

默认: want_hide (优先级 2):
  条件: 没有高优先级目标
  目标: action_hide（躲在窝里或灌木丛下）
  ← 兔子的默认状态不是游荡，是躲藏
  ← 它们只在固定的觅食时间出来
```

## 五、兔子的逃跑策略

```
兔子看到威胁 → 立即逃跑，不是犹豫:

逃跑路线:
  1. 优先往最近的窝跑（知识库里有就直奔）
  2. 如果没有窝 → 往最近的灌木丛跑
  3. 如果没有灌木丛 → 随机方向（远离威胁）

逃跑速度:
  快跑（速度 8 × 1.5 = 12）→ 体力每秒-2
  兔子耐力=4 → 体力上限=4 → 只能跑2秒
  → 2秒后体力耗尽 → 降为慢走
  → 如果捕食者耐力更强 → 追上了 → 被猎杀

躲藏:
  到了窝/灌木丛 → 蹲下不动 → 视觉感知+50%（警戒）
  → 如果威胁离开 → 20 Tick后才敢出来
  → 如果威胁持续在附近 → 继续躲
```

## 六、兔子的觅食

```
兔子吃:

  草（草地上自然生长，无限）:
    效果: 饥饿度 -2
    耗时: 10 Tick（低头吃草）

  嫩叶/灌木叶（森林/灌木丛）:
    效果: 饥饿度 -3
    耗时: 8 Tick

  野果/莓果（偶尔遇到）:
    效果: 饥饿度 -4
    耗时: 5 Tick
    但兔子不会主动去找野果——它们碰上了才吃

  树皮（冬天草少时）:
    效果: 饥饿度 -1
    耗时: 20 Tick（难啃）
    仅在冬天使用 ← 这是兔子能活过冬天的原因

兔子的食谱和季节:
  春/夏: 草地和灌木丛草+嫩叶充足 → 兔子和鹿竞争
  秋: 草开始枯萎 → 兔子和鹿都往有灌木的地方集中
  冬: 草基本没了 → 兔子啃树皮、挖草根 → 此时狼最难——猎物都躲起来了
```

## 七、繁殖

```
繁殖条件:
  - 任何成年公兔 + 母兔（没有等级限制——兔子不是狼）
  - 发情季节: 春、夏、秋（一年三季可繁殖，每次间隔约30天）
  - 母兔健康 > 5

交配:
  公兔 want_breed → 靠近母兔 → 交配
  → 母兔进入孕期

孕期: 约30天（游戏时间）
每窝: 3~8只幼崽（兔子繁殖力极强）
每年可生: 3~4窝 ← 这就是"兔子成灾"的原因

幼崽:
  0~14天: 在窝里，不出门
  14~30天: 跟着母兔出窝探索（但不去太远）
  1个月: 独立（离开母兔，自己找窝）

母兔喂奶:
  幼崽 0~14天 在窝里 → 母兔每天回窝1~2次喂奶
  → want_nurse_kits 触发（优先级7，低于吃喝高于睡觉）
  → 回窝 → 喂奶 → 幼崽饥饿度恢复
  → 14天后幼崽开始吃草 → 母兔不再频繁喂奶

如果游戏里不控制兔子数量:
  1对兔子 → 1年后 → 可能增长到50~100只
  ← 这是真实的——自然界靠狼/狐狸来控
    在游戏里，狼群狩猎频率决定了兔子数量是否爆炸
```

## 八、兔子与捕食者

```
兔子的天敌:
  狼: 如果在兔子附近出现 → 兔子逃跑 → 狼追逐 → 体力比较
       兔子跑得快但耐力差 → 如果兔子在2秒内到了窝 → 存活
       如果兔子在开阔地 → 被追上 → 死亡

  人类: 同上，但人可以潜行 → 更难被兔子感知

  鹰（飞鸟——未来实现）:
    鹰从天上俯冲 → 兔子视觉看到 → 逃跑 → 鹰速度快 → 兔子可能被擒

兔子数量的自然平衡:
  兔子太多 → 草地被吃秃 → 兔子饿肚子 → 数量下降
  兔子太多 → 狼更容易猎到 → 狼群壮大 → 兔子被吃得更多 → 数量下降
  兔子太少 → 狼饿肚子 → 狼群萎缩 → 兔子恢复 → 数量上升

  ← 这就是自然界的捕食者-猎物循环
    不需要我们手动控——食物和天敌自动平衡
```

## 九、巢穴的建造

```
兔子窝:
  每只成年兔子自己找个地方挖窝
  选址偏好:
    灌木丛下（隐蔽）→ 优先
    大树根下（有遮挡）→ 可选
    开阔草地（危险！很少选）

  窝的作用:
    - 躲藏（逃避天敌）
    - 生幼崽
    - 睡觉

  多只兔子可能共享一个窝区域——但不是社群，只是碰巧住得近
```
