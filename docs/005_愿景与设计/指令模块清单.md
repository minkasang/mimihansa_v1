## 三、指令模块的通用参数格式

每个指令模块实现时遵循：

```typescript
interface CmdModule {
  name: string;             // 本表中的模块名
  params: Record<string, any>;  // 参数(见各模块声明)
  execute(ctx: ExecutionContext): CmdResult;
}

// ctx 包含：
//   - npc: NPC实例
//   - world: WorldState
//   - rand: 随机数生成器
//   - 其他NPC/物品/建筑的查找函数
```

## 四、优先级建议

| 优先级 | 模块 | 理由 |
|:------|:-----|:-----|
| P0 | cmd_喝水, action_采摘 | 第一天就用到——没有它们阿树活不了 |
| P0 | cmd_生火, cmd_磨石刀 | 文明起点——解锁后续所有工具 |
| P0 | cmd_烤肉, cmd_攻击(最简) | 打猎→食物 |
| P1 | cmd_耕地~收获(5个) | 食物稳定来源——第二年需要 |
| P1 | action_狩猎 | 肉的来源 |
| P1 | cmd_投喂 | 圈养需要 |
| P2 | cmd_建造围栏, cmd_打铁 | 建筑/工具进阶 |
| P2 | cmd_纺线/织布/缝衣 | 服饰产业链 |
| P2 | action_钓鱼, action_驯化 | 补充玩法 |
