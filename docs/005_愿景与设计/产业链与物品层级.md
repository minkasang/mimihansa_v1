# 产业链与物品层级

> 全项目物品的"产源"字典。区分四个层级，每一件物品只在本文件定义"怎么来的"。
> 其他规格书引用物品时，查本表即可，无需重复定义配方。

---

## 一、四个层级

```
层级0 — 自然资源（不靠人出产，大自然就有）
层级1 — 初级加工品（人手+简单工具）
层级2 — 复合制品（多材料+多步骤）
层级3 — 高级制品（需要专业技能/工艺）
```

---

## 二、层级0：自然资源

| 物品 | 如何获取 | 产出形式 |
|:-----|:---------|:---------|
| 木材（原木） | 砍树（用石刀/石斧） | 1棵 → 木材×3~5 |
| 石头 | 捡拾/开采 | 草地/山地捡起 |
| 粘土 | 挖掘 | 河边/低洼地开挖 |
| 水 | 去水域站立→取水 | — |
| 干草 | 草地采集 | 1把 |
| 铁矿 | 挖掘 | 山地有铁矿 |
| 麦种（野麦） | 春天草地采集 | 1处 → 野麦种子×2~3 |
| 棉花 | 种植→收获 | 1株 → 棉花×2 |
| 麻 | 野生/种植 | 采集麻叶→搓绳 |
| 羊毛 | 剪羊 | 1头羊 → 每季1份 |
| 皮革/兔皮 | 打猎→剥皮 | 1只兔 → 1块 |
| 马毛/猪毛 | 集中收集 | 每头马/猪少量 |
| 鸟蛋 | 找/捡巢 | 少数地形 |
| 蜂蜡 | 极难获取（森林深处大树） | 1块 |

## 六、产业链图谱

```
自然资源 → 初级加工 → 复合制品 → 高级制品

木材 → 木棍、木板 ──┬→ 锄头(石)、铲子、镰刀、鱼竿
                    └→ 木桶、篮子

石头 → 石刀 ──→ 石斧、锄头(石)、镰刀、木矛
   └→ 石斧 → 砍树更高效

铁矿 → 铁锭 → 铁钩、铁斧、铁锄头、针、剪刀

干草 → 草绳 → 绳子
麻叶 → 麻绳 → 绳子
毛 → 毛线(纺车) → 粗布(织机) → 粗布衣(针)

棉花 → 棉线(纺车) → 棉布(织机) → 棉布衣(针)

动物 → 皮 → 皮革 → 皮绳
     → 毛 → 毛线
     → 肉 → 烤肉(火堆)
```

## 七、本文档的作用

1. **单一定义**：每一件物品只有这里定义"怎么来的"；其他规格书只引用名称
2. **层级呼应引擎**：公式 `产率 = 天赋系数 × 工具 × 时间` 无须在文档中重写
3. **链断检测**：如果某个环节无人提供原材料→下游全部停工（由市场系统自然处理）
