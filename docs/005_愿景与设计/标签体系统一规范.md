### 3.3 标签更新机制

```javascript
// 每 Tick 刷新标签
function refreshNPCTags(npc) {
    // 1. 清除动态标签（保留静态标签）
    clearDynamicTags(npc);
    
    // 2. 重新计算静态标签
    updateAgeTags(npc);      // 基于 age
    updatePhysiologicalTags(npc);  // 基于 needs
    updateEmotionTags(npc);  // 基于 emotion
    
    // 3. 重新计算动态标签
    updateSocialTags(npc);   // 基于 education, family, home
    updateActionTag(npc);    // 基于 currentAction
    updateCareTag(npc);      // 综合判定 [需要照料]
}

// 事件驱动更新（更高效）
function onEvent(npc, event) {
    switch(event.type) {
        case 'PARENT_DIED':
            refreshOrphanTag(npc);
            break;
        case 'ENROLL_SCHOOL':
            addTag(npc, '[学生]');
            break;
        case 'GRADUATE':
            removeTag(npc, '[学生]');
            break;
        case 'LOSE_HOME':
            addTag(npc, '[流浪者]');
            break;
    }
}
```

### 3.4 标签互斥规则

以下标签**同一时间只能存在一个**：

| 互斥组 | 标签 |
|:-------|:-----|
| 动作状态 | `[战斗中]` `[休息中]` `[忙碌]` `[空闲]` |
| 住所状态 | `[有住所]` `[无住所]` `[流浪者]` |

## 四、标签命名规则（硬约定）

```
1. 标签用中文，加方括号：[标签名]
2. 多词标签用形容词+名词：[野生] ✓ / [野生的] ✗
3. 层级标签用分号层级：[压力:低] [压力:中] [压力:高]
4. 动态参数不写进标签：体温 37°C ✗ → 用实数参数即可
5. 各系统新增标签前 → 先查本表 → 无重复再新注册
```

## 四、已知的标签冗余（已清理）
