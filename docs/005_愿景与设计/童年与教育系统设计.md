## 一、儿童发育阶段（标签过渡）

基于皮亚杰认知发展理论和医学标准，游戏内NPC的成长阶段划分如下：

| 阶段 | 游戏年龄 | 标签 | 决策系统 | 能力边界 |
|:----:|:--------:|:----:|:--------:|:---------|
| **婴儿期** | 0~2岁 | `[婴儿]` | **本能反射** | 只会哭、吃、睡，完全依赖照料。无自主意识，不走GOAP循环 |
| **幼儿期** | 2~6岁 | `[幼儿]` | **简化GOAP** | 能走能跑、会说话、认识父母、简单模仿。欲望库精简，不学复杂技能 |
| **学龄期** | 6~12岁 | `[学龄]` | 标准GOAP | 可以上学、学基础技能、读书 |
| **青少年期** | 13~17岁 | `[青少年]` | 标准GOAP | 学技能速度加快，开始形成独立人格 |
| **成年期** | 18+岁 | `[成年]` | 标准GOAP | 全功能 |

> 标签切换按**固定年龄节点**触发，不依赖其他条件。
> 科学依据：皮亚杰认知发展四个阶段（感知运动0-2岁、前运算2-7岁、具体运算7-11岁、形式运算11岁+）。

### 1.1 决策系统差异总览

| 决策系统 | 适用标签 | 引擎处理方式 |
|:---------|:---------|:------------|
| **本能反射** | `[婴儿]` | 跳过 GOAP 循环。由专门的本能处理步骤（见下方 1.2）接管 |
| **简化GOAP** | `[幼儿]` | 走标准 GOAP 循环，但只加载幼儿欲望库条目（约5-8条） |
| **标准GOAP** | `[学龄]+` | 走标准 GOAP 循环，加载完整欲望库 |

核心原则：**引擎不区分"婴儿"还是"成人"——它只根据标签选择走哪条计算路径。欲望库条目的数量决定了行为复杂度。**

### 1.2 婴儿本能反射（0~2岁）

> 婴儿没有"选择"、"规划"、"效用打分"——生理状态直接驱动行为。

```
每 Tick 对标签包含 [婴儿] 的 NPC：

  ⚠️ v3.0 重大修正：婴儿不跳过 Step 2（感知）和 Step 3（生理）——
  他有眼睛有耳朵，从出生起就在积累人脸记忆和知识库。
  他只是不做 GOAP 决策（跳过 Step 4 和 Step 5）。

  Step 2（感知）→ 正常走:
    婴儿看到周围的人 → 引擎匹配辨识符 → 写入知识库
    ← 这让婴儿在0~2岁期间就学到了"这个人是经常喂我的"、
      "那个人抱过我"——到2岁幼儿期开始GOAP时，
      他的知识库已经积累了足够的信息来触发 want_stay_near_parent。
  
  Step 3（生理推演）→ 正常走:
    婴儿.饥饿度、疲劳度自然上升 → 为 Step 3.5 提供基础

  Step 3.5（本能反应）→ 接管:
    检查生理状态，按优先级触发本能动作：
  
  优先级1（最高）：饥饿
    饥饿度 > 5 → 执行: 哭
      - 产生听觉事件 { 类型:"婴儿哭声", 来源:npc_id, 半径:30+10格 }
      - 持续直到被喂饱或累到睡着
  
  优先级2：疲劳
    疲劳度 > 7 → 执行: 睡觉
      - 原地躺下/闭眼
      - 每 Tick: 精力 +2, 疲劳度 -0.5
      - 睡到疲劳度 < 3 或饥饿度 > 8（饿醒了）
  
  优先级3：身体不适
    健康值 < 5 或 压力值 > 7 → 执行: 哭
      - 与饥饿哭声不同（可能需要辨别的逻辑——但不影响当前范围）
  
  优先级4：其他不适
    任何生理状态异常 → 执行: 哭

  默认状态（没有任何不适）：
    执行: 睡觉或发呆
  
  本能反应规则:
    - 没有"欲望选择"——哪个生理需求最紧迫就触发哪个
    - 没有"规划"——只在原地执行单一动作
    - 没有"目标"——本能动作不计入 GOAP 目标队列
    - 哭是"产生事件"的动作，影响周围 NPC 的 Step 2 感知
```

### 1.3 幼儿简化GOAP（2~6岁）

> 幼儿走标准 GOAP 循环，但只加载幼儿专属的欲望库条目。引擎不用改代码——只改 JSON 配置。

```
幼儿欲望库加载的条目（约5-8条）:

  want_eat            ← 饿了知道要吃的（但不能自己做，只能找妈妈/吃现成的）
  want_play           ← 想玩耍（幼儿的核心活动）
  want_stay_near_parent ← 跟在父母附近（安全感需求，← 幼儿期特有）
  want_sleep          ← 困了知道要睡
  want_imitate        ← 看大人做什么就模仿（学习技能的前身，← 幼儿期特有）
  want_talk           ← 想说话（语言发展期，← 幼儿期特有）
  want_explore_near   ← 探索附近（2-3格内走走看看，但不能跑太远）
  want_drink          ← 口渴了知道要喝水

不加载的成人欲望:
  want_work, want_build, want_hunt, want_craft
  want_court, want_marry, want_trade, want_govern
  ...（全部成人欲望都不加载）
```

幼儿的技能学习速度（年龄系数=0.2，见 §二 学习速度公式）极低，所以即使他有 `want_imitate` 触发了模仿行为，实际技能增长也微乎其微——这才是符合现实的。

### 1.4 幼儿如何"认识"父母

这个过程完全由信息壁垒 + 辨识符机制 + 幼儿简化GOAP 驱动，不需要系统告知：

```
幼儿 Step 2（感知）:
  每天看到的都是同一个女人给自己喂食物、抱着自己
  → 引擎内存映射: system_id=npc_mother → 幼儿辨识符=r_001
  
幼儿知识库中 r_001 条目的自然演化:
  第1年:
    { 辨识符: "r_001", 称呼: "喂我的人", 标签: ["给我吃的"] }
  
  第2年（开始有语言了）:
    幼儿 want_talk 触发 → 尝试称呼这个人
    如果母亲教他"叫妈妈" → 称呼进化为 "妈妈"
    如果没教 → 可能称呼进化为 "那个经常喂我的人"
    总之称呼取决于互动内容
    
  第3-4年:
    { 辨识符: "r_001", 称呼: "妈妈", 
      标签: ["妈妈", "经常喂我", "会抱我", "会讲故事"],
      我知道的事: ["妈妈说爸爸去山上打猎了"]
    }
```

## 二、智力发育与学习速度

### 2.1 科学背景
- 0~3岁：大脑发育黄金期，神经连接高速建立
- 6~12岁（学龄期）：学习能力快速上升期
- 20~30岁：智力巅峰（韦氏智力测量峰值区间）
- 30岁后：经验/见识继续上升，反应速度微降

### 2.2 学习速度公式

```
学习速度(技能X) = 该技能对应的天赋 × 年龄系数 × 书生气加成

天赋映射（不同技能有不同天赋）：
  农业技能    → 天赋_力量 × 0.5 + 天赋_智商 × 0.5
  锻造技能    → 天赋_手工
  交易技能    → 天赋_社交 × 0.5 + 天赋_智商 × 0.5
  医术技能    → 天赋_智商
  建筑技能    → 天赋_力量 × 0.4 + 天赋_手工 × 0.6
  战斗技能    → 天赋_力量 × 0.7 + 天赋_手工 × 0.3
  教学技能    → 天赋_社交 × 0.6 + 天赋_智商 × 0.4
  （天赋值来自NPC参数总表"九、天赋参数"）

年龄系数：
  0~2岁   → 0.0
  2~6岁   → 0.2
  6~12岁  → 0.6
  13~17岁 → 0.8
  18~30岁 → 1.0
  30~50岁 → 0.9
  50+岁   → 0.6

书生气加成（乘法）：
  书生气 = 0 → 加成 = 1.0
  书生气 = 5 → 加成 = 1.0 + 0.025 = 1.025
  书生气 = 10→ 加成 = 1.0 + 0.05 = 1.05
  公式：书生气加成 = 1.0 + (书生气 / 10) × 0.05
```

## 三、上学决策

### 3.1 先决条件
孩子到6岁（进入学龄期）时，检查：
- **附近是否有学校/学堂？**
  - "附近" = 同村(建筑归属同一村落ID)内 OR 步行距离<50格
  - ❌ 没学校 → 上不了学（可能自学或放弃）
  - ✅ 有学校 → 进入父母决策流程

### 3.2 父母决策公式（量化打分）

```
送上学得分 = Σ(各因素得分 × 权重)

因素1：责任心（道德水准_规则遵守）
  责任心 × 8  → 最高80分

因素2：经济条件
  家庭金钱 >= 学校学费×12(一年学费) → 80分
  家庭金钱 >= 学校学费×3  → 40分
  家庭金钱 < 学校学费×1  → 0分

因素3：认知水平（智商 × 0.4 + 书生气 × 0.4 + 知识库丰富度 × 0.2）
  // 知识库丰富度 = min(已知地点数/20, 1) × 10，用来代理"见识"
  计算值≥7 → 80分（知道读书有用）
  计算值4-6→ 40分
  计算值<4 → 0分（觉得读书没用）

因素4：自私程度（反向打分）
  selfishScore = max(财富态度_获取欲望, (10-道德水准_利他意愿))
  selfishScore≤3 → 50分（不自我，愿意为孩子付出）
  selfishScore4-6→ 30分
  selfishScore≥7→ 0分（自私，只想让孩子早点赚钱）

权重：
  责任心  × 0.3
  经济    × 0.35
  认知    × 0.2
  自私(反向)× 0.15

最终得分 >= 50 → 送孩子上学 ✅
最终得分 < 50 → 不送（去干活）❌
```

### 3.3 学费设计
- 学费由学校/教师设定（也是NPC定价行为的一部分）
- 学校有两种类型：
  - **公立学校**：政府出资/补贴，学费低廉或免费，由政府指派教师
  - **私立学校**：个人开办，学费由开办者自定（受其性格影响）
- 初始状态下，政府可能预设少量公立学校作为基础设施
- NPC可以将学费信息贴在公示栏上

## 四、学校系统

### 4.1 学校的建立
- 学校是一个**建筑**（需要有人建造）
- 需要有人担任**教师**（职业）
- 没有教师 → 学校等于空建筑
- 学校的容量有限（**默认1个老师最多教15个学生**，可在建筑配置中调整）
- 学生数超过容量 → 需要再招老师或建新校

### 4.2 上学的过程
- 学龄期孩子每天去学校
- 在学校里由教师引导学习
- 学习效果受**教师的教学技能**影响（好老师教得好）
- 上学期间可能结交朋友（同龄人社交）

### 4.3 上学的效果
- 基础技能提升（阅读、计算、见识）
- 书生气缓慢积累（比自学慢但更系统）
- 可能触发特定的事件（校园事件）

## 五、读书系统

### 5.1 书是什么
- 书是一个**物品**，属于商品
- 书有不同类型：教材、文学、知识等
- 书籍需要生产（造纸→印刷→装订）
- 书籍可以在书店购买，也可以借阅

### 5.2 阅读行为
- NPC拥有书 → 执行"阅读"动作
- 阅读需要消耗**游戏内时间**
  - 教材类：20游戏小时/本（约2-3天，业余时间读）
  - 文学类：15游戏小时/本（读得快）
  - 知识类：30游戏小时/本（需要消化）
  - 智商越高，阅读越快：实际用时 = 标准用时 × (10 / 智商)
- 阅读的进度受**智商**影响（智商高读得快）
- 阅读的效果：
  - 书生气 +0.1~0.3（依书的类型和质量）
  - 教材类 → 对应技能少量提升
  - 知识类 → 知识库增加
  - 文学类 → 开心值上升

### 5.3 书生气
- **来源**：读书（阅读书籍），不是上学
- 学校本身不增加书生气——上学只是因为学校里有书读
- 没上过学但自学读书的人，书生气同样会增长
- 书生气是一种**气质**，影响他人对NPC的感知：
  - 某些异性可能偏好"有书卷气"的人
  - 书生气高的NPC在社交中可能获得额外好感
  - 书生气高 ≠ 智商高，但有助于学习速度

## 六、同龄人影响（量化）

```
孩子在感知范围内扫描同龄人：
  同龄人范围：同村/同街区内，年龄差距<3岁的其他孩子

计算"上学率"：
  同龄人中上学者数量 / 同龄人总数
  
  上学率 >= 0.5 → 产生同龄人正面影响"同龄人都上学我也想上"
  上学率 < 0.5 → 产生同龄人负面影响"同龄人都干活那我也不上了"

该影响作为上学决策的修正项（不是进入欲望竞争的独立欲望）：
  正面影响 → 上学决策最终得分+10
  负面影响 → 上学决策最终得分-10
```
