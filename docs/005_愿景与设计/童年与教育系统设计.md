## 一、儿童发育阶段（标签过渡）

基于皮亚杰认知发展理论和医学标准，游戏内NPC的成长阶段划分如下：

| 阶段 | 游戏年龄 | 标签 | 认知特征 | 能力边界 |
|:----:|:--------:|:----:|:---------|:---------|
| **婴儿期** | 0~2岁 | `[婴儿]` | 仅有感知和本能反应 | 只会哭、吃、睡，完全依赖照料 |
| **幼儿期** | 2~6岁 | `[幼儿]` | 开始有语言和基本认知，以自我为中心 | 能走能跑，但不能独立学习复杂技能 |
| **学龄期** | 6~12岁 | `[学龄]` | 逻辑思维开始形成 | 可以上学、学基础技能、读书 |
| **青少年期** | 13~17岁 | `[青少年]` | 抽象思维能力发展，接近成人 | 学技能速度加快，开始形成独立人格 |
| **成年期** | 18+岁 | `[成年]` | 智力巅峰（20~30岁为最高） | 全功能 |

> 标签切换按**固定年龄节点**触发，不依赖其他条件。
> 科学依据：皮亚杰认知发展四个阶段（感知运动0-2岁、前运算2-7岁、具体运算7-11岁、形式运算11岁+）。

## 二、智力发育与学习速度

### 2.1 科学背景
- 0~3岁：大脑发育黄金期，神经连接高速建立
- 6~12岁（学龄期）：学习能力快速上升期
- 20~30岁：智力巅峰（韦氏智力测量峰值区间）
- 30岁后：经验/见识继续上升，反应速度微降

### 2.2 学习速度公式

```
学习速度(技能X) = 该技能对应的天赋 × 年龄系数 × 书生气加成

天赋映射（不同技能有不同天赋）：
  农业技能    → 天赋_力量 × 0.5 + 天赋_智商 × 0.5
  锻造技能    → 天赋_手工
  交易技能    → 天赋_社交 × 0.5 + 天赋_智商 × 0.5
  医术技能    → 天赋_智商
  建筑技能    → 天赋_力量 × 0.4 + 天赋_手工 × 0.6
  战斗技能    → 天赋_力量 × 0.7 + 天赋_手工 × 0.3
  教学技能    → 天赋_社交 × 0.6 + 天赋_智商 × 0.4
  （天赋值来自NPC参数总表"九、天赋参数"）

年龄系数：
  0~2岁   → 0.0
  2~6岁   → 0.2
  6~12岁  → 0.6
  13~17岁 → 0.8
  18~30岁 → 1.0
  30~50岁 → 0.9
  50+岁   → 0.6

书生气加成（乘法）：
  书生气 = 0 → 加成 = 1.0
  书生气 = 5 → 加成 = 1.0 + 0.025 = 1.025
  书生气 = 10→ 加成 = 1.0 + 0.05 = 1.05
  公式：书生气加成 = 1.0 + (书生气 / 10) × 0.05
```

## 三、上学决策

### 3.1 先决条件
孩子到6岁（进入学龄期）时，检查：
- **附近是否有学校/学堂？**
  - "附近" = 同村(建筑归属同一村落ID)内 OR 步行距离<50格
  - ❌ 没学校 → 上不了学（可能自学或放弃）
  - ✅ 有学校 → 进入父母决策流程

### 3.2 父母决策公式（量化打分）

```
送上学得分 = Σ(各因素得分 × 权重)

因素1：责任心（道德水准_规则遵守）
  责任心 × 8  → 最高80分

因素2：经济条件
  家庭金钱 >= 学校学费×12(一年学费) → 80分
  家庭金钱 >= 学校学费×3  → 40分
  家庭金钱 < 学校学费×1  → 0分

因素3：认知水平（智商 × 0.4 + 书生气 × 0.4 + 知识库丰富度 × 0.2）
  // 知识库丰富度 = min(已知地点数/20, 1) × 10，用来代理"见识"
  计算值≥7 → 80分（知道读书有用）
  计算值4-6→ 40分
  计算值<4 → 0分（觉得读书没用）

因素4：自私程度（反向打分）
  selfishScore = max(财富态度_获取欲望, (10-道德水准_利他意愿))
  selfishScore≤3 → 50分（不自我，愿意为孩子付出）
  selfishScore4-6→ 30分
  selfishScore≥7→ 0分（自私，只想让孩子早点赚钱）

权重：
  责任心  × 0.3
  经济    × 0.35
  认知    × 0.2
  自私(反向)× 0.15

最终得分 >= 50 → 送孩子上学 ✅
最终得分 < 50 → 不送（去干活）❌
```

### 3.3 学费设计
- 学费由学校/教师设定（也是NPC定价行为的一部分）
- 学校有两种类型：
  - **公立学校**：政府出资/补贴，学费低廉或免费，由政府指派教师
  - **私立学校**：个人开办，学费由开办者自定（受其性格影响）
- 初始状态下，政府可能预设少量公立学校作为基础设施
- NPC可以将学费信息贴在公示栏上

## 四、学校系统

### 4.1 学校的建立
- 学校是一个**建筑**（需要有人建造）
- 需要有人担任**教师**（职业）
- 没有教师 → 学校等于空建筑
- 学校的容量有限（**默认1个老师最多教15个学生**，可在建筑配置中调整）
- 学生数超过容量 → 需要再招老师或建新校

### 4.2 上学的过程
- 学龄期孩子每天去学校
- 在学校里由教师引导学习
- 学习效果受**教师的教学技能**影响（好老师教得好）
- 上学期间可能结交朋友（同龄人社交）

### 4.3 上学的效果
- 基础技能提升（阅读、计算、见识）
- 书生气缓慢积累（比自学慢但更系统）
- 可能触发特定的事件（校园事件）

## 五、读书系统

### 5.1 书是什么
- 书是一个**物品**，属于商品
- 书有不同类型：教材、文学、知识等
- 书籍需要生产（造纸→印刷→装订）
- 书籍可以在书店购买，也可以借阅

### 5.2 阅读行为
- NPC拥有书 → 执行"阅读"动作
- 阅读需要消耗**游戏内时间**
  - 教材类：20游戏小时/本（约2-3天，业余时间读）
  - 文学类：15游戏小时/本（读得快）
  - 知识类：30游戏小时/本（需要消化）
  - 智商越高，阅读越快：实际用时 = 标准用时 × (10 / 智商)
- 阅读的进度受**智商**影响（智商高读得快）
- 阅读的效果：
  - 书生气 +0.1~0.3（依书的类型和质量）
  - 教材类 → 对应技能少量提升
  - 知识类 → 知识库增加
  - 文学类 → 开心值上升

### 5.3 书生气
- **来源**：读书（阅读书籍），不是上学
- 学校本身不增加书生气——上学只是因为学校里有书读
- 没上过学但自学读书的人，书生气同样会增长
- 书生气是一种**气质**，影响他人对NPC的感知：
  - 某些异性可能偏好"有书卷气"的人
  - 书生气高的NPC在社交中可能获得额外好感
  - 书生气高 ≠ 智商高，但有助于学习速度

## 六、同龄人影响（量化）

```
孩子在感知范围内扫描同龄人：
  同龄人范围：同村/同街区内，年龄差距<3岁的其他孩子

计算"上学率"：
  同龄人中上学者数量 / 同龄人总数
  
  上学率 >= 0.5 → 产生同龄人正面影响"同龄人都上学我也想上"
  上学率 < 0.5 → 产生同龄人负面影响"同龄人都干活那我也不上了"

该影响作为上学决策的修正项（不是进入欲望竞争的独立欲望）：
  正面影响 → 上学决策最终得分+10
  负面影响 → 上学决策最终得分-10
```
