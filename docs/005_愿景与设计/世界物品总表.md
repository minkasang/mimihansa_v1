# 世界物品总表 —— 所有可交互对象的属性字典

> 本文档汇总这个世界里**所有物品**及其属性。新增物品时先查此表。
> ⚠️ 规范研究文档。部分物品已有数据，部分为"预留占位"，后续讨论时填充。

## 物品的基础属性格式

每个物品应包含以下基础字段：

| 字段 | 类型 | 说明 |
|:----:|:----:|------|
| 物品id | 字符串 | 唯一标识 |
| 名称 | 字符串 | 显示用名称 |
| 描述 | 字符串 | 简要说明 |
| 类型 | 枚举 | 物品大类 |
| 标签 | 字符串[] | 属性标签，用于AI匹配 |
| 基础价格 | 数字 | 默认交易价格（铜板），仅为初始参考值，实际由市场定价 |
| 可堆叠 | bool | 是否能多个叠在一起 |
| 耐久度 | 1-100 或 ∞ | 使用寿命（消耗品为∞/1次） |
| 重量/体积 | 1-10 | 影响携带数量 |
| 可制作 | bool | 是否能由NPC制作 |
| 配方 | 对象 | 制作所需材料+时间（如可制作） |
| 效果 | 对象 | 使用后的效果，**统一数据结构**为：`{"参数名": 变化值}` |

### 效果字段统一格式

所有物品的"效果"使用相同的数据结构，方便程序读取：

```json
// 食物示例
"效果": {"饥饿": -3, "开心": 1}

// 药品示例  
"效果": {"健康": 5}

// 书籍示例
"效果": {"书生气": 0.2}

// 复合效果
"效果": {"饥饿": -5, "开心": 2, "疲劳": -1}
```

参数名必须与NPC参数总表中的参数名一致。

**书籍的特性：**
- 书籍是**可阅读的物品**——和吃东西不同，阅读需要消耗游戏内时间
- 书可被**多次阅读**（温故知新），但书生气只在第一次阅读时增加
- 书籍可以被**抄写**（技能高的NPC可以复制书籍）
- 书籍可以被**买卖**、**收藏**、**赠送**
- 如果世上没有书，NPC就无法通过读书获得书生气
