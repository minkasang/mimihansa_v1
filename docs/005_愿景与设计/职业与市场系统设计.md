## 一、核心原则

### 1.1 职业不是性格决定的
一个人选择某个职业，**不取决于他"应该"具备什么性格**，而是：

| 选择动机 | 说明 | 例子 |
|:---------|:-----|:-----|
| **压力回避** | 不想承受高压 → 选压力低的职业 | 有人当老师是因为有寒暑假、压力小 |
| **收入追求** | 想赚钱 → 选收入高的职业 | 有人做高风险生意 |
| **离家近** | 不想远行 → 选离家近的工作 | 很多人不想出远门 |
| **兴趣/理想** | 就是喜欢这个行业 | 理想主义者 |
| **没得选** | 只有这个工作机会 | 被迫选择 |
| **门槛限制** | 学历/技能不够，进不了别的行业 | 只能做体力活 |

### 1.2 用标签体系代替性格绑定
每个职业打上**通用标签**，NPC根据自己的性格+需求去匹配，而不是为每个职业写一套性格条件。

### 1.3 经济是涌现的，不是写死的
价格、供需、工资全部由NPC自己的行为自发形成。引擎只提供"每个商人自己算账"的机制，不预设任何均衡价格。

## 二、职业标签体系

### 2.1 职业的通用标签

| 标签维度 | 取值范围 | 说明 |
|:---------|:--------|:-----|
| `[压力: 低/中/高]` | 低、中、高 | 职业的精神压力大小 |
| `[收入: 低/中/高]` | 低、中、高 | 收入水平（平均参考值） |
| `[门槛: 低/中/高]` | 低、中、高 | 需要学历/技能吗 |
| `[社交: 低/中/高]` | 低、中、高 | 需要与人打交道吗 |
| `[体力: 低/中/高]` | 低、中、高 | 体力消耗程度 |
| `[兴趣标签]` | 自由文本 | 如 `[农业]` `[教育]` `[商业]` |

> ⚠️ **注意**：`[离家远近]` **不是职业的固有标签**。离家远近 = NPC的家坐标 ↔ 工作场所坐标的实际距离，是计算值。
> 本村人做本村的工作 → 离家近；外村人来打工 → 离家远。

### 2.2 示例职业的标签

| 职业 | 压力 | 收入 | 门槛 | 社交 | 体力 | 兴趣标签 |
|:----|:----:|:----:|:----:|:----:|:----:|:---------|
| **教师** | 低 | 中 | 中 | 高 | 低 | `[教育]` |
| **农民** | 低 | 低 | 低 | 低 | 高 | `[农业]` |
| **商人** | 中 | 高 | 中 | 高 | 低 | `[商业]` |
| **工匠** | 中 | 中 | 中 | 低 | 中 | `[制作]` |
| **矿工** | 高 | 中 | 低 | 低 | 高 | `[采矿]` |
| **医生** | 高 | 高 | 高 | 高 | 低 | `[医术]` |
| **官员** | 高 | 高 | 高 | 高 | 低 | `[管理]` |
| **士兵** | 高 | 中 | 低 | 中 | 高 | `[战斗]` |
| **作家** | 低 | 低 | 中 | 低 | 低 | `[文学]` |

| **伐木工** | 低 | 低 | 低 | 低 | 高 | `[林业]` |

### 2.3 NPC的择业逻辑（被动信息获取！）

```
⚠️ NPC不是全知全能的——他们只能通过自己知道的信息来找工作

NPC到了就业年龄（约16~18岁）
  ↓
Step 1：收集自己知道的就业信息（仅限于NPC知识库中的信息）
  来源：
    a) 看过公示栏 → 记住了哪些机构在招人
    b) 朋友/家人告诉的 → 社交网络中传播的招聘资讯
    c) 自己路过时看到的 → 感知范围内看到的店铺招牌/门口招工牌
    d) 继承家业 → 自动知道家族生意

Step 2：对每个已知的职业空缺打分（根据NPC的性格+需求）：
  评分维度：
    - 压力匹配度：胆小/求稳 → [压力低]加分，胆大/野心 → 无所谓
    - 离家匹配度：计算家坐标↔工作场所的 A* 路径距离（不是直线距离）
      → 路径距离<50格：+30分
      → 路径距离50-200格：0分
      → 路径距离>200格：-20分（太远了，可能需要租房）
    - 收入匹配度：贪婪/野心 → [收入高]加分，知足 → 无所谓
    - 门槛匹配度：所需技能/学历 > NPC当前水平 → 过滤掉
    - 兴趣匹配度：有对应[兴趣标签] → +20分
  ↓
Step 3：选择得分最高的职业
  ↓
Step 4：如果没有可用的就业信息 → 生成欲望"want_find_job"
  → 去看公示栏 / 向熟人打听 / 上门问 / 无所事事

### 2.4 NPC可以打多份工
- 只要时间/精力允许，NPC可以同时做多份工作
- 精力是有限的——做一份工消耗体力，做两份工消耗更多
- 如果精力耗尽 → 效率下降，可能出错/生病
- 所以虽然"可以"打多份工，但大多数NPC会选择一份主职

## 三、NPC的"家"与工作距离

### 3.1 "家"的定义

| NPC状态 | 家的定义 | 说明 |
|:--------|:---------|:-----|
| **未成年人（<18岁）** | 父母的房子 | 和父母一起住 |
| **成年人，未结婚** | 父母的房子 或 自己租/买的房子 | 可能搬出去独立 |
| **已婚** | 自己和配偶的房子 | 婚后另立门户 |
| **无房** | 没有"家"属性 | 流浪汉，住在野外/桥洞 |

### 3.2 工作距离的计算
```
工作距离 = 家的坐标 ↔ 工作场所坐标 的路径距离

对NPC决策的影响：
  距离近 → 通勤时间短，方便 → 加分
  距离远 → 通勤时间长，消耗精力 → 减分
  远到一定程度 → 需要在外租房/买房
```

### 3.3 租房与买房
- 去外村打工 → 大概率需要租房
- 租房需要付租金 → 增加生活成本
- 租金受地段影响（村中心和边缘价格不同）
- 租金受供需影响（问的人多 → 房东涨价，租不出去 → 降价）
- 有钱的NPC可以选择直接买房

### 3.4 房子是怎么来的
- NPC可以**自己动手搭建**小房子（需要材料+时间+基础建筑技能）
- NPC也可以**请专业的建筑队**（有建筑技能的人）建造更高级的房子
- 高级房子需要更多、更好的材料（砖头、木材、石材等）
- 材料的供应本身也是一条产业链

## 四、NPC找工作方式

| 方式 | 说明 |
|:----|:------|
| **告示栏/公示栏** | 村庄/城镇里设置的公共设施，老板贴招人启事 |
| **熟人介绍** | 朋友/亲戚介绍工作（通过社交网络传播） |
| **自己上门** | 直接去店铺/作坊问"招不招人" |
| **继承** | 子承父业（父母是工匠，孩子自然学手艺） |
| **自己创业** | 有资本 → 自己开店当老板 |

### 4.1 公示栏（读写双向——任何NPC都可以贴和看）

公示栏是一个**公共信息板**，任何NPC都可以在上面：
- **贴信息**（发布）：招人、买卖、打听消息、任务悬赏……
- **看信息**（读取）：获取别人贴的信息

但——NPC贴不贴、贴什么，受性格影响。有人什么都敢公开说，有人不愿意让别人知道自己的事。

#### 4.1.1 发布行为：什么样的人会去贴？

```
NPC有需求 → 决定是否去公示栏发布

需求类型（要发布的内容）：
  招人     → 老板缺员工，公事公办
  买卖     → 有东西要卖/想收东西
  打听消息 → 想知道某人/某地的信息
  发布任务 → 想雇人做某件事
  发布公告 → 想通知全村某件事（如"明日我家办喜事"）

发布意愿 = 需求紧迫度 × 性格公开度

性格公开度（影响"愿不愿意公开说"）：
  社交属性_自我坦露 × 0.5  // 坦露度高 = 不怕公开
  人际关系_猜疑程度(反向) × 0.3  // 多疑的人怕被人盯上
  + (1 - 胆魄气量_风险规避/10) × 0.2  // 谨慎的人不会什么都往外说

  如果需求涉及个人隐私（如打听某人/表白/求救）：
    → 性格公开度 × 0.5（更害羞）
  
  如果需求是纯商业行为（招工/买卖）：
    → 不受影响，公事公办

发布判定：
  if 发布意愿 > 0.6:
    去公示栏贴信息（消耗少量时间）
  else:
    不贴——换其他方式（如托熟人打听、自己上门）
```

#### 4.1.2 公示栏上的信息类型

| 信息类型 | 发布者 | 示例内容 |
|:---------|:-------|:---------|
| `[招工]` | 老板/作坊主 | "本店招伙计1名，月薪XX铜板" |
| `[买卖]` | 商人/农民 | "高价收木材" / "低价卖苹果" |
| `[打听]` | 任何人 | "谁知道XX在哪儿？" / "谁认识XX？" |
| `[任务]` | 任何人 | "帮我建个房子，酬劳XX铜板" |
| `[公告]` | 任何人 | "本周六村口集会" / "我家丢了东西" |

#### 4.1.3 读取行为：什么样的人会去看？

```
NPC查看公示栏的驱动力 = 需求紧迫度 × 性格主动性

需求紧迫度（取最高的一项）：
  NPC正在找工作（就业需求）      → 100分
  NPC想买某样东西但不知道去哪买  → 70分
  NPC想卖东西找买家             → 60分  
  NPC只是好奇                   → 30分
  NPC什么都不需要               → 0分

性格主动性（受以下维度影响）：
  外显活力_行动意愿 × 0.5    // 勤奋的人主动
  情绪基调_积极倾向 × 0.3    // 乐观的人主动
  行事风格_决策模式 × 0.2    // 理性的人会主动收集信息

最终查看概率 = (驱动力 / 100) × 性格主动性 / 10

更新频率：
  驱动力=100(急需) → 每天看一次
  驱动力=50-60 → 每3天看一次
  驱动力=0-30 → 每周看一次（随便瞥一眼）
```

#### 4.1.4 没有公示栏的村子
- 信息流通更慢，主要靠**熟人介绍**和**口口相传**
- NPC想发布信息？只能挨个去问、去告诉

### 4.2 机构能容纳多少员工
- 每个店铺/作坊有**最大员工容量**（由规模和设备决定）
- 需要提前设定好（比如：一个小造纸坊最大3人）
- 员工数量 = 按需分配：生产多少书需要多少人
- 如果需求下降 → 裁员；需求上升 → 扩招

## 五、老板的性格与定价（核心机制！）

### 5.1 影响定价的性格维度（全部来自34维系统，无新增）

| 性格维度 | 偏向 | 对定价的影响 |
|:---------|:----|:------------|
| **财富态度_获取欲望（贪婪）** | 高 | 利润空间大，定价高 |
| | 低 | 赚够就行，定价平实 |
| **道德水准_利他意愿（善良）** | 高 | 体谅顾客，定价偏低，可能给穷人打折 |
| | 低 | 无所谓，按市场最高价走 |
| **胆魄气量_风险规避（谨慎）** | 高 | 定价保守，不敢太高也不敢太低，求稳 |
| | 低 | 敢定高价赌利润，也敢降价冲销量 |
| **胆魄气量_无畏程度（大胆）** | 高 | 敢要高价，不怕卖不出去 |
| | 低 | 定价偏低怕压货 |
| **行事风格_决策模式（理性）** | 高 | 根据成本和供需精确计算，定价合理 |
| | 低 | 凭感觉、拍脑袋定价 |
| **情绪基调_情绪稳定性** | 高 | 价格稳定，不受短期情绪影响 |
| | 低 | 容易波动（被顾客气到→涨价，心情好→打折） |
| **社交属性_控制欲** | 高 | 喜欢掌控市场，可能搞垄断/联手抬价 |
| | 低 | 随行就市 |

### 5.2 个性化定价公式

```
NPC商人的最终定价 = 进货成本 × (1 + 期望利润率)

期望利润率 = 基础利润率(20%) + 性格修正（各项叠加）

性格修正参考值（举例）：
  贪婪 ≥ 8  → +15%
  贪婪 ≤ 3  → -5%
  善良 ≥ 7  → -10%
  风险规避 ≥ 7 → 0%（求稳，不加也不减）
  大胆 ≥ 7  → +10%
  理性 ≥ 7  → 根据库存和近期销量动态调价
  情绪稳定性 ≤ 3 → ±5%随机波动（看心情）
  控制欲 ≥ 7  → +8%（想多赚）

示例对比：
  奸商（贪婪8，大胆7，理性3）：
  利润率 = 20% + 15% + 10% = 45%
  进货价2铜板的苹果 → 卖2.9铜板（≈3铜板）

  良心商人（善良8，谨慎7，理性7）：
  利润率 = 20% - 10% = 10%
  进货价2铜板的苹果 → 卖2.2铜板
```

### 5.3 成本核算
- 如果商人自己生产商品 → 成本 = 原材料 + 人工 + 设备折旧
- 如果商人进货转卖 → 成本 = 进货价 + 运输费
- 商人需要算清楚成本才能定出不会亏本的价格
- 需要一个**成本核算器**（引擎机制，不是玩家手动算）

## 六、市场价格波动（价格信号驱动供需）

### 6.1 核心原则
- **价格不是写死的**——每个商人根据自己的成本和库存独立定价
- 没有一个中央系统在调价，是千千万万个商人的个体行为→宏观价格
- 价格更新频率：**至少一周（游戏内）更新一次**，避免频繁波动

### 6.2 价格更新频率与时机
- 价格**至少一周（游戏内）更新一次**，不是每天更新
- 每个商人有一个"下次定价日"字段
  - 初始随机分配在7天内的某一天（避免所有商人在同一天同时算账，避免性能尖刺）
  - 到了定价日 → 自动触发成本核算 + 重新定价
- 特殊触发：如果进货成本发生了剧烈变化（>30%变动），可以提前触发一次紧急调价

### 6.3 成本核算器（引擎机制）

```
// 每次定价日调用此函数，计算单件商品的成本

function 计算单位成本(商人NPC, 商品):
  单位成本 = 0
  
  // 1. 原材料成本
  if 商人是生产者（自己生产商品）:
    单位成本 += Σ(每种原材料.最近进价 × 单件消耗量)
    单位成本 += 设备折旧费  // 固定值，可在JSON中配置
  else 商人是中间商（进货转卖）:
    单位成本 += 最近一次进货单价
  
  // 2. 人工成本（摊到单件）
  单位成本 += (月工资总额 / 月均产量)

  // 3. 租金（如果租店铺）
  if 店铺非自有:
    单位成本 += (月租金 / 月均产量)

  // 4. 运输成本（从外村进货）
  if 进货源头 != 本地:
    单位成本 += 距离系数 × 固定运费率

  return 单位成本

// 最终定价公式（§5.2风格的统一版）
最终定价 = 单位成本 × (1 + 期望利润率)
其中期望利润率由 NPC 性格决定（见 §5.2）
```

### 6.4 价格波动的自发起源

```
场景：苹果丰收年

农民A收获了大量苹果 → 库存多 → 降价出售
  ↓
商店进货价变低 → 零售价也降低
  ↓
消费者看到苹果便宜 → 更多NPC买苹果 → 需求上升
  ↓
部分农民看到种苹果利润变低 → 明年少种苹果，改种小麦
  ↓
苹果供给减少 → 价格回升 → 新的平衡
```

### 6.5 产业链断链的自修复（涌现式调节 + 被动信息传递）

⚠️ 重要：NPC不会"自动知道"上游涨价了，必须通过交易行为被动发现。

```
木材断货了
  ↓
造纸坊去进木材 → 发现"没有货"或"价格涨了很多"
  ├─ 这是被动获得的——造纸坊只有在进货时才发现
  └─ 造纸坊把"木材紧缺"记入自己的知识库
  ↓
造纸坊无法正常生产 → 纸产量下降
  ↓
书局去进纸 → 发现纸变贵/变少了（被动发现）
  ↓
书局的书产量下降 → 零售渠道的书变少
  ↓
消费者在书店发现：书变贵了（被动发现价格变化）
  ↓
信息沿着交易链一层层往上传递：
  消费者愿意高价买 → 书店高价进 → 出版商高价买纸 → 造纸坊高价收木
  ↓（信息每一层都是通过实际交易才传递的，不是广播）
  
伐木工在公示栏看到/朋友听说：木材厂高价收木材！
  ↓
高薪吸引NPC去伐木
  ↓
木材供给恢复 → 价格回落
```

关键：信息不是广播的。NPC B只有在去和NPC A交易时，才会发现A的价格变了。

## 七、工资与雇佣

### 7.1 老板与员工
- 每个生产机构/店铺有**所有者**（老板）
- 老板可以**雇佣**其他NPC（数量取决于规模和需求）
- 员工数量根据产量需求动态调整

### 7.2 工资决定
```
工资水平由以下因素决定：
  - 老板的性格（大方→工资高，贪婪→工资低）
  - 店铺盈利能力（赚钱多→工资可以高）
  - 劳动力市场竞争（附近缺人→工资涨，人多→工资降）
  - 职业门槛（门槛高的职业→工资高）
  - 产业链传导（下游愿意高价收货→上游利润好→能给更高工资）

如果工资太低 → 员工可能离职/偷东西/抗议
如果工资太高 → 老板利润下降，可能裁员
如果某个环节利润极高 → 更多NPC想进入这个行业
```

### 7.3 裁员与扩招
- 需求下降 → 生产减少 → 裁员
- 需求上升 → 扩招
- 被裁的NPC → 找新工作或做临时工

### 7.4 员工行为（程序化判定）

**离职：**
```
离职概率 = clamp(基础率(5%) + 不满意度 × 10%, 5%, 80%)

不满意度（范围0~5，各项累加）：
  // 1. 工资对比（NPC的认知范围内比较！）
  已知的同行平均工资（通过和朋友聊天/看公示栏获得）
  自己的工资 < 同行均值 × 0.7 → 不满意度 +0.5
  自己的工资 < 同行均值 × 0.5 → 不满意度 +1.0

  // 2. 工资购买力
  月薪 < 月基本生活支出 → 不满意度 +0.5
  
  // 3. 老板的态度
  连续多日被老板训斥/减少休息 → +0.3

  // 4. 通勤时间（距离）
  通勤>200格 → 不满意度+0.3

  离职概率判定：每月评定一次
  if random(0,1) < 离职概率 → 主动离职
```

**偷东西：**
```
偷窃判定（每月评定）：

触发前提（满足即可）：
  - 道德水准_底线意识 ≤ 5（底线低）
  AND
  - 满足以下其一：
    a) 月薪 < 基本生存成本（穷困）→ 概率 15%
    b) 人际关系_嫉妒心 ≥ 7（嫉妒老板有钱）→ 概率 10%
    c) 胆魄气量_风险规避 ≤ 3（胆大不怕被抓）→ 概率 8%

执行：
  if random(0,100) < 概率:
    偷取一件店铺库存物品（价值随机）
    被发现概率 = 30% + 店铺保安力 - 员工敏捷度
    如果被发现 → 老板记入记忆标签[被员工偷过]，可能被解雇/打骂/报官
    如果未被发现 → 员工财富增加，老板库存减少
```

**抗议/罢工：**
```
触发条件（多个员工同时不满）：
  - 店铺有≥2名员工
  - 其中≥60%的员工不满意度>0.7
  → 触发抗议事件
  
抗议效果：
  领头员工（社交属性_自我坦露最高者）提出诉求：
    "要求加薪到XX（同行均值）"
  老板的回应：
    善良的老板 → 加薪
    理性的老板 → 谈判（部分加薪）
    贪婪的老板 → 拒绝
    拒绝后 → 罢工概率 = 60%
    罢工 → 店铺停工，老板收入归零，直到谈判成功或老员工全离职
```

## 7.5 人与人之间的直接交易（P2P）

> 并非只有商店才能买卖。任何 NPC 都可以直接和另一个 NPC 交易。

```
NPC A 想卖东西（多余/不需要的物品）
NPC B 想买东西（正需要的物品）

交易触发：
  A 有物品 X，想卖掉
  B 缺少物品 X，想以物易物或用铜板换
  A 和 B 在同一个视野/听觉范围内

P2P 定价（与商人不同）：
  因为不是商业行为 → 价格由双方友好程度决定
    陌生人 → 按市场价
    朋友 → 可能打折
    好感度 ≥ 60 → 可能半价
    好感度 ≤ -50 → 不卖给你

  以物易物：
    不需要铜板 → A 拿 X 换 B 的 Y
    A 判断 Y 值不值：
      性格理性≥7 → 算得清楚
      性格大方≥7 → 随便换（"算了算了就当交个朋友了"）

交易流程：
  CMD_出价(物品, 期望价) → B看了 → 
    接受 → 钱+物交换 ✓
    拒绝 → 两人各继续往前走

商人额外能力：
   商人可以分析市场供需偏差（买方市场缺什么）→主动去低价区买→高价卖回来 → P2P 卖给别人
```

## 八、房价与房租

### 8.1 地段差异
- 村中心 vs 村边缘 → 价格不同（但农村差异不大）
- 城镇 vs 农村 → 城镇房价高于农村
- 随着村庄发展成城镇 → 房价自然上涨

### 8.2 房东的定价逻辑
```
房租由房东的性格+供需决定：
  - 来看房的人多（供<求）→ 房东涨价
  - 房子长期空置（供>求）→ 房东降价
  - 贪婪的房东 → 租贵
  - 善良的房东 → 租便宜

价格不是每天变，可以设定为"每次租约到期时重定价"
或者设定一个调整周期（比如每月）
```

## 九、NPC建房系统

### 9.1 两种方式

| 方式 | 要求 | 结果 |
|:----|:-----|:-----|
| **自己建** | 需要基础建筑技能 + 材料 | 只能建小/简陋的房子 |
| **请建筑队** | 需要付工钱 + 材料 | 可以建更大/更好的房子 |

### 9.2 建房产业链
```
挖粘土/伐木 → 原材料
  ↓
烧砖坊（粘土→砖头）/ 锯木坊（木材→木板）
  ↓
建筑队/工匠（砖头+木板→房子）
  ↓
NPC入住
```

### 9.3 房子的等级

> 详细等级表见 [原始生存系统 §7.4](./原始生存系统.md)。这里仅概述：

- 简陋草棚（自己就能建，材料少，无技能门槛）
- 普通民房（需要工匠，材料中等）
- 高级宅院（需要高级工匠，材料多且贵）

### 9.4 攀比心机制

心理学上，攀比心（比较心理）≠嫉妒心：
- **嫉妒**："见不得别人好"，希望别人变差——破坏性
- **攀比**："别人有的我也想要"，驱动消费和建设——建设性

程序化实现（不新增维度，利用现有34维）：

```
NPC看到邻居家有更好的房子/衣服/物品时：
  ┌─ 触发条件：感知范围内有同龄/同阶层NPC
  │   且对方拥有自己没见过/更好的物品
  │
  ├─ 攀比驱动 = 人际关系_嫉妒心 × 0.4 + 财富态度_获取欲望 × 0.6
  │   攀比驱动 > 5 → 生成欲望"想换更好的房子/衣服"
  │
  └─ 这个欲望进入正常的欲望打分流程
      → 和"想睡觉""想吃东西"一起竞争
      → 分数最高的欲望被执行
```

不需要新增"攀比心"维度，它只是已有性格维度的组合表现。
