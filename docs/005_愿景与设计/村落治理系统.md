## 一、触发条件

```
当村里的人口 >= 20人 → 自动触发"需要个管事的"
人口计数由出生/死亡系统自动统计
```

---

## 二、选举村长

```
选举流程（每月自动触发一次）：

Step 1：谁都可以提名自己/他人
Step 2：所有村民投票
  投票规则：
    每个村民给自己最喜欢的人投票
    投票偏好 = 对候选人的好感度（范围 -100~+100）
    好感度越高 → 越可能投给他

Step 3：得票最高的NPC → 成为"村长" → 获得[村長]标签

如果平票 → 随机选一个
如果没有人愿意 → 社会声望最高/最强/最富有的人自荐
```

---

## 三、村长的职责

### 3.1 组织公共建设

```
村长可以发起公共项目：
  建公示栏（10铜板，大家凑钱）
  修路（用土/石，大家出力）
  挖公共水井（省去每天去河边打水）

NPC对公共项目的态度：
  责任心高 → 愿意出钱出力
  自私 → 不想参与
  村长劝说的成功率 = 村长社交属性/10 × 0.7 + 村民友善度/10 × 0.3
```

### 3.2 收税（初期象征性）

```
每户每年 1~5 铜板（看经济水平）
税用于公共建设→优先公示栏、道路
村长不能滥用（全体村民监督，滥用会降好感度）
```

### 3.3 调解纠纷

```
村里两个人吵架/打架 → 村长出面调解
  调解成功率 = 村长社交/10 × 0.6 + 双方好感度差距的倒数 × 0.4
  成功 → 双方好感+1，村长的威信+1
  失败 → 双方继续吵，村长丢面子
```
