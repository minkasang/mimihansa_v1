# 初始建造与工具链

> ⚠️ 规范研究文档。定义 NPC 如何从一无所有的露营状态，逐步发展到村落和铁器文明。
> 覆盖所有工具的制作方式、材料来源、以及各级建筑的建造条件。

---

## 一、总体演化路线

```
阶段0: 露营过夜（Day 1）
  ├── 捡柴、生火 → 第一堆篝火
  ├── 徒手摘野果 → 充饥
  └── 走到河边喝水 → 解渴

阶段1: 简易工具（Day 1~3）
  ├── 摔碎石头 → 锋利碎片 → 石刀
  ├── 石刀 + 树枝 → 石斧、石镐
  └── 有了石刀 → 可以砍小树、加工木材

阶段2: 简易遮棚（Day 3~7）
  ├── 木材×5 + 树叶草绳 → 单人遮棚
  ├── 多人协作可以搭更大的
  └── 能防雨、提高睡眠质量

阶段3: 固定草房（Day 10~30）
  ├── 木材×20 + 石头×10 + 藤蔓×30
  ├── 多人协作建造（至少2人）
  ├── 设置家坐标 → 固定住所
  └── 随季节演化

阶段4: 村落形成（Day 30+）
  ├── 多个草房聚集成群
  ├── 触发村落治理系统（人口20+）
  ├── 出现道路（踩踏形成）
  └── 分工明确 → 铁匠/农夫/猎人

阶段5: 铁器时代（未来）
  ├── 石镐挖矿 → 铁矿石
  ├── 熔炉炼铁 → 铁锭
  └── 锻造铁器
```

## 二、工具链（徒手 → 石器）

### 2.1 工具层级

```
徒手阶段（什么都没有）:
  能做的事:
    ✅ 捡树枝（地面拾取 → 消耗时间）
    ✅ 捡石头（地面拾取）
    ✅ 摔碎石头 → 得锋利碎片
    ✅ 徒手挖土（慢）
    ✅ 徒手生火（钻木取火，成功率低）
    ✅ 徒手摘野果、喝水（直接喝河水）
  不能做的事:
    ❌ 砍树（打不断）
    ❌ 挖矿（敲不动）
    ❌ 精细加工

摔石 → 石刀（最基础的工具）:
  需要: 大石头×1（找到大石头，砸碎）
  动作: 找个合适的石头砸碎 → 挑锋利碎片
  耗时: 约半小时（游戏时间）
  成功率: (智商 + 力量) / 20 × 100%
  产物: 石刀（工具，耐久=20，用完即碎）

石刀 → 石斧（石斧需要木柄）:
  需要: 石刀×1 + 树枝×1 + 藤蔓×1
  动作: 用石刀削树枝成柄 → 绑石头 → 石斧
  耗时: 约1小时
  产物: 石斧（工具，可砍树，耐久=30）

石刀 → 石镐:
  需要: 石刀×1 + 硬木棍×1 + 藤蔓×2
  产物: 石镐（可挖矿，耐久=25）

石刀 → 石铲:
  需要: 石刀×1 + 平石板×1 + 木棍×1
  产物: 石铲（可挖土/挖坑，效率比徒手高5倍）
```

### 2.2 工具耐久与替换

```
所有石器工具都有耐久度:
  石刀: 耐久20。每次使用消耗1。用来加工时消耗减半。
  石斧: 耐久30。砍树每次消耗1。
  石镐: 耐久25。挖矿每次消耗1。
  
耐久归零 → 工具碎掉 → 物品栏移除 → 需要重做

工具耐久耗尽后 NPC 需要重新制作。这自然驱动了"石匠"的职业分工——
有人专门磨石头，有人专门做工具。
```

## 三、建造链（露营 → 村落）

### 3.1 阶段0: 篝火（Day 1，所有NPC可用）

```
欲望触发: 天黑、冷、有生肉需要烤 → want_make_fire

方法A: 钻木取火（不需要任何工具）
  材料: 干树枝×2
  成功率: (智商 + 10) / 20 × 100%（基础50%~100%）
  失败: 多试几次
  成功: 生成火堆实体 → 写入 World.fires[]

火堆效果:
  ✅ 取暖（周围10格内精力恢复+50%）
  ✅ 烤肉（放在火上烤 → 生肉变熟肉）
  ✅ 社交（NPC被火光吸引过来，触发聊天）
  ✅ 防止野兽靠近
  缺点:
    ❌ 需要不断加柴（每Tick消耗燃料）
    ❌ 雨天会熄灭
```

### 3.2 阶段1: 简易遮棚（Day 1~7）

```
欲望触发: 天黑、下雨、疲劳 → want_build_shelter

所需材料:
  木材×5（砍小树 → 不需要石斧，徒手折树枝凑合）
  树叶×10（地上捡）
  藤蔓×3（森林/草地采集）

建造时间:
  单人: 约一个游戏日（8小时）
  三人协作: 约3小时

遮棚效果:
  类型: 临时建筑（不可设为永久家坐标，但可临时标记）
  耐久: 50（下雨-5/次，大风-10/次，约撑3~5天）
  容量: 2~3人挤在一起
  防雨: 是（减少雨天暴露）
  精力恢复加成: +30%

多人协作规则:
  NPC在Step 2感知到有人在建遮棚 → 如果自己没地方睡且友善度高 → 主动帮忙
  帮忙时: 建造速度提升（每人贡献自己的建造速度）
```

### 3.3 阶段2: 固定草房（Day 10~30）

```
欲望触发: want_build_home（想要一个固定的家）

前提条件:
  1. 有基本工具（石刀或石斧）
  2. 知识库里知道怎么建房（初始常识或学习）
  3. 需要一定的材料积累

所需材料:
  木材×20（砍大树 → 需要石斧）
  石头×10（捡石头或挖石头）
  藤蔓/草绳×30
  黏土×5（用于糊墙缝）

建造时间:
  单人: 约10个游戏日
  四人协作: 约3~5天

草房效果:
  类型: 永久建筑（可设为家坐标）
  等级: 基础
  耐久: 100
  容量: 4格×4格屋内空间
  防雨: 完全
  精力恢复加成: +50%
  
  拥有者:
    房屋.所有者ID = 建造者ID
    建造者的家坐标自动设置为此位置

建筑数据:
  {
    id: "building_01",
    类型: "草房",
    等级: "基础",
    位置: [x, y],
    所有者ID: "npc_xxx",
    建造者ID: ["npc_aaa", "npc_bbb"],
    耐久度: 100,
    内部空间: [2, 2]
  }
```

### 3.4 阶段3: 村落形成（约Day 30+）

```
触发条件:
  同一区域内建筑 > 5座
  AND 人口 >= 20

村落形成后的变化:
  1. 触发 村落治理系统（选举村长、调解纠纷）
  2. 出现职业分化（铁匠、农夫、猎人、教师）
  3. 出现市场（以物换物）
  4. 出现道路（踩踏形成的路径）
  
道路形成:
  多人频繁走同一路径 → 踩踏度累积 → 形成小路 → 后来变成道路
  道路上的移动速度 +20%
  道路旁的草地逐渐退化为裸露地
```

## 四、原始生存常用行动计划

| 动作 | 前提 | 消耗 | 产物 | 用于 |
|:-----|:-----|:-----|:-----|:-----|
| 徒手捡树枝 | 附近有森林/草地 | 时间 | 树枝×1 | 生火 |
| 徒手捡石头 | 附近有山地/草地 | 时间 | 小石头×1 | 工具 |
| 摔碎大石头 | 有大石头 + 力量>3 | 体力-2 | 锋利碎片×1~3 | 石刀 |
| 磨石刀 | 锋利碎片 + 智商 | 时间 | 石刀×1 | 通用工具 |
| 钻木取火 | 干树枝×2 | 时间+体力 | 火堆 | 取暖/烤食 |
| 徒手摘野果 | 附近有森林/草地 | 时间 | 野果×1~3 | 吃 |
| 砍小树 | 石刀/石斧 | 体力-2 | 木材×1~3 | 建筑 |
| 徒手挖土 | 站在草地 | 体力-5 | 土坑 | 埋人/种地 |
| 石铲挖土 | 石铲 | 体力-1 | 深坑 | 埋人/种地/地基 |
