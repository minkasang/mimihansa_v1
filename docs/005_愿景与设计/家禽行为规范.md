# 家禽行为规范（鸡、鸭）

> ⚠️ 规范研究文档。鸡和鸭是可驯养家禽，行为简单，产出稳定。
> 复用人类 GOAP 引擎。野生状态走少欲望循环，圈养后更简单。

---

## 一、鸡

### 参数

| 素质 | 值 | 说明 |
|:-----|:--:|:-----|
| 移动速度 | 3 | 不快——但短距离扑腾 |
| 耐力 | 2 | 体力极少 |
| 力量 | 1 | 无攻击力 |
| 视觉 | 15格 | 能看清地面虫子和谷物 |
| 听觉 | 20格 | 听到动静就警觉 |
| 嗅觉 | 5格 | 鸡靠眼不靠鼻子 |
| 震动感知 | 8格 | 地面震动→警觉 |

### 欲望（5条）

```
want_flee (优先级 10):
  条件: 感知到威胁（人/狼/鹰靠近）
  目标: 扑腾着跑开 → 躲进灌木

want_eat (优先级 9):
  条件: 饥饿度 > 5 + 是白天
  目标: 啄地面找虫子/谷物/碎草
  效果: 饥饿度 -3

want_drink (优先级 8):
  条件: 口渴度 > 6
  目标: 去水源喝水
  效果: 口渴度 -5

want_lay_egg (优先级 7):
  条件: 母鸡 + 距上次下蛋 > 1天 + 健康 > 5
  目标: 在窝里/角落下蛋 → 蛋生成在地上
  效果: 世界生成鸡蛋物品

want_sleep (优先级 5):
  条件: 疲劳度 > 7 OR 天黑
  目标: 回窝/高处睡觉（缩成团，头埋在翅下）

默认: want_idle (优先级 2):
  条件: 无高优先级目标
  目标: 在窝附近踱步、啄地
```

### 圈养后变化

- 人提供饲料 → want_eat 条件从"找虫子"变成"走到饲料槽"
- 人定时喂水 → want_drink 从"去水源"变成"去水槽"
- 人建鸡窝 → 固定在窝里睡觉下蛋
- **公鸡打鸣**：清晨触发 → 产生听觉事件"鸡鸣"→ 成为村庄时间信号

## 二、鸭

鸭子跟鸡的欲望几乎一样——多一个"游泳"。

### 与鸡的关键区别

| | 鸡 | 鸭 |
|:--|:--|:--|
| 移动 | 碎步快走 | 摇摇摆摆走 + **可以下水游泳** |
| 栖息 | 高处/窝 | 水边/窝 |
| 默认状态 | 啄地 | 如果有水→下水游 / 没有→啄地 |
| 感知 | 地面震动敏感 | 同鸡，但对"水声"有额外反应 |

### 鸭子特有欲望

```
want_swim (优先级 3):
  条件: 附近有水域 + 不饿不困
  目标: 走到水边 → 下水游泳（浮游+觅食水面）
  ← 鸭子大部分空闲时间都在水里
```

## 三、鸡鸭的种群管理

```
繁殖: 公+母 → 受精蛋 → 母鸡/母鸭孵化21/28天 → 小鸡/小鸭
  自然: 母鸡抱窝孵化
  人工: 人捡走蛋 → 蛋没了 → 母鸡继续下（隔1~2天）

驯化路径:
  抓野生原鸡/野鸭 → 圈养 → 喂食 → 繁殖 → 建立稳定种群

经济价值:
  鸡: 蛋(稳定每日产出) + 鸡肉(屠宰)
  鸭: 鸭蛋(比鸡蛋略大) + 鸭肉 + 鸭毛(做羽绒)
```
