## 一、地图：第一张图叫什么

### 1.1 尺寸

沿用现有的 `data/maps/幸福镇.json`，100×100格，作为第一张地图。

### 1.2 地形生成（简化版）

```
地图 = 100×100网格

地形类型（每格一个属性）：
  草地（最普遍，可以建房子、种地）
  森林（提供木材——需要砍伐后才能变成草地）
  水域（河流、湖泊——提供水源，不能种地）
  山地（提供石头/矿石——不能种地但可以开采）
  道路（天生就有连接的道路——以后由NPC踩出来/修建）

生成算法（程序自动）：
  1. 先铺满草地
  2. 随机撒几片森林(占20%)
  3. 画一条河流(从地图一侧到另一侧)
  4. 放几个水面(湖泊)
  5. 角落放一些山地(占10%)
  6. 预留一个"村落初始点"：地图中央偏左的一片50×50的平坦草地
```

这个生成规则可以放到 `data/maps/幸福镇.json` 里，或被程序硬编码为一个生成函数。

## 二、初始NPC：第一代村民

### 2.1 方案：手工配置几个始祖

游戏启动时，世界空无一人。系统生成第一批NPC——这是"最初的村民"。

**多少人？**
建议：**8~12人**（太少没互动，太多初期运行慢）

**性别比例：**
男女各半（随机）

**年龄分布：**
```
  18~25岁：4人（年轻人，建村主力）
  26~40岁：3人（中年人，有经验）
  41~50岁：1人（老年人，寿命快到上限了）
```

**初始数据生成：**

所有第一代NPC的属性由程序随机生成，但有约束：

```
姓名：从姓氏表+名字表里随机组合（如"云飞"、"齐琳琳"）
性别：随机M/F，保持1:1
年龄：按上述分布随机
基本素质：力量/智商/耐力等，random(3,8)
性格维度：所有34维均 random(3,8)，不极端化
初始技能：全部为0（原始社会，什么都不会）
初始物品：空的
初始金钱：0铜板

特殊约束：
  至少1人智商≥7（聪明人——以后可能发明工具、建学校）
  至少1人健康≥8（体质好——活得久）
  至少1人力量≥7（壮汉——能砍树打猎）
```

### 2.2 初始状态

| 项目 | 初始值 |
|:-----|:------|
| 住所 | 无（第一晚睡在草地上） |
| 食物 | 无（需要马上采集/打猎） |
| 水 | 需要去河边取 |
| 工具 | 无 |
| 火 | 无 |
| 金钱 | 无 |
| 职业 | 无（都是"原始人"） |
| 社会结构 | 无（没有村长、没有规则） |

## 三、第一天：生存驱动

### 3.1 NPC第一天的欲望

```
Tick 1启动，每个NPC都处于"原始状态"：

欲望系统自动计算：
  最高分欲望：
    1. 饿 → 想吃东西(want_eat) — 优先级8
       → 寻找食物：采摘野果、打猎……
    2. 想休息 → 疲劳了需要有地方睡(want_rest) — 优先级5
       → 先【建一个简陋的庇护所】
    3. 渴 → 想喝水 — 需要去河边
  
  聪明人(智商≥7)可能优先做：
    → 生火（需要木材+石头）
    → 制作最简单的工具（尖石头当刀）

所有人都没有职业→没有收入→没有金钱→无法交易（以物易物阶段）
```

### 3.2 庇护所的建造

```
动作：建造简易庇护所
  材料：木材×5（需要先砍树）
  时间：约1个游戏日（几个人一起更快）
  效果：生成一个[建筑：简陋木棚]，可以作为"家"坐标
  容纳：2~3个人挤一晚上
  抗风雨：极差（暴雨时可能漏水）

多个NPC可以合作建造（搭把手）：  
  一个人干：8小时
  三个人干：3小时
```

### 3.3 寻找食物

```
采摘（不消耗工具）：
  在森林/草地附近寻找野果
  采到：野果（饥饿-2）

狩猎（需要工具或群体合作）：
  力量≥6 + 有空手武器 → 猎杀小动物
  → 获得：生肉（需要烤熟才能吃）
  成功率：单人30%，多人围猎60%

生火：
  材料：木材×1 + 石头×2
  方法：钻木取火（智商越高成功率越高）
  成功后生成[火堆]，可以烤熟食物
```

### 3.4 第一天结束时的期望状态

```
期望：
  - 至少搭建了1~2个简易庇护所
  - 所有人都吃到了第一顿食物（野果或烤熟的肉）
  - 有人生起了火
  - 有人在河边取了水
  - 聪明人开始琢磨："有没有更好的办法？"
```

## 四、从原始走向初级文明

### 4.1 工具发明（由智商驱动的需求触发）

```
发明判定：NPC每执行一次某个动作后，判定是否"灵光一现"

示例：
  打猎N次用空手 → 如果智商≥7 → 概率5%触发"发明石刀"
    发明石刀需要的条件：
      自己或附近有：石头×2
      自己去河边磨石头 → 获得[工具：石刀]
      标签[发明了石刀]记入记忆
  
  采摘野果N次 → 如果智商≥7 → 概率5%触发"发明篮筐"
    编篮子 → 采摘效率提升

  看到别人建的庇护所 → 如果智商≥7 → "我也可以建"
```

工具发明是一连串的——有人发明了石刀→他可以砍树更快→可以造更多东西。

### 4.2 初级分工

```
随着时间推移，NPC开始发现各自的优势：

  力量高的 → 多去打猎
  智商高的 → 多去思考/发明
  手工好的 → 做工具/建房子
  社交好的 → 负责协调"谁去打猎谁去采果"

这不是谁分配的——是自然形成的：
  力量高者：打猎的成功率就是比别人高→他自然多去打猎
  智商高者：发明的触发率就是比别人高→他自然"发明"更多
```

## 五、初始社会秩序

### 5.1 无政府状态下的规则

```
没有任何正式的法律、警察、政府。

基础秩序靠：
  1. 道德底线——大多数人不会抢劫、杀人（底线意识≥6）
  2. 社交排斥——如果有人做了太坏的事，其他人"不理他"、"不帮他"、"驱逐他"
  3. 强制力——如果冲突升级，可能发展成武力解决
  
矛盾处理：
  两个人吵架/打架：
    - 周围人围观
    - 有人出来劝架（善良者、共同朋友）
    - 如果有人受伤 → 其他人对施暴者产生负面评价
    
  一个人偷东西/抢劫：
    - 受害者+看到的人发布在公示栏（如果有的话）
    - 全村人对他好感度下降
    - 下次他再来 → 不卖东西给他、不帮他
    - 严重情况 → 集体驱逐（"滚出这个村子"）
    - 极端情况 → 一伙人揍他一顿
```

### 5.2 社交排斥的三层

```
第一层：冷遇
  好感度降至负 → 不打招呼、不帮忙、不交易
  触发：小偷小摸、说谎、失信

第二层：孤立
  好感度<-50 → 没人跟他说话
  触发：严重失信、恶意伤害
  效果：该NPC无法通过口口相传获得信息

第三层：驱逐
  好感度<-80 + 村里有≥3人对他好感度<-50
  → 集体行动：把他赶出村子
  → 如果对方不服→可能爆发武力冲突
```
