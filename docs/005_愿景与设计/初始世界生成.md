## 一、地图：第一张图叫什么

### 1.1 尺寸

沿用现有的 `data/maps/幸福镇.json`，**300×300格**（原100×100扩大），作为第一张地图。

### 1.2 地形生成（简化版）

```
地图 = 300×300网格

地形类型（每格一个属性）：
  草地（最普遍，可以建房子、种地）
  森林（提供木材——需要砍伐后才能变成草地）
  水域（河流、湖泊——提供水源，不能种地）
  山地（提供石头/矿石——不能种地但可以开采）
  道路（天生就有连接的道路——以后由NPC踩出来/修建）

生成算法（程序自动）：
  1. 先铺满草地
  2. 随机撒几片森林(占20%)
  3. 画一条河流(从地图一侧到另一侧)
  4. 放几个水面(湖泊)
  5. 角落放一些山地(占10%)
**初始出生点约束：**
- 村落初始点必须在水域20格以内 ✅
- 水源同时吸引动物（也是它们喝水的地方）→ 初始村落旁有动物出没
- 出生点旁有一片50×50的平坦草地作为初始村落预留地
```

这个生成规则可以放到 `data/maps/幸福镇.json` 里，或被程序硬编码为一个生成函数。

## 二、初始NPC：第一代家族

> ⚠️ v2.0 重写：初始群体不是随机生成的个人——是几个有血缘关系的家族一起迁徙。

### 2.1 家族迁徙结构

总人数约 **30~40人**，约 **6~8个家族单元**。每个家族都是拖家带口来的。

```
每个家族单元:
  - 1对中年夫妻（30~50岁）: 家族的主事人
  - 0~2个孩子（0~17岁）: 跟着父母来的
  - 可能有祖辈（50~60岁）: 家族的老人

人口分布:
  0~2岁（婴儿）: 0~2人       → 少数家庭带着婴儿
  2~6岁（幼儿）: 2~4人        → 能跑能跳的幼童
  6~17岁（学龄/青少）: 4~6人   → 半大孩子，能帮忙
  18~30岁（青年）: 5~8人       → 年轻劳动力
  31~50岁（中年主力）: 10~14人  → 壮年
  51~60岁（老年）: 2~4人        → 老人

家族单元之间:
  - 有血缘或姻亲关系
  - 6个家族可能来自同一更大宗族的分支
  - NPC创建时带着完整家族关系（社会关系表 + 知识库辨识符映射）
```

### 2.2 初始常识 + 初始地点认知（v2.0 重写）

始祖不是原始人——他们是"迁徙过来的"，而且**选择在水源附近扎营**。这是他们在这里的原因。

```
所有始祖NPC初始知识库包含:

  概念知识（类型:"概念"）:
    ✅ { 类型:"概念", 内容:"火可以钻木生", 来源:"习得" }
    ✅ { 类型:"概念", 内容:"石头可以磨成刀", 来源:"习得" }
    ✅ { 类型:"概念", 内容:"野果可以吃", 来源:"习得" }
    ✅ { 类型:"概念", 内容:"渴了要喝水", 来源:"习得" }
    ✅ { 类型:"概念", 内容:"冬天冷夏天热", 来源:"习得" }

  地点知识（因为是扎营在河边，亲身经历）:
    ✅ { 类型:"地点", 名称:"水源", 位置:[营地坐标],
         参考物:"河边有大树", 方向:"营地旁", 距离:"很近",
         来源:"亲眼", 可信度:1.0 }
    ← 每个人都知道水源在哪，因为营地就挨着水

但不知道的:
    ❌ 营地之外的地图（需要探索）
    ❌ 哪里有铁矿
    ❌ 其他人的性格（需要接触才知道）
```

### 2.3 初始数据生成（v2.0 修正）

```
姓名: 从姓氏表+名字表随机组合
性别: 按家族单元分配（夫妻配对+子女随机）
年龄: 按 §2.1 分布
素质: random(3, 8)
性格: 34维 random(3, 8)
技能: 全部 = 0
物品栏: []
金钱: 0

特殊约束:
  至少1人智商≥7（聪明人）
  至少1人健康≥8（体质好）
  至少1人力量≥7（壮汉）

婴儿:
  如果家族中有0~2岁婴儿:
    母亲.标签: 添加 [哺乳期]
    母亲.生理状态.母乳值: 60
    ← 保证初始婴儿不会饿死
```

### 2.4 初始状态

| 项目 | 初始值 |
|:-----|:------|
| 住所 | 无（但家族单元有足够的劳动力快速搭建多处庇护所） |
| 食物 | 少量干粮（路上吃剩的），需要马上采集/打猎 |
| 水 | 需要去河边取（出生点≤20格内必定有水域） |
| 工具 | 几乎无 |
| 火 | 无（但知道怎么生火→第一天天黑前有人生火） |
| 金钱 | 无 |
| 职业 | 无 |
| 社会结构 | 家族关系存在，但没有公共领导 |

## 三、初始动物生成（v2.1 新增）

> 地图上需要动物才能让狼有猎物、让人有狩猎目标。

### 3.1 初始动物数量

```
基于300×300地图的初始动物投放（可按比例调整）:

  野兔: 30~50只
    分布: 草地、森林边缘、灌木丛附近
    每只兔子携带知识库: { 水源位置, 窝位置 }

  野鹿: 2~4群（每群3~6只，共10~20只）
    分布: 草地开阔区，靠近森林（方便躲藏）
    鹿群位置距营地至少50格（否则第一天就被赶跑了）

  野猪: 1~3群（每群2~4只，共5~10只）
    分布: 森林深处、山地边缘

  狼: 1~2群（每群3~5只，共5~10只）
    分布: 距离营地至少80格外的森林/山地
    狼群有自己的巢穴和初始领地范围
    ← 初始狼不会立刻威胁营地

  飞鸟: 20~30只（点缀用，不参与核心生态）
    分布: 全地图天空随机位置

  鱼: 所有水域格中随机投放鱼群（每条河/湖3~5群，每群10~20条）
```

### 3.2 动物生成的规则

```
1. 动物不能生成在营地50格以内的区域（营地是"人类刚来，野生动物还没被赶走但也不会在"）
   例外: 飞鸟不受限制（鸟在天上）

2. 动物的初始知识库:
   兔子/鹿/野猪: { 水源位置(最近的河流/湖泊), 巢穴/窝位置(生成点) }
   狼: { 水源位置, 巢穴位置, 角色(首领/Beta/Omega) }

3. 动物之间不能重叠生成（两只动物不在同一格）

4. 狼群的初始位置必须距离鹿群/兔群不太远（狼也需要有食物——否则一开始就饿死）
   但也不能太近（否则第一天就吃光了）
   建议: 狼群巢穴距最近的鹿群约40~60格
```

## 四、第一天：生存驱动

### 3.1 NPC第一天的欲望

```
Tick 1启动，30~40个NPC带着基础常识醒来：

因为有基础常识→大家已经知道"火""水""工具"是啥→不需要重新发明轮子

欲望系统自动计算：
  最高分欲望：
    1. 饿 → 想吃东西(want_eat) — 优先级8
       → 采摘野果（徒手） ✅ 常识库有辨识力
    2. 渴 → 想喝水(want_drink) — 优先级8
       → 去河边（出生点附近≤20格） ✅ 
    3. 想休息 → 疲劳了需要有地方睡(want_shelter) — 优先级5
       → 砍木头（先磨石刀→常识里有）→ 搭简易草棚

第一天结束时的预期：
  核心水源处→有人取水→形成第一个路径
  几人尝试生火→40人中有10+人成功→有了第一个公共火堆
  30多人采摘野果→当天采集量足够全家吃
  简单草棚搭好了2~3个→分成几个小组合住
```

### 3.2 庇护所的建造

```
动作：建造简易庇护所
  材料：木材×5（需要先砍树）
  时间：约1个游戏日（几个人一起更快）
  效果：生成一个[建筑：简陋木棚]，可以作为"家"坐标
  容纳：2~3个人挤一晚上
  抗风雨：极差（暴雨时可能漏水）

多个NPC可以合作建造（搭把手）：  
  一个人干：8小时
  三个人干：3小时
```

### 3.3 寻找食物

```
采摘（不消耗工具）：
  在森林/草地附近寻找野果
  采到：野果（饥饿-2）

狩猎（需要工具或群体合作）：
  力量≥6 + 有空手武器 → 猎杀小动物
  → 获得：生肉（需要烤熟才能吃）
  成功率：单人30%，多人围猎60%

生火：
  材料：木材×1 + 石头×2
  方法：钻木取火（智商越高成功率越高）
  成功后生成[火堆]，可以烤熟食物
```

### 3.4 第一天结束时的期望状态

（30~40人）

```
期望：
  - 搭建了5~8个简易草棚（家庭为单位）
  - 所有人都吃到了第一顿食物（野果或烤熟的肉）
  - 1~2个公共火堆升起，成为天然的"社交中心"
  - 水源处已有路径雏形（多组人去取水）
  - 家庭团聚在一起，有人开始磨石刀
```

## 五、从原始走向初级文明

### 4.1 工具发明（由智商驱动的需求触发）

```
发明判定：NPC每执行一次某个动作后，判定是否"灵光一现"

示例：
  打猎N次用空手 → 如果智商≥7 → 概率5%触发"发明石刀"
    发明石刀需要的条件：
      自己或附近有：石头×2
      自己去河边磨石头 → 获得[工具：石刀]
      标签[发明了石刀]记入记忆
  
  采摘野果N次 → 如果智商≥7 → 概率5%触发"发明篮筐"
    编篮子 → 采摘效率提升

  看到别人建的庇护所 → 如果智商≥7 → "我也可以建"
```

工具发明是一连串的——有人发明了石刀→他可以砍树更快→可以造更多东西。

### 4.2 初级分工

```
随着时间推移，NPC开始发现各自的优势：

  力量高的 → 多去打猎
  智商高的 → 多去思考/发明
  手工好的 → 做工具/建房子
  社交好的 → 负责协调"谁去打猎谁去采果"

这不是谁分配的——是自然形成的：
  力量高者：打猎的成功率就是比别人高→他自然多去打猎
  智商高者：发明的触发率就是比别人高→他自然"发明"更多
```

## 六、初始社会秩序

### 5.1 无政府状态下的规则

```
没有任何正式的法律、警察、政府。

基础秩序靠：
  1. 道德底线——大多数人不会抢劫、杀人（底线意识≥6）
  2. 社交排斥——如果有人做了太坏的事，其他人"不理他"、"不帮他"、"驱逐他"
  3. 强制力——如果冲突升级，可能发展成武力解决
  
矛盾处理：
  两个人吵架/打架：
    - 周围人围观
    - 有人出来劝架（善良者、共同朋友）
    - 如果有人受伤 → 其他人对施暴者产生负面评价
    
  一个人偷东西/抢劫：
    - 受害者+看到的人发布在公示栏（如果有的话）
    - 全村人对他好感度下降
    - 下次他再来 → 不卖东西给他、不帮他
    - 严重情况 → 集体驱逐（"滚出这个村子"）
    - 极端情况 → 一伙人揍他一顿
```

### 5.2 社交排斥的三层

```
第一层：冷遇
  好感度降至负 → 不打招呼、不帮忙、不交易
  触发：小偷小摸、说谎、失信

第二层：孤立
  好感度<-50 → 没人跟他说话
  触发：严重失信、恶意伤害
  效果：该NPC无法通过口口相传获得信息

第三层：驱逐
  好感度<-80 + 村里有≥3人对他好感度<-50
  → 集体行动：把他赶出村子
  → 如果对方不服→可能爆发武力冲突
```
