## 一、欲望：色欲与性欲的关系

### ⚠️ 色欲 ≠ 性欲（重要修正！）

两者是不同概念，区分如下：

| 概念 | 类型 | 说明 | 变化特征 |
|:----|:----|:------|:--------|
| **色欲** | 性格/欲望（人设） | 好色程度——对异性的兴趣强弱。是**性格底色** | 相对稳定，弹性性格可微调 |
| **性欲** | 生理状态（动态） | 当下的生理冲动——身体想不想。是**临时状态** | 波动很大，每天/每小时变化 |

**关系链：**
```
色欲(高) + 暧昧环境 + 亲密对象 → 性欲值上升 → 可能触发周公之礼
色欲(低) + 没有暧昧 → 性欲值不高 → 不容易触发
```

### 性欲值的设计

```
性欲值 = f(色欲, 环境加成, 对象好感, 时间因子)

色欲基础：
  色欲1-3  → 性欲基础值10（不太想）
  色欲4-6  → 性欲基础值30（中等）
  色欲7-10 → 性欲基础值50（很想）

环境加成（累加到基础值）：
  双方[独处]且无旁人在场          → +15
  双方[亲密关系]（配偶/情侣）      → +20
  环境[暧昧]（夜晚+室内+安静）     → +10
  对方外貌分>7                     → +10
  对方好感度>30                    → +10

时间因子：
  距上次周公之礼超过7天 → ×1.2
  距上次周公之礼超过30天 → ×1.5
  距上次周公之礼3天内 → ×0.3（不重复触发）

性欲值>60 → 触发欲望"do_周公之礼"，进入行动队列
```

### 暧昧标签（新增！）

| 标签 | 触发条件 |
|:-----|:---------|
| `[独处]` | 周围N格内只有双方二人 |
| `[夜晚]` | 游戏时间在晚间 |
| `[室内]` | 双方在同一建筑内 |
| `[安静]` | 周围没有嘈杂事件 |
| `[亲密关系]` | 双方是配偶/情侣 |

## 二、周公之礼的触发流程（程序化）

```
// 每Tick检查 NPC的性欲欲望

Step 1：NPC的性欲值 > 60？
  ├─ 否 → 不触发
  └─ 是 → 进入Step2

Step 2：感知范围内有合适的异性对象？
  ├─ 否 → 不触发
  └─ 是 → 选择好感度最高且满足条件的异性

Step 3：检查环境条件：
  - 双方都在善意/中性的社交状态（非仇恨/战斗）
  - 环境标签满足[独处]或双方在建筑中
  ├─ 不满足 → 不触发
  └─ 满足 → 进入Step4

Step 4：发起方生成动作"action_周公之礼"
  - 步骤1：走向目标NPC
  - 步骤2：目标判定是否同意
    同意条件公式：
      暧昧环境分 = (有[独处]?20:0) + (有[夜晚]?10:0) + (有[室内]?10:0) + (有[安静]?5:0) + (有[亲密关系]?15:0)
      agreeScore = 对方性欲值×0.4 + 对方对发起方好感度/100×0.3 + 暧昧环境分×0.3
      agreeScore > 35 → 同意
      agreeScore ≤ 35 → 拒绝（触发"被拒绝"事件，发起方心情-3）
  - 步骤3：双方都同意 → 执行周公之礼
  - 步骤4：效果结算
    → 双方开心值+5（基础）
    → 双方[快乐值]+10~20（受男性性表现力影响，见参数总表）
    → 女性可能怀孕（见下节）
    → 双方关系标签更新
```

## 三、经期系统

### 3.1 周期数据结构

每个女性NPC维护一个周期状态对象：

```typescript
interface MenstrualCycle {
  周期长度: number;          // 21~35，出生时随机
  生育力: number;            // 0~10，来自参数总表，越高越容易受孕、排卵越稳定
  当前周期日: number;        // 每天+1，到周期长度后归零
  上次月经日: Tick;          // 时间戳
  是否闭经: boolean;
  是否怀孕: boolean;
  孕期天数: number;          // 如果怀孕中，已怀孕了多少天
}
```

### 3.2 每日Tick更新

```
每天Tick时：
1. 是否怀孕？
   是 → 孕期天数+1 → 不更新周期
   否 → 继续

2. 是否生病？or 健康<3？
   是 → 暂停周期（当前周期日不变）
   否 → 继续

3. 今天是否情绪极度低落（开心值<2）？
   是 → 排卵调整值 + random(2,5)天（延迟排卵）
   
4. 当前周期日 +1
5. 如果当前周期日 >= 周期长度 → 周期日归零（新周期开始）
```

### 3.3 排卵窗口计算

```
排卵日 = 周期长度 - 14
排卵日调整 = 排卵日 ± floor((10 - 开心值) / 2)    // 开心值越低，偏移越大
                ± floor((10 - 健康值) / 3)         // 健康越差，偏移越大
                ± floor((10 - 生育力) / 3)         // 生育力越低，排卵越不稳定

最终排卵日 = clamp(排卵日 + 排卵日调整, 周期长度-18, 周期长度-10)

排卵窗口 = [最终排卵日 - 5, 最终排卵日 + 1]   // 6天窗口
```

### 3.4 受孕判定

```
周公之礼发生时：
  if 女性.当前周期日 not in 排卵窗口 → 怀孕概率 = 0%
  if 女性.当前周期日 in 排卵窗口 → 按公式计算：
  
  受孕概率 = 窗口内基础率(25%) × 生育力系数 × 年龄系数 × 意图系数
  
  生育力系数：
    生育力 / 10  → 基础系数(0.1~1.0)
    → 生育力系数 = 基础系数 × 2.0   // 范围0.2~2.0，默认居中=1.0
  
  年龄系数：
    20-30岁 → 1.0
    30-35   → 0.7
    35-40   → 0.4
    40-45   → 0.15
    45+     → 0.0（闭经）
  
  意图系数：
    想要孩子 → 1.2
    无所谓   → 1.0
    不想要   → 0.2

执行判定：
  if random(0, 1) < 受孕概率 → 怀孕
```

## 四、想要孩子（综合打分公式）

触发因素：NPC结婚后，每次周公之礼前系统计算一次"生育意愿"。

### 4.1 社会道德约束（前置检查）

```
⚠️ 社会规则：游戏世界中的"结了婚才能要孩子"是社会道德规范
  
前置检查：NPC是否已婚？
  ├─ ✅ 已婚 → 正常进入生育意愿打分
  └─ ❌ 未婚 → 检查道德约束
       道德水准_底线意识（道德底线）：
         底线高(≥7)  → 遵守社会规范，不想要非婚生子 → 生育意愿=0
         底线中(4-6) → 内心纠结，生育意愿 × 0.5
         底线低(≤3)  → 不在乎社会规范 → 正常进入打分
```

### 4.2 综合打分

```
生育意愿 = Σ(各因素得分 × 权重)

因素1：已有孩子数（反向，越少越想生）
  无孩子 → 100分
  1个    → 60分
  2个    → 30分
  3个    → 10分
  4个+   → 0分

因素2：家庭经济
  家庭金钱/月支出（估算）
  比值>3 → 100分（富裕，养得起）
  比值1-3 → 50分
  比值<1 → 0分（太穷，养不起）

因素3：年龄
  18-30岁 → 100分
  30-35   → 70分
  35-40   → 30分
  40+     → 10分

因素4：责任心（道德水准_规则遵守）
  责任心7-10 → 80分（觉得应该留后代）
  责任心4-6  → 50分
  责任心1-3  → 20分

权重：
  已有孩子数 × 0.3
  家庭经济   × 0.3
  年龄       × 0.2
  责任心     × 0.2

综合得分 ≥ 50 → "想要孩子"
综合得分 30-50 → "无所谓"
综合得分 < 30 → "不想要"
```

> 社会道德规则（如"先婚后育"）可以做成可配置项，放在 `data/libraries/社会规则配置.json` 中，方便调整。

## 五、流产（量化）

```
流产风险 = 基础风险(5%) + 事件加成

事件加成：
  被攻击：
    攻击伤害值 > 3 → +20%流产风险
    攻击伤害值 1-3 → +10%
    攻击伤害值 < 1 → +5%
  
  摔倒/跌倒（由环境事件触发）：
    → +10%流产风险

孕期阶段系数：
  孕早期(1-3月)：流产风险 ×1.5
  孕中期(4-7月)：流产风险 ×1.0
  孕晚期(8-10月)：流产风险 ×0.5

最终流产概率 = 流产风险 × 孕期阶段系数

判定：if random(0, 100) < 最终流产概率 → 流产
流产效果：孕妇心情-10，健康-2，怀孕状态清零
```

## 八、性格与天赋遗传

### 8.1 性格遗传

```
孩子性格初值 = clamp(parentMean × 0.67 + randomUnif(1,10) × 0.33, 1, 10)

对每个34维单独计算：
  parentMean = (父.维度 + 母.维度) / 2
```

### 8.2 智商发育曲线（量化）

```
NPC智商实际值随年龄变化：
  0-2岁  → 天赋智商 × 0.3（婴儿）
  2-6岁  → 天赋智商 × 0.5（幼儿）
  6-12岁 → 天赋智商 × 0.75（学龄，快速增长）
  13-17岁→ 天赋智商 × 0.9（青少年，接近成年）
  18-30岁→ 天赋智商 × 1.0（巅峰）
  30-50岁→ 天赋智商 × 0.95（轻微下滑）
  50+岁  → 天赋智商 × 0.85（老年）

书生气可以额外加成：有10点书生气 → 智商实际值+0.5（上限10）
```

## 十、婴儿行为

### 10.3 孤儿被救助的量化

```
每天Tick时，检查所有孤儿：
  if 孤儿.饥饿度 > 7（快饿死了）:
    扫描孤儿感知范围内所有NPC
    对每个NPC计算"救助意愿"：
      救助意愿 = 道德水准_同理心 × 0.6 + 道德水准_利他意愿 × 0.4
      救助意愿 > 5 → 此NPC有概率触发投食动作
      概率 = (救助意愿 - 5) / 5 × 50%   // 最高50%
    
    if 没有任何NPC触发救助:
      孤儿.饥饿度持续上升
      if 孤儿.饥饿度 >= 10:
        → 饿死（死亡处理）
```

## 十一、多胞胎设计（量化修正）

```
判定公式：
  最终概率 = 1/89 × 修正系数
  
  修正系数 = 1.0
  if 母亲年龄30+  → ×1.5
  if 母亲.家族有多胞胎史 → ×2.0  （未来扩展，先预留字段）
  if 母亲.生育力 > 7 → ×1.3
  
  最终概率 = clamp(最终概率, 0, 0.05)  // 上限5%
  
  if random(0,1) < 最终概率 → 双胞胎
```
