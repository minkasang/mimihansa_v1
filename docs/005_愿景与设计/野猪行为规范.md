## 二、野猪——不怕你，甚至想冲你

野猪是所有猎物中唯一"可能反过来攻击你"的动物。这是它在生态系统中的独特位置。

```
其他猎物（兔/鹿）: 感知威胁 → 逃跑
野猪: 感知威胁 → 评估 → 决定跑还是打

野猪的反击条件:
  如果威胁在 5格内 → 野猪冲过去攻击
  如果威胁在 5格外 → 野猪保持警戒，但不主动追击
  
  如果野猪正在带幼崽（母野猪 + 小猪）:
    → 母野猪攻击性 ×2（护崽心切）
    → 任何靠近幼崽的生物都是攻击目标

  如果野猪受伤了（健康度 < 5）:
    → 攻击性 ×1.5（困兽之斗——这是真的）
    → 受伤的野猪极其危险

野猪 vs 人类:
  人近战 → 野猪冲撞 → 人可能受伤甚至死亡
  这是早期狩猎中最危险的猎物

野猪 vs 狼:
  1~2只狼 → 野猪冲过去 → 狼逃跑（不值得受伤）
  5+只狼 → 狼群围猎 → 野猪可能被杀，但也可能有狼受伤
```

## 三、野猪的日常作息

```
野猪是杂食动物，觅食时间比纯草食动物更灵活:

05:00~09:00（清晨）: 第一次觅食
  - 用鼻子拱土找根茎、块茎
  - 顺便去水源喝水

09:00~16:00（白天）: 泥浴+休息
  - 在泥坑里打滚（降温+防虫——这是真的）
  - 在树下或灌木丛里睡觉

16:00~22:00（黄昏到夜里）: 第二次觅食（夜间觅食）
  - 野猪可以在夜间活动——嗅觉强弥补了视觉差
  - 拱土、吃橡子、找昆虫

22:00~05:00（深夜）: 休息
  - 在灌木丛或草丛中铺一个"床"

季节变化:
  秋天: 大量吃橡子 → 增肥准备过冬
  冬天: 觅食频率降低，消耗储存的脂肪
  春天: 恢复活跃，母野猪准备生崽
```

## 四、野猪的欲望（5条）

```
want_attack_threat (优先级 10, 最高):
  条件: 感知到威胁在 5格内 OR (带幼崽 + 威胁在 10格内)
  目标: action_charge_attack（冲撞攻击）
  效果: 造成伤害（力量判定）

want_eat (优先级 9):
  条件: 饥饿度 > 5
  目标: action_forage_omnivore（拱土找食物）
  效果: 饥饿度 -5

want_drink (优先级 8):
  条件: 口渴度 > 6
  目标: action_go_to_water
  效果: 口渴度 -5

want_sleep (优先级 5):
  条件: 疲劳度 > 7 + 在安全区域
  目标: action_sleep
  效果: 疲劳度 -4

默认: want_wallow_or_roam (优先级 2):
  条件: 没有高优先级目标
  目标: 泥浴（有泥坑时）OR 游荡（没有泥坑时）
```

## 五、野猪的觅食

```
杂食——几乎什么都吃：

  根茎/块茎（拱土挖出来）:
    什么地方: 草地、森林
    效果: 饥饿度 -4
    耗时: 20 Tick（拱土费力）
    野猪的鼻子把草地翻得乱七八糟——这也是它能"整地"的原因
    ← 人类后期可能驯化野猪帮自己翻地

  橡子/坚果（秋天大量）:
    效果: 饥饿度 -3
    耗时: 10 Tick

  腐肉（闻到尸体就来吃）:
    效果: 饥饿度 -5
    耗时: 15 Tick
    野猪不拒绝腐肉——这是它和草食动物的本质区别

  昆虫/蚯蚓:
    效果: 饥饿度 -1
    耗时: 5 Tick
    吃不饱，但可以当零食

  草/嫩叶:
    效果: 饥饿度 -2
    耗时: 15 Tick
    野猪也吃草——但不怎么喜欢

  小动物（偶尔）:
    如果遇到受伤的小动物 → 不吃白不吃
```

## 六、野猪的逃跑/反击策略

```
野猪的核心策略是和狼完全相反的一对:

  狼看到比自己弱的小动物 → 狼主动攻击
  野猪看到狼 → 狼评估: "值得受伤吗？"

野猪的"武器":
  獠牙: 上牙往外翘，是獠牙。冲撞时刺入对方
  体重: 80~150公斤（游戏里抽象为体型=中型）
  冲撞力量: 强大的冲击力，能把人撞翻

野猪的反击判定:
  if 威胁在5格内:
    冲撞 → 命中判定（力量9 → 基础命中率 0.45）
    命中 → 威胁方受到伤害
    未中 → 野猪继续追（不轻易放弃）
  
  if 威胁在5格外:
    警戒（转身面对威胁，发出低吼）→ 不主动追击
  
  if 野猪被多次攻击（HP下降）:
    投降条件: HP < 30% → 可能逃跑
    但之前的攻击已被激怒 → 至少先还击一次再跑

人类猎杀野猪的三种方式:
  1. 潜行 + 背后一箭/一矛 → 野猪没发现就被击杀 ✅
  2. 多人围猎（像狼一样）→ 从多方向同时攻击 → 野猪顾不了头尾
  3. 正面硬刚 → ❌ 极不推荐——野猪会冲过来
```

## 七、繁殖

```
繁殖条件:
  - 任何成年公野猪 + 母野猪
  - 发情季节: 秋末冬初（一年一次）
  - 公野猪之间的争斗可能很激烈（獠牙互刺）

孕期: 约115天（游戏时间，比鹿短）
每胎: 3~8只（和兔子差不多多！）

幼猪:
  0~1个月: 在母野猪用草铺的窝里
  1~3个月: 跟着母野猪到处走，学习拱土
  3~6个月: 半独立，但还跟着母亲
  1岁: 独立

母野猪的护崽:
  幼猪在附近时 → 母野猪攻击性 ×2
  任何人或狼靠近 → 母野猪直接冲撞

幼猪的天敌:
  独狼/狐狸会抓幼猪
  → 母野猪是幼猪的保护伞
```

## 八、野猪与人类

```
野猪对人类的双重意义:

  威胁: 单独的人遇到野猪 → 危险 → 尤其是带崽的母野猪
  食物: 猎杀成功 → 生肉×4 + 皮毛 + 獠牙 → 产出比鹿还多

  破坏: 野猪拱土 → 破坏农作物（后期种地时需要防范）
  翻地: 被驯化的家猪拱土 → 可以帮人翻地准备耕种

  驯化: 抓幼猪养大 → 长大后变成[家猪] → 不再攻击人
        → 产出生肉量大 → 非常重要的肉食来源
        → 这是人类从狩猎转向饲养的关键一步

野猪的象征意义（在游戏世界里）:
  - 猎到一头野猪 → 全村能吃好几天
  - 被野猪杀死 → 村里的故事（"他太大意了"）
  - 驯化第一头野猪 → 文明的里程碑
```
