## 一、设计定位：动物是"弱化版NPC"

动物不是人，不需要整套34维性格。但它们在引擎框架里**走同一个决策循环**——只是欲望更简单、指令更少、没有社交关系。

```
动物的引擎循环（与NPC一致）：
  感知 → 欲望计算 → 选最高分 → 执行指令 → 效果结算

区别在于：
  动物只有"生理驱动"（饿→找食物，困→睡觉，发情→繁衍）
  没有"高阶需求"（不想赚钱、不想上学、不想写诗）
```

## 三、动物参数（简化版NPC参数）

> ⚠️ v3.0 关键修正：动物和数据必须与人类共用同一套引擎数据结构。
> 动物特有的字段放在 `NPC.动物数据` 和 `NPC.感知结果` 下——这两个是人类 NPC 也都有的字段，
> 只是人类的 `动物数据` 都是 null/默认值，感知结果由同一个 Step 2 写入。

```
interface Entity {  // 人类和动物的统一接口
  id: string;
  类型: "人类" | "动物";
  
  // === 共用的生理状态 ===
  生理状态: {
    饥饿度: number;    // 1-10
    口渴度: number;    // 1-10
    疲劳度: number;    // 1-10
    健康度: number;    // 1-10
    是否发情: boolean; // 动物繁殖季，人类始终=false
  };
  
  // === 共用的感知结果（Step 2 写入，所有实体通用） ===
  感知结果: {
    看到捕食者: boolean;     // 任何实体都能有——人看到狼也是"看到捕食者"
    闻到捕食者: boolean;
    闻到狼: boolean;         // 鹿/兔子特有感知
    震动感知触发: boolean;    // 兔子特有
    附近有猎物: boolean;
    发现大型猎物: boolean;
    威胁在5格内: boolean;
    威胁在10格内: boolean;
    首领在移动: boolean;
    同群在逃跑: boolean;      // 鹿群从众逃跑
    巢穴距离: number;        // -1 表示不知道
    窝距离: number;
    同群距离: number;
    附近同群数量: number;
  };
  
  // === 动物专属数据（人类也有一份，全部=默认值） ===
  动物数据: {
    物种: string;            // "人类" | "狼" | "兔子" | "鹿" | "野猪"
    体重: "小型" | "中型" | "大型";  // 人类="中型"
    角色?: "首领" | "Beta" | "Omega" | "幼崽";  // 人类=undefined
    进食顺序?: number;       // 人类=undefined
    带幼崽: boolean;         // 人类=false
    距上次巡逻: number;      // 人类=0
    狼群ID?: string;         // 人类=undefined
    鹿群ID?: string;         // 人类=undefined
  };
  // ⚠️ 动物数据永远不为 null。人类的.物种="人类"，其余字段设默认值。
  // 这样 ConditionEvaluator 读 NPC.动物数据.xxx 时不会崩溃。
  
  当前位置: [number, number];
  当前动作: string;
  标签: string[];           // [在安全区域] 等
}
```

**关键**：`NPC.感知结果.xxx` 和 `NPC.动物数据.xxx` 是两个标准字段路径，ConditionEvaluator 通过统一的点号嵌套路径解析它们。
人类 NPC 的 `动物数据 = null`，不影响任何计算。动物的 `感知结果` 字段由 Step 2 感知系统统一填充，跟人类用同一个代码路径。

## 四、动物行为：欲望循环

### 4.1 野生动物

```
自由状态下的欲望循环：

  want_eat(饥饿>5)
    → 分物种：
        兔子 → 采集草/浆果
        鹿   → 吃草/灌木
        狼   → 狩猎小动物
    → 移动到食物地点 → 进食 → 饥饿-4

  want_sleep(疲劳>7)
    → 移动到安全区域（树林/洞窟）
    → 睡觉 → 疲劳恢复

  want_breed(发情+附近有同类异性)
    → 走向对方 → 繁衍
    → 母体-怀孕判定 → 孕期-分娩

  want_flee(感知到威胁)
    → 检测到有人在攻击/靠近
    → 选择反方向逃跑
    → 食肉动物可能反击而非逃跑

  want_wander(无欲望)
    → 随机走动（半径10格）
    
---

```

  对抗猎物：
    如果狼群中任一只发现猎物→其他狼也加入追击
    群体作战判定：
      狼的数量 >= 猎物体型×1.5 → 攻击
      狼的数量太少   → 不攻
    攻击目标优先：受伤的/年幼的/落单的

  对抗威胁：
    如果一只狼受攻击→附近的同伴赶来帮忙
    群体中至少需要2只狼在场→才敢主动攻击人

  群体感知共享：
    狼群在地图上有[狼群区域]（群体常驻地）
    狼群不会无限扩张——一个区域同时只有一个狼群

    NPC遇到狼的危险评估：
      看到1只狼         → 轻度威胁（可能只是斥候）
      看到2~3只并行的   → 危险（成双成对出现，群体不远）
      看到4+只          → 极其危险（不要硬碰硬）
```

## 五、人与动物的交互

### 5.0 捕食者攻击公式（v3.1 新增）

> 所有捕食者（人类、狼）对猎物（兔子、鹿、野猪）的攻击使用同一个公式。
> 人类狩猎和狼群围猎的区别在于"武器加成"和"围猎系数"，不在核心公式。

```
攻击命中率 = 力量/10 × 0.4 + 敏捷/10 × 0.3 + 武器加成 × 0.3

  力量/10 × 0.4:
    狼力量=7 → 0.28
    野猪力量=9 → 0.36（野猪反击时也用这个公式）
    人类力量=7 + 石刀 → 0.28 + 0.15 = 0.43
  
  敏捷/10 × 0.3:
    狼敏捷=6 → 0.18
    兔子敏捷=9 → 0.27（兔子不攻击，但逃跑用的敏捷值）

  武器加成 × 0.3:
    徒手（狼/野猪牙齿）: 0.3 → 总加成 0.09
    石刀: 0.5 → 总加成 0.15
    矛: 0.7 → 总加成 0.21
    弓箭: 0.9 → 总加成 0.27

围猎加成（仅当多只狼同时攻击同一猎物）:
  2只狼: 命中率 × 1.1
  3只狼: × 1.2
  5+只狼: × 1.3
  ← 猎物顾不过来多个方向

猎物体型惩罚:
  小型（兔子/鸡）: 命中率 × 1.2（容易打中）
  中型（鹿/野猪/狼）: × 1.0
  大型（牛）: × 0.8（皮厚难伤）

致伤/致死:
  命中 → 对猎物造成伤害（HP扣减）
  小型猎物（兔子/鸡）: 一击必杀
  中型猎物（鹿/野猪）: 需要2~4击
  大型猎物（牛）: 需要5+击

  猎物 HP < 30% → 狼群判定: 继续追
  猎物 HP < 10% → 猎物开始踉跄（移速-50%）→ 捕食者追上 → 死亡

此公式统一覆盖:
  狼→兔子、狼→鹿、狼→野猪、人→兔子、人→鹿、人→野猪、猪→人/狼（反击）
```

### 5.1 狩猎（初始获取肉食）

```
NPC想打猎 → 需要：
  武器：石刀/弓箭/长矛
  或合作：多人围猎提高成功率

狩猎过程（不是一发判定，是多步骤的追逐过程）：

Step 1：发现猎物
  视觉半径内出现[可狩猎]标签的动物

Step 2：靠近
  NPC移到猎物附近 → 进入射程/攻击范围

Step 3：追逐判定（猎物逃跑）
  猎物感知到威胁 → 逃跑
  NPC追上去

  追逐的核心机制 = 体力消耗与恢复（见下方"体力与追逐"系统）
    短跑：体力快速下降，但有机会追上
    追不上：体力耗尽 → 动物逃脱 → 狩猎失败
    追上了：近距离判定攻击

Step 4：攻击判定
  命中率 = 力量/10 × 0.4 + 敏捷/10 × 0.3 + 武器×0.3
  成功 → 造成伤害 → 动物受伤/死亡
  失败 → 动物可能反击（如果它是猪/狼）

Step 5：收获
  动物死亡 → 尸体出现 → NPC可采集肉、皮、骨等
```

#### 体力与追逐系统（新增！）

```
NPC的当前体力（在"身体力"的基础上管理的）：

体力 = 基础体力上限（来自身体素质中的耐力）
快跑：
  每秒消耗体力 = 2点
  速度 = NPC移速×1.5

慢走：
  每秒消耗体力≈ 0.5点
  速度 = NPC标准移速

静立/休息：
  每秒恢复体力 = 1点
  速度 = 0

追逐机制：
  兔的速度：比走的快的人快→人需要跑才能追上

  例：
    NPC移速6，兔子速度8
    NPC需要快跑(9)才能追上 → 每秒体力-2
    如果NPC体力=8 → 4秒后体力耗尽 → 追不上了
    如果NPC体力=14 → 7秒后体力耗尽 → 但也有机会在这7秒内追上
    
  追逐结果：
    如果NPC够快→移动距离差小于0→该Tick攻击
    如果NPC体力耗尽→停→动物逃跑了
    如果NPC放弃→狩猎失败
```

狩猎和追逐全部走引擎的通用指令：
  `cmd_快跑` → 快速移动 + 体力消耗
  `cmd_攻击目标` → 伤害判定
  `cmd_行走` → 正常移动 + 体力微小消耗
  （这些都是模块库中已有的移动类/判定类指令）

### 5.2 驯化（从野生到圈养）

```
NPC发现野生动物 → 可以尝试驯化

驯化条件：
  目标动物：野兔、野羊、野猪……（可驯化物种）
  需要的工具：绳子/网/诱饵
  判定：
    驯化成功 = 动物年龄越轻(幼年) → 基础模式30%
              年龄越大→ 基础模式5%
              + 捕猎技能高 → 提高成功率
              + 人手多→ 提高

  成功 → 该动物转入"圈养"模式 → [家畜]标签
  失败 → 动物逃跑
```

### 5.3 饲养

```
圈养动物每天需要：
  食物(草/饲料)：有专门的饲料物品 → 主人需要备料
  水：在水域旁/提供水槽
  清洁：需要定期清理圈舍
  繁殖：异性的同类在圈养中+发情→ 可生育

产出的获取：
  鸡：每天检查→可能有蛋 → 捡起来 → 物品:鸡蛋
  羊：每季节→ 剪毛 → 物品:羊毛
  牛：每天检查→ 挤奶 → 物品:牛奶
  屠宰：动物死亡 → 尸体 → 获得肉/皮毛
```

### 5.4 交易

```
动物可以买卖：
  卖动物：圈养的动物可以卖给别人
  卖产出：鸡蛋/牛奶/羊毛/肉 可以卖
  价格受市场波动影响
```

## 六、动物繁殖

```
动物繁殖条件：
  1. 两只异性同种动物
  2. 都在发情期(季节性)
  3. 母亲没有怀孕
  4. 母亲健康>=5

繁殖产物：
  下崽数量视物种：鸡1~5个蛋、羊1~2只、猪3~8只、马1只、牛1只
  幼崽：初始年龄=0岁，半年后达到成年
```

## 七、动物死亡

```
死亡原因：
  老死：年龄>=物种寿命 → 自然死亡
  被猎杀：被NPC攻击致死
  被食肉动物杀死：狼吃兔子等
  饿死/病死：同NPC逻辑
  自然捕食：狼在[有肉食动物]地形可能攻击圈养动物

尸体产物：
  尸体停留N天腐烂 → 可采集 [肉,皮毛,骨骼,羽毛,…]
  之后消失
```

## 十、动物感知系统（v2.0 新增）

> ⚠️ 每种动物的感官能力不同——这是狩猎策略的核心。

### 10.1 各物种感知参数

| 物种 | 视觉半径 | 听觉半径 | 嗅觉半径 | 震动感知 | 潜行减免 |
|:-----|:-------:|:-------:|:-------:|:-------:|:-------:|
| 人类（基准） | 20格 | 30格 | 10格 | 无 | — |
| **野兔** | 15格 | **40格** | 20格 | **10格** | 震动-8格 |
| **野鹿** | **25格** | 35格 | 25格 | 8格 | 震动-6格 |

### 10.2 震动感知

兔子的大耳朵和敏锐触觉能感觉到地面的轻微震动。在游戏里模拟为：

```
震动感知（仅兔子、鹿、野猪有）:

  检测条件:
    附近有人/动物在移动 → 按移动速度计算震动
  
  震动半径计算:
    实际震动半径 = 基础震动感知 × (移动方速度 / 正常速度)
    
    例: 兔子震动感知=10格
      人正常走（速度×1.0） → 震动半径 = 10格
      人快跑（速度×1.5）   → 震动半径 = 15格 ← 20格外就知道有东西在跑
      人潜行（速度×0.3）   → 震动半径 = 3格  ← 几乎贴脸才发现
      人静止               → 震动半径 = 0格  ← 完全感觉不到

  猎物反应:
    震动感知触发 → 猎物警觉 → 抬起头、停止进食
    → 如果震动持续+靠近 → 触发 want_flee
    → 如果震动消失 → 恢复进食状态
```

### 10.3 潜行狩猎（v2.0 新增）

猎人通过降低速度来减少被猎物感知的概率：

```
潜行模式（NPC 可以选择）:
  速度: 标准移速 × 0.3
  体力消耗: 慢走级别（每Tick -0.2）
  
  对猎物感知的减免:
    震动感知: 半径 -8格（兔子几乎贴身才发现）
    听觉半径: ×0.5（走路轻声）
    视觉半径: ×0.5（但如果猎人躲在树/灌木后→再×0.5）
  
  适用场景:
    靠近兔子/鹿等警觉猎物
    兔子喝水时（分心→感知-30%）更易靠近

正常行走:
  无减免 → 猎物在标准距离内发现猎人

快跑:
  震动感知半径 ×2（远处的猎物全跑了！）
  适合: 猎物已经发现猎人，开始逃跑时才冲刺追逐
```

### 10.4 狩猎策略决策

```
NPC Step 4 欲望计算 → want_hunt 触发:

  1. 靠近猎物 — 目标: 降低距离到攻击范围内
  
  2. NPC 的性格影响接近方式:
     身手敏捷 >= 7 → 倾向潜行（"我敏捷高，能悄悄靠近"）
     力量 >= 7 → 倾向直接冲（"我力气大，追得上"）
     智商 >= 6 → 会根据猎物类型选择策略:
       兔子/鹿 → 潜行（知道这些猎物警觉）
       野猪 → 多人围猎或直接上（野猪不跑，但会反击）
  
  3. 接近到攻击范围（1~2格）→ 突然冲刺 → 攻击判定
     ← 冲刺瞬间猎物才开始检测（已经没有时间逃跑了）
  
  4. 攻击命中 → 猎物受伤/死亡 → 生成尸体（死亡系统 §3.1.6）
  
  5. 攻击未中 → 猎物受惊 → 逃跑（进入追逐判定）
```

## 十二、狼群嚎叫通讯（v2.0 新增）

> 狼没有知识库，没有善恶。它们通过**嚎叫**共享信息——这是物理传播，不是魔法。

```
狼A 发现猎物 → 触发生理本能: 嚎叫

嚎叫行为:
  产生听觉事件:
    { 类型:"狼嚎", 来源:狼A, 内容:"发现猎物", 目标位置:[120,85], 半径:40格 }

同群狼B（在25格外）→ Step 2.5 感知到嚎叫:
  听到内容 + 位置 → 当前目标中断 → 向 [120,85] 移动
  → 到了之后狼B自己的眼睛能看到猎物 ← 不是魔法，是"收到通知后自己去看"

同群狼C（在50格外）→ 超过40格半径 → 没听到 → 无事发生

狼群的群内判定:
  如果多只狼在同一区域（距离<30格）→ 属于同一群
  一狼嚎叫 → 40格内同群狼都响应

对抗猎物时:
  狼群数 >= 猎物体型×1.5 → 攻击
  狼群数 < 猎物体型×1.5 → 不主动攻击，跟踪等待时机

对抗人类时:
  狼群数 >= 3 → 才敢主动攻击单独的人类
  如果人类在挥舞火把/站在火堆旁 → 狼不靠近
```

## 十三、人与动物的交互（重新组织）

### 13.1 狩猎追逐时序修正（v2.0）

> ⚠️ 修复 Step 2.5（动物行动）在 Step 5（NPC 行动）之前的问题。

```
原问题: 每Tick:
  Step 2.5: 兔子检测到威胁 → 逃跑
  Step 5: 猎人移动 → 兔子已经不在原来的位置了
  → 兔子永远比猎人快一步，永远追不上

修正方案: 同一Tick内按"接近距离"分阶段处理:

  如果猎人距离猎物 > 3格（尚未进入攻击范围）:
    Step 2.5: 猎物检测威胁 → 如果感知到了 → 逃跑
    Step 5: 猎人根据猎物新位置移动
    → 这是追逐阶段，猎物先手是合理的

  如果猎人距离猎物 <= 3格（已进入冲刺范围）:
    Step 5 先于 Step 2.5 执行 ← 猎人冲刺先于猎物反应
    → 猎人冲刺攻击 → 如果命中 → 猎物受伤/死亡
    → Step 2.5: 如果猎物没死 → 才开始逃跑

潜行接近:
  猎人以潜行模式接近到 1~2格内
  → 猎物没感知到 → Step 5: 猎人突然冲刺攻击 → 猎物来不及反应
```
