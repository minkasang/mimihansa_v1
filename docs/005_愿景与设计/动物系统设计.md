# 动物系统设计

> 设计师口述 → AI整理结构化 → 设计师检查确认
> ⚠️ 规范研究文档，不映射当前代码

## 一、设计定位：动物是"弱化版NPC"

动物不是人，不需要整套34维性格。但它们在引擎框架里**走同一个决策循环**——只是欲望更简单、指令更少、没有社交关系。

```
动物的引擎循环（与NPC一致）：
  感知 → 欲望计算 → 选最高分 → 执行指令 → 效果结算

区别在于：
  动物只有"生理驱动"（饿→找食物，困→睡觉，发情→繁衍）
  没有"高阶需求"（不想赚钱、不想上学、不想写诗）
```

## 二、动物类型

### 2.1 野生动物（不归任何人）

| 动物 | 标签 | 用途 | 攻击性 | 出没地形 |
|:-----|:----|:-----|:-----|:---------|
| 野兔 | `[野生]` `[小动物]` `[可狩猎]` | 肉+1、毛皮 | 无 | 草地、森林 |
| 野鹿 | `[野生]` `[中型动物]` `[可狩猎]` | 肉+3、鹿角 | 无（会逃跑） | 森林 |
| 野猪 | `[野生]` `[中型动物]` `[可狩猎]` | 肉+4 | 会反击 | 森林、山地 |
| 狼 | `[野生]` `[食肉]` `[群居]` `[危险]` `[可狩猎]` | 肉+5、狼皮(贵重)、偶尔可猎但风险极高 | 会主动攻击弱小、受群体制约 | 森林、山地 |
| 飞鸟 | `[野生]` `[飞行]` `[难以狩猎]` | 几乎不可猎 | 无 | 全地形（天空） |
| 鱼 | `[野生]` `[水生]` `[可钓鱼]` | 鱼+1 | 无 | 水域 |

### 2.2 家畜/家禽（被驯养）

| 动物 | 标签 | 产出 | 寿命 | 饲养难度 |
|:-----|:----|:-----|:-----|:-------|
| 鸡 | `[家禽]` `[小型]` | 鸡蛋(每1~2天1枚) | 5~8年 | 简单 |
| 鸭 | `[家禽]` `[小型]` | 鸭蛋+羽毛 | 5~8年 | 简单 |
| 羊 | `[家畜]` `[中型]` | 羊毛(每季)、羊肉 | 10~12年 | 中等 |
| 猪 | `[家畜]` `[中型]` | 猪肉(屠宰) | 12~15年 | 中等 |
| 牛 | `[家畜]` `[大型]` | 牛奶(每天)、耕作用 | 15~20年 | 较难 |
| 马 | `[家畜]` `[大型]` `[可骑乘]` | 交通工具 | 20~25年 | 难 |

### 2.3 宠物（被饲养，无经济产出）

| 动物 | 标签 | 作用 | 寿命 |
|:-----|:----|:-----|:-----|
| 狗 | `[宠物]` `[护卫]` | 陪伴(NPC开心+1/周)、看家(报警) | 10~15年 |
| 猫 | `[宠物]` `[捕鼠]` | 陪伴、减少粮食被鼠吃 | 12~18年 |

## 三、动物参数（简化版NPC参数）

```
interface Animal {
  物种: string;           // 例如 "鸡"、"马"
  名称: string;           // 如果有名字的话，否则用物种名
  性别: '公' | '母';
  年龄: number;           // 岁
  预期寿命: number;       // 此物种的标准寿命
  
  生理状态: {
    饥饿度: 1-10;        // 和NPC一样
    疲劳度: 1-10;
    健康度: 1-10;
    是否发情: boolean;   // 每季判定一次
  };
  
  当前状态: '自由' | '圈养' | '跟随' | '战斗' | '休息';
  所有者ID: string|null;  // 无人拥有 = 野生动物
  当前位置: [x,y];
  
  可产出: string[];       // ['肉','皮革','羊毛','牛奶','蛋',...]
}
```

动物**不需要**：性格维度、好感度、知识库、记忆、职业、书生气、色欲…（这些只有人需要）

## 四、动物行为：欲望循环

### 4.1 野生动物

```
自由状态下的欲望循环：

  want_eat(饥饿>5)
    → 分物种：
        兔子 → 采集草/浆果
        鹿   → 吃草/灌木
        狼   → 狩猎小动物
    → 移动到食物地点 → 进食 → 饥饿-4

  want_sleep(疲劳>7)
    → 移动到安全区域（树林/洞窟）
    → 睡觉 → 疲劳恢复

  want_breed(发情+附近有同类异性)
    → 走向对方 → 繁衍
    → 母体-怀孕判定 → 孕期-分娩

  want_flee(感知到威胁)
    → 检测到有人在攻击/靠近
    → 选择反方向逃跑
    → 食肉动物可能反击而非逃跑

  want_wander(无欲望)
    → 随机走动（半径10格）
    
---

#### 狼的群体行为（特殊）

狼是【群居】动物，行为不同于独居动物：

```
每只狼属于一个狼群（系统维护狼群列表）

狼群行为：
  狼群的核心 = 一群3~8只狼共享一个群体认知

  对抗猎物：
    如果狼群中任一只发现猎物→其他狼也加入追击
    群体作战判定：
      狼的数量 >= 猎物体型×1.5 → 攻击
      狼的数量太少   → 不攻
    攻击目标优先：受伤的/年幼的/落单的

  对抗威胁：
    如果一只狼受攻击→附近的同伴赶来帮忙
    群体中至少需要2只狼在场→才敢主动攻击人

  群体感知共享：
    狼群在地图上有[狼群区域]（群体常驻地）
    狼群不会无限扩张——一个区域同时只有一个狼群

    NPC遇到狼的危险评估：
      看到1只狼         → 轻度威胁（可能只是斥候）
      看到2~3只并行的   → 危险（成双成对出现，群体不远）
      看到4+只          → 极其危险（不要硬碰硬）
```
```

### 4.2 家畜（圈养中）

```
圈养中的简单循环：

  want_eat(饥饿>3)
    → 如果有饲料(主人喂的) → 吃
    → 如果圈养 → 不会自己找
    → 如果放养 → 自己在附近采食

  want_sleep(疲劳>7)
    → 回到圈舍 → 睡觉

  want_breed(有异性同类在圈养中)
    → 繁衍
```

### 4.3 宠物

```
  狗：
    跟随主人移动（半径5格内）
    如果有陌生人靠近 → 叫（警告）
    如果主人被攻击 → 帮忙攻击对方
    
  猫：
    随机走动（带捕鼠判定）
    抓老鼠 → 减少老鼠数量
    陪伴主人 → 主人开心值小增
```

## 五、人与动物的交互

### 5.1 狩猎（初始获取肉食）

```
NPC想打猎 → 需要：
  武器：石刀/弓箭/长矛
  或合作：多人围猎提高成功率

狩猎过程（不是一发判定，是多步骤的追逐过程）：

Step 1：发现猎物
  视觉半径内出现[可狩猎]标签的动物

Step 2：靠近
  NPC移到猎物附近 → 进入射程/攻击范围

Step 3：追逐判定（猎物逃跑）
  猎物感知到威胁 → 逃跑
  NPC追上去

  追逐的核心机制 = 体力消耗与恢复（见下方"体力与追逐"系统）
    短跑：体力快速下降，但有机会追上
    追不上：体力耗尽 → 动物逃脱 → 狩猎失败
    追上了：近距离判定攻击

Step 4：攻击判定
  命中率 = 力量/10 × 0.4 + 敏捷/10 × 0.3 + 武器×0.3
  成功 → 造成伤害 → 动物受伤/死亡
  失败 → 动物可能反击（如果它是猪/狼）

Step 5：收获
  动物死亡 → 尸体出现 → NPC可采集肉、皮、骨等
```

#### 体力与追逐系统（新增！）

```
NPC的当前体力（在"身体力"的基础上管理的）：

体力 = 基础体力上限（来自身体素质中的耐力）
快跑：
  每秒消耗体力 = 2点
  速度 = NPC移速×1.5

慢走：
  每秒消耗体力≈ 0.5点
  速度 = NPC标准移速

静立/休息：
  每秒恢复体力 = 1点
  速度 = 0

追逐机制：
  兔的速度：比走的快的人快→人需要跑才能追上

  例：
    NPC移速6，兔子速度8
    NPC需要快跑(9)才能追上 → 每秒体力-2
    如果NPC体力=8 → 4秒后体力耗尽 → 追不上了
    如果NPC体力=14 → 7秒后体力耗尽 → 但也有机会在这7秒内追上
    
  追逐结果：
    如果NPC够快→移动距离差小于0→该Tick攻击
    如果NPC体力耗尽→停→动物逃跑了
    如果NPC放弃→狩猎失败
```

狩猎和追逐全部走引擎的通用指令：
  `cmd_快跑` → 快速移动 + 体力消耗
  `cmd_攻击目标` → 伤害判定
  `cmd_行走` → 正常移动 + 体力微小消耗
  （这些都是模块库中已有的移动类/判定类指令）

### 5.2 驯化（从野生到圈养）

```
NPC发现野生动物 → 可以尝试驯化

驯化条件：
  目标动物：野兔、野羊、野猪……（可驯化物种）
  需要的工具：绳子/网/诱饵
  判定：
    驯化成功 = 动物年龄越轻(幼年) → 基础模式30%
              年龄越大→ 基础模式5%
              + 捕猎技能高 → 提高成功率
              + 人手多→ 提高

  成功 → 该动物转入"圈养"模式 → [家畜]标签
  失败 → 动物逃跑
```

### 5.3 饲养

```
圈养动物每天需要：
  食物(草/饲料)：有专门的饲料物品 → 主人需要备料
  水：在水域旁/提供水槽
  清洁：需要定期清理圈舍
  繁殖：异性的同类在圈养中+发情→ 可生育

产出的获取：
  鸡：每天检查→可能有蛋 → 捡起来 → 物品:鸡蛋
  羊：每季节→ 剪毛 → 物品:羊毛
  牛：每天检查→ 挤奶 → 物品:牛奶
  屠宰：动物死亡 → 尸体 → 获得肉/皮毛
```

### 5.4 交易

```
动物可以买卖：
  卖动物：圈养的动物可以卖给别人
  卖产出：鸡蛋/牛奶/羊毛/肉 可以卖
  价格受市场波动影响
```

## 六、动物繁殖

```
动物繁殖条件：
  1. 两只异性同种动物
  2. 都在发情期(季节性)
  3. 母亲没有怀孕
  4. 母亲健康>=5

繁殖产物：
  下崽数量视物种：鸡1~5个蛋、羊1~2只、猪3~8只、马1只、牛1只
  幼崽：初始年龄=0岁，半年后达到成年
```

---

## 七、动物死亡

```
死亡原因：
  老死：年龄>=物种寿命 → 自然死亡
  被猎杀：被NPC攻击致死
  被食肉动物杀死：狼吃兔子等
  饿死/病死：同NPC逻辑
  自然捕食：狼在[有肉食动物]地形可能攻击圈养动物

尸体产物：
  尸体停留N天腐烂 → 可采集 [肉,皮毛,骨骼,羽毛,…]
  之后消失
```

## 八、动物在引擎中的位置

动物也走引擎的统一循环，只是简化的：

```
引擎循环
  ├── [数据加载器] ← 新增: Animals_Library.json (定义物种/属性/产出)
  │
  ├── [每Tick循环]
  │   环境感知(和NPC一样) → 看/听/闻
  │   动物生理推进         → 饥饿/疲劳/发情
  │   动物欲望评估器       → 读动物欲望库 → 计算动物适用欲望
  │   ↓ (权重最高者)
  │   行动执行(较简单的移动/进食/逃跑指令)
  │
  ├── [周期钩子]
  │   动物事件检测器 → 出生/死亡/发情/被猎杀
  │
  └── 人和动物的交互钩子
      狩猎/驯化/饲养/骑乘
```
