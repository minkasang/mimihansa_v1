## 一、初始家当：始祖NPC不是两手空空

### 1.1 理念

始祖村民像迁徙部落一样，每个人都带一点东西进来——不是凭空变出来，是"路上带来的"。这样第一天就不用从零开始了。

### 1.2 始祖NPC的初始物品

```
每个始祖NPC随机获得1~2件：
  {物品: "麦种×10", 概率: 60%}       // 大部分人带了种子
  {物品: "石头", 概率: 80%}           // 几乎都有
  {物品: "干粮×2", 概率: 50%}         // 路上吃剩的
  {物品: "空葫芦", 概率: 30%}         // 天然容器
  {物品: "绳子", 概率: 20%}           // 少数人有
  {物品: "遮布", 概率: 10%}           // 极少数有布
```

## 二、种田：从野麦到粮仓

### 2.1 作物

| 作物 | 生长季 | 生长天数 | 产出 | 种子来源 |
|:-----|:-----|:--------|:-----|:--------|
| 小麦 | 春、秋 | 约100天 | 麦穗×3~5 | 初始携带/采集野麦 |
| 黄瓜 | 春、夏 | 约60天 | 黄瓜×2~3 | — |
| 西红柿 | 春、夏 | 约70天 | 西红柿×2~4 | — |

### 2.2 野麦采集

```
春天草地、田野地形有概率出现[野麦]资源点
NPC可执行 action_collect_wild_wheat → 获得"野麦种子×1~3"
收集10颗种子 → 足够种一小块田
```

### 2.3 种田的完整五步

```
Step1 - 开垦（耕地）
  前提：有一块空地（草地/已清理的树林）
  工具：锄头/简易铲/石刀
  动作：CMD_耕地(位置)
  耗时：4小时/格
  产出：该格变为[耕地]状态

Step2 - 播种
  前提：手上有种子
  动作：CMD_播种(位置, 作物类型, 种子个数)
  耗时：1小时/格
  产出：该格变为[已播种:小麦]

Step3 - 浇水
  前提：附近有水源
  动作：CMD_浇水(位置)
  工具：无→用葫芦/碗
  耗时：2小时/格
  效果：水分+50%（基础）

Step4 - 施肥（可选，提高产量）
  前提：手上有肥料
  动作：CMD_施肥(位置)
  耗时：1小时/格
  效果：生长速度×1.3，产出+30%

Step5 - 收获
  前提：生长天数完成
  动作：CMD_收获(位置)
  耗时：3小时/格
  产出：小麦×随机(最低,最高)
```

### 2.4 作物生长模型

```
每格[已播种]状态存储：
  生长进度: 0~100%
  水分: 0~100%
  肥料: 0~100%

每天结算：
  生长进度 += 基础速度 × 水分系数 × 肥料系数
  
  水分系数：
    水>=60% → ×1.0
    水30-60% → ×0.7
    水<30% → ×0.3
  
  基础速度（游戏内每天）：
    小麦：1%
    黄瓜：1.5%
    西红柿：1.2%
  
  如果有施肥：
    肥料>=30% → ×1.3
  
  每天水分衰减：-8%（干旱→-15%）

  雨天：
    水分回满
```

### 2.5 种田由谁做

```
欲望触发：want_tend_crops（欲望库里已有）
触发条件：手上有种子 + 当前有空土地 + NPC勤奋≥4
或：看到别人在种田 → "我也想种"（社会影响）
```

## 三、食物储藏与保质期

### 3.1 食物会烂

```
每件食物物品有：
  → 收获日期
  → 腐烂天数（不同食物不同）

腐烂机制：
  腐烂天数 = 基础腐烂速度 × 季节系数

季节系数：
  春 → ×1.0
  夏 → ×1.5（夏天烂得快！）
  秋 → ×1.0
  冬 → ×0.3（冬天几乎不烂）

食物腐烂比较：
  野果   → 2~4天
  生肉   → 1.5~2天（很快！）
  烤肉   → 3~5天
  麦子   → 几个月（不易烂）
  鸡蛋   → 7天
  牛奶   → 2天
```

### 3.2 仓库

```
仓库是一个建筑，可以建在自家院子旁：
  材料：木材×15（简易原木仓库）
  建造耗时：2~3天
  效果：
    所有放在仓库内的食物，腐烂速度×0.5（比在外面存放更持久）
    仓库有偷盗保护（外人看不到内部）
    仓库容量：最多20个食物物品
```

## 四、院子与围栏

### 4.1 院子的形成

NPC建好房子后 → 可能建院子（不是必须，按性格走）

```
NPC想要院子 → 触发 desire_build_fence

条件：
  已有房子 → 基础驱动力
  性格主动性高(行动意愿≥6)→ 更想建
  看到邻居有院子 → "我也想要"（参照效应）

院子的大小：
  参照机制（简化）：
    只要有一两个邻居有院子 → 后来人就参考邻居的大小 = "差不多那么大就行"
    没有邻居(第一个建的人) → 按默认：
      主动性高 → 院大一点(5×5～8×8)
      主动性低 → 院小一点(3×3～5×5)
```

### 4.2 围栏的建造

```
围栏用什么做：
  树枝围栏   → 材料：木材×1/格（木头并排插地上）
  石墙       → 材料：石头×2/格（垒起来）

围栏的动作流程：
  CMD_建造围栏(位置, 长度, 材料类型)
  → NPC沿着院子边界线一格一格摆放围栏
  → 形成闭合或部分闭合的圈

围栏的属性：
  体积 = 1（占一格）
  高度 = 1~2（人能跨过去，牲畜不能）
  碰撞 = 阻挡动物通行
  可见 = 是
```

### 4.3 围墙的体积碰撞（新增物理）

```
地图上每个物品都有体积：
  - 空气格：体积=0
  - 围栏/墙：体积=1
  - 房屋：体积=占地面积
  - 动物：体积=体型（小=1，中=2，大=3）

阻挡逻辑：
  任何Agent（人/动物）移动时：
    检查目标格是否有阻挡
    如果阻挡体积 > Agent.体型 → 无法穿过
    如果阻挡体积 <= Agent.体型 → 可以跨过（人能跨矮栏，牛跨不过）

例：
  兔子穿过围栏 → 体积1对体积1 → 能过（兔子钻过去）
  牛穿过围栏 → 体积3对体积1 → 能过（牛推倒！）
  → 需要石墙才能挡牛（体积2的石墙）
```

## 五、扩建

NPC可以对已有建筑进行扩建（不是推倒重来）

```
扩建的触发：
  需求型：家太小了(有了新孩子、结婚后俩人的东西放不下)
  攀比型：邻居的房子更大更气派

扩建动作：
  选择一面墙 → 向外扩N格 → 需要N×材料+时间
  
扩建做出来的房子形状：
  → 不规则也无妨
  → NPC不知道怎么"设计美观的"
  → 能住就行
```

## 六、季节与天气

### 6.1 四季模型

```
一年 = 365游戏天
春：0~90天   气温 10~20°C  野果多 动物活跃  可播种
夏：91~180天 气温 25~35°C  食物烂得快 雨水多  可播种
秋：181~270天气温 10~20°C  收获季 野果少 动物在为冬天储备
冬：271~365天气温 -5~5°C   野果无 动物稀少 可播种(需保暖物)
```

### 6.2 季节影响

| 受季节影响的 | 春 | 夏 | 秋 | 冬 |
|:------------|:--:|:--:|:--:|:--:|
| 野果数量 | 多 | 多 | 少 | 无 |
| 动物活跃度 | 高 | 高 | 中 | 低(冬眠) |
| 食物腐烂速度 | 正常 | 快(×1.5) | 正常 | 极慢(×0.3) |
| 口渴速度 | 正常 | 快(热) | 正常 | 慢 |
| 可播种 | 是 | 是 | 是 | 否 |
| 遮蔽需求 | 低 | 低(热) | 中 | 高(必须遮蔽，不然冷) |

### 6.3 气候/温度

```
温度决定NPC的保暖需求：
  温暖(>15°C)→无需遮蔽
  凉(5-15°C)→火堆可暖
  冷(-5~5°C)→需要房子内+火堆
  极冷(< -5°C)→如果露宿→健康快速下降
```

## 七、钓鱼

### 7.1 三种钓鱼方式

| 方式 | 需要什么 | 成功率 | 产出 |
|:-----|:---------|:-----|:-----|
| 徒手捉 | 敏捷≥6 | 低(15%) | 1条小鱼 |
| 鱼竿 | 木杆+线+钩 | 中(35%) | 1~2条 |
| 网 | 绳子×3 | 高(55%) | 3~5条 |

### 7.2 鱼竿制作

```
材料：木材×1 (杆) + 绳子×1 (线) + 铁钩×1
铁钩的来源：
  → 铁匠铺锻造（需要铁矿石+生火）
  → 或用骨头代替（效率更低）
```

## 八、铁匠铺

```
铁匠铺是一个建筑 + 一个职业

建筑要求：
  铁匠铺 → 材料：石头×10+木材×5+火炉区
  需要火源（持续燃料）

铁匠动作：
  CMD_打铁 → 铁矿石×1 → 铁锭×1（生火+3小时）
  CMD_打造铁钩 → 铁锭×1 → 铁钩×2

铁匠铺收费：
  有人来定制 → 铁匠按自己的定价(要价公式)
  这个价跟着市场波动，由他性格决定
```

## 九、冲突与基础战斗

### 9.1 最简单的战斗

```
两个人发生冲突 → 进入[战斗]状态

战斗 = 回合制推演（每Tick一轮）
  双方各打一拳（CMD_攻击）
  
  攻击判定：
    命中 = random(0, 100) < (力量/10 × 40 + 敏捷/10 × 30)
  
  伤害 = 基础(2) + 力量/10 × 随机(1,4)
  
  NPC有这些属性（新增战斗参数）：
    HITPOINTS(体力=生命值) = 体质×5
    攻击力(基础)= 力量/10 × 4
    闪避率 = 敏捷/10 × 30%

任何一方 HP = 0 → 倒地 = 打架结束
```

### 9.2 触发冲突

```
触发条件：
  吵架升级（好感度骤降超过-15 → 60%概率触发打架）
  偷东西被抓（受害者殴打小偷）
  领土纠纷（"你的羊跑到我院子里了"）
```

## 十、物品耐久与维护

### 10.1 三类耐久

| 类型 | 实例 | 耐久方式 | 能否修 |
|:-----|:-----|:--------|:-----|
| **消耗品** | 野果、肉 | 一次性 | — |
| **磨损品** | 石刀、石斧 | 耐久100→递减 | ✅可修(磨刀) |
| **耐用/永久** | 铁器、房子 | 极慢递减或无限 | 铁器几乎不坏 |

### 10.2 修理

```
石刀耐久降到<30时出现"钝了" → NPC可磨刀
  CMD_打磨(石刀) = 磨石×1 + 5分钟 → 耐久回复50

房子耐久下降到<50 → 需要修理
  材料：当初建房子的材料×0.3
  CMD_修房子 → 耐久回满
```
