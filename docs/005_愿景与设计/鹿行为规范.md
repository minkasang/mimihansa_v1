## 二、鹿的群居行为

鹿不像狼有严格等级，但它们成群活动——因为群体中的多双眼睛可以更早发现危险。

```
鹿群:
  2~8只鹿组成松散群体
  没有Alpha/Beta/Omega之分
  没有固定的首领——但有"老鹿"经验更丰富

群体警觉:
  只要群里有任何一只鹿发现危险（Step 2 感知）→ 整群都跑
  不是魔法——是一只鹿先跑，其他鹿看到它跑了也跟着跑
  → 这就是"从众式逃跑"

群体优势:
  20只眼睛扫视比2只眼睛安全得多
  捕食者很难同时攻击多只鹿
  → 狼通常攻击落在最后面的、年老的、或受伤的鹿
```

## 三、鹿的日常作息

```
05:00~09:00（清晨）: 觅食高峰
  - 在草地吃草
  - 去水源喝水
  - 边走边吃，缓慢移动

09:00~16:00（白天）: 反刍+休息
  - 在树林边缘或灌木丛旁休息
  - 反刍（把早上吃的东西再嚼一遍）
  - 半躺着，但眼睛仍在扫描周围

16:00~20:00（黄昏）: 第二次觅食
  - 再次吃草
  - 这是第二个狩猎窗口

20:00~05:00（夜晚）: 休息
  - 在树林深处或灌木丛里过夜
  - 不反刍，浅睡状态

季节性迁徙:
  冬天 → 草枯萎 → 鹿群朝有森林的方向移动 → 吃灌木叶、树皮
  春天 → 草重新长出 → 回到草地
```

## 四、鹿的欲望（5条）

```
want_flee (优先级 10, 最高):
  条件: 感知到捕食者（狼/人）在靠近
        ← 注意：鹿的视觉比狼远（25 vs 22），所以鹿通常先看到狼
  目标: action_flee_herd
  策略: 往远离威胁的方向跑 → 整群一起跑

want_eat (优先级 9):
  条件: 饥饿度 > 5 + 是清晨或黄昏
  目标: action_graze
  效果: 饥饿度 -5（鹿体型大，一次吃得多）

want_drink (优先级 8):
  条件: 口渴度 > 6
  目标: action_go_to_water
  效果: 口渴度 -5

want_sleep (优先级 5):
  条件: 疲劳度 > 7 + 在安全区域
  目标: action_sleep
  效果: 疲劳度 -4

默认: want_graze_slow (优先级 2):
  条件: 没有高优先级目标
  目标: 慢速吃草（边走边吃，同时警戒）
  ← 鹿大部分时间都在吃草或反刍
```

## 五、鹿的逃跑策略（与兔子不同）

```
兔子: 极速冲刺（速度12）× 2秒 → 钻进窝 → 躲起来

鹿: 中速长跑（速度7）× 长时间 → 拉开距离 → 让捕食者追不动

人类的比较:
  人快跑: 速度 1.5× = 约10.5 → 比鹿快 → 可能追上
  但人耐力有限 → 跑一阵就没劲了 → 鹿跑得更久
  → 如果鹿在开阔地 → 人追上了 → 鹿死亡
  → 如果鹿在森林/山地 → 复杂地形对人不利 → 鹿逃脱

狼的比较:
  狼群策略: 轮番追击 → 一只狼驱赶，其他狼截断路线
  → 鹿被围住 → 无处可逃 → 狼群击杀
  → 如果只有1~2只狼 → 追不上、挡不住 → 鹿存活

鹿的"假动作":
  高速逃跑一阵后 → 突然转向 → 捕食者惯性冲过头
  → 鹿获得几秒喘息
  ← 这只是程序上的"随机转向"模拟，不是真的AI
```

```

  草（草地）:

    耗时: 15 Tick（慢慢吃）

    效果: 饥饿度 -4

    效果: 饥饿度 -2
    耗时: 25 Tick（和兔子一样啃树皮）

  水生植物（水边）:
    效果: 饥饿度 -3
    耗时: 10 Tick

鹿的食量:
  一头鹿≈5只兔子的食量
  → 一片草地能支撑的鹿比兔子少得多
  → 这是鹿比兔子稀少的原因
```

## 七、鹿的繁殖

```
繁殖条件:
  - 任何成年公鹿 + 母鹿
  - 发情季节: 秋季（每年一次）
  - 公鹿之间可能发生争斗（力量+体型比较，赢的获得交配权）

孕期: 约200天（游戏时间）
每胎: 1~2只（不像兔子一生一窝）
性成熟: 1.5~2岁

幼鹿:
  出生后30分钟就能站起来走路 ← 这是真的
  0~3个月: 跟着母鹿，在隐蔽处躲藏
  3~6个月: 跟着鹿群一起活动，学习吃草
  1岁: 独立觅食，但还在群里
  1.5~2岁: 性成熟

鹿的寿命:
  野生: 约10~15年
  被猎杀: 大部分活不到10年
```

## 八、鹿与捕食者

```
鹿的天敌:
  狼（主要）: 需要3~5只狼才能成功围猎一头成年鹿
             少于3只 → 鹿轻松逃脱 → 狼挨饿

  人: 可以潜行 + 远程武器（弓箭）→ 威胁极大
      但弓箭是后期物品，早期没有

  熊（未来）: 偶尔偷袭幼鹿、病鹿

鹿的防御策略总结:
  1. 视觉远（25格）→ 提前发现危险
  2. 耐力好（7）→ 长跑甩掉追兵
  3. 群体优势 → 多只眼睛、捕食者难选目标
  4. 复杂地形 → 森林里鹿比人灵活
```
