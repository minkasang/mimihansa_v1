## 一、原料来源

| 原料 | 获取方式 | 产出频率 |
|:-----|:---------|:---------|
| 棉花 | 种植→收获（同农耕系统） | 1株→棉花×2 |
| 麻 | 种植/野生采集 | 1株→麻叶×2 |
| 羊毛 | 剪羊（动物系统） | 每季1份/羊 |
| 皮革 | 猎杀动物 | 1只→1块 |

> 所有原料的层级归属见 [产业链与物品层级 §二](./产业链与物品层级.md)

## 二、纺织流程

```
原料(棉花/麻/毛) → 纺线(纺车) → 纱线
                          ↓
                      织布(织机) → 布料
                          ↓
                      裁剪/缝合(针) → 衣服
```

- 纺车 = 木材×5 + 绳子×2 → 需要石刀制作
- 织机 = 木材×8 + 绳子×4 → 需要纺车后制作
- 针   = 铁锭×1 → 需要铁匠铺

## 三、服饰等级

| 等级 | 面料 | 效果 | 社交加成 |
|:-----|:-----|:-----|:-------|
| 粗布衣 | 粗布×2 | 冬天保暖+1 | 无 |
| 棉布衣 | 棉布×2 | 保暖+2，舒适+1 | 魅力+1 |
| 丝绸衣 | 丝绸×2 | 保暖+3 | 魅力+2，社交好感+1 |

## 四、NPC穿衣驱动

```
NPC 每衣有耐久（100→递减）

衣服破损→需要替换（CMD_制作衣服 或 去商店买）

冬季：
  如果没有衣服 → 健康每天-0.5（冻着）
  如果有粗布衣 → 健康不受冻

攀比：
  看到邻居穿好衣服 → 攀比驱动(见职业与市场 §9.4)
  → 想换更好的 → 去商店买/自己做
```
