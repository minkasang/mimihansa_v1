## 一、水系统

### 1.1 口渴：新的生理需求

```
每个NPC都有一个口渴度（范围1~10，同饥饿度）
  1=完全不渴，10=濒临脱水

每Tick：
  口渴度 +0.05（大约每小时+3）

脱水速度受环境影响：
  快跑/重体力 → +0.1/tick（比正常快两倍）
  炎热夏天   → +0.08/tick
  静止      → +0.02/tick

口渴度 >= 7 → 触发欲望 want_drink（优先级8，和吃饭同级）
口渴度 = 10 → 健康快速下降，3天内死亡
```

### 1.2 水在哪里

| 水源类型 | 地形 | 获取方式 | 水质 |
|:---------|:-----|:---------|:-----|
| 河流 | [水域]格 | 走到河边→直接喝 | 一般（可能有污染） |
| 湖泊 | [水域]格 | 走到湖边→直接喝 | 较好 |
| 雨水 | 雨天任意格 | 接雨水 | 干净 |
| 地表积水 | [草地]（雨后）| 找小坑 | 尚可 |

### 1.3 喝水的方式

```
方式A：直接喝（用手捧）
  条件：NPC站在水域旁（相邻格即为水域）
  动作耗时：2秒
  效果：口渴度-5

方式B：用容器装水带走
  需要：容器（陶罐/木碗/葫芦）
  动作：装水 → 物品：装满水的容器
  在家/营地 → 喝掉 → 口渴度-5

方式C：挖坑积水
  需要：工具（石刀/铲子）
  在非水域格挖小坑→雨后积水→可临时取水
```

### 1.4 发现水源后如何告诉别人

```
发现者把水源信息存到自己的知识库：
  {
    "类型": "已知地点",
    "名称": "水源",
    "方向": "东北偏东",    // 用8方位描述
    "大概距离": "走路约80步", // 模糊距离
    "参考物": "河边有一棵大树"
  }

发现者告诉同伴时：
  同伴的知识库得到同样的模糊信息
  
同伴去找水时：
  用"探索寻路"（不是A*）：
    沿方向走 → 走距离后如果没看到→扩大半径搜索→找到→更新为精确坐标
```

### 1.5 水相关的新物品

| 物品 | 制作方式 | 用途 |
|:-----|:---------|:-----|
| 木碗 | 木材×1 + 石刀雕刻 | 盛水容器 |
| 陶罐 | 粘土×3 + 烧制 | 储水容器，可装多份水 |
| 葫芦 | 采摘获得 | 天然容器 |
| 水袋 | 皮革×1 + 缝制 | 出行携带 |

## 二、采摘与觅食

### 2.1 采摘野果

NPC可以采集天然生长的食物，不需要任何工具（徒手即可）。

```
采摘要求：
  地形：[草地]、[森林]
  条件：没有季节/天气限制

采摘动作：
  action_forage → 搜索周围5格→ 找野果/莓果
  
  找到概率 = 地形因子 × 季节因子：
    草地  → 基础概率 40%（野果、莓果）
    森林  → 基础概率 60%（浆果、蘑菇）
    水域旁→ 基础概率 30%

单次采摘耗时：约10 Tick（10秒）
单次采回数量：1~3颗野果
  每颗野果效果：饥饿度-1，口渴度-0.2
```

### 2.2 可以采集的东西

| 可采集物 | 出现地形 | 用途 | 可存放时间 |
|:---------|:---------|:-----|:----------|
| 野果 | 草地、森林 | 直接吃 | 2~3天 |
| 莓果 | 草地、森林 | 直接吃 | 1~2天 |
| 蘑菇 | 森林（雨后更多） | 直接吃/有毒判定 | 2~3天 |
| 可食用草根 | 草地 | 直接吃 | 3~4天 |
| 鸟蛋 | 森林/树上 | 烤熟吃 | 5~7天 |
| 蜂蜜 | 森林（极罕见） | 直接吃，开心+3 | 不坏 |

### 2.3 蘑菇毒判定

```
NPC遇到蘑菇时：
  如果NPC的智商 ≥ 7 → 有知识判断哪些可吃（成功率80%）
  如果NPC以前吃过有毒蘑菇→ 记忆里有"蘑菇有毒"→ 不吃
  否则 → 50%概率吃到毒蘑菇
  
  毒蘑菇效果：健康-2，呕吐（饥饿度-3 + 口渴度-2）
```

## 三、生火系统

### 3.1 火：一个特殊的"物品"

火不是可以随身携带的物品，而是一个**放置在某个坐标上的活动对象**。

```
火的属性：
  {
    类型: "火堆",
    位置: [x, y],
    燃料剩余时间: 300,     // 单位Tick，0=火熄灭
    提供热度半径: 3格,     // 在这之内有热度
    是否会蔓延: false      // 先不做了（火灾太复杂）
  }
```

### 3.2 如何生火

```
需要：
  木材/干草 × 2（燃料）
  石头 × 1（硬物打火）

方法：钻木取火
  判定：
    成功率 = baseRate(30%) + 智商/10×40% + (如果有干草)+15%
    例：智商5 → 50%，智商8 → 62%

  耗时：30 Tick（如果失败→再试）
```

### 3.3 火有什么用

| 用途 | 方式 | 效果 |
|:-----|:-----|:-----|
| 烹饪 | 把肉/食物放在火上 → 烤熟 | 食品安全 |
| 取暖 | 站在火堆3格内 | 寒冷天气中不受冻 |
| 光照 | 火堆照亮半径5格 | 夜晚能看清周围 |
| 防御 | 野兽怕火 | 狼不会靠近火堆 |
| 社交 | 人们自然聚在火旁 | 促进交流和好感积累 |

### 3.4 火会熄灭

```
每Tick燃料-1
NPC可以加燃料：
  把木材/干草放进火堆 → 燃料+N Tick

如果火完全熄灭→需要重新生火
```

## 四、基础制作

### 4.1 石刀——文明的起点

第一个工具。有了它，才能砍树、狩猎、雕刻。

```
制作材料：
  石头 × 2（任何石头都可）

制作过程：
  action_craft → cmd_石刀制作
  
  成功率 = baseRate(30%) + 手工天赋/10×40% + 智商/10×20%
  耗时：约20 Tick
  失败 → 石头裂了（浪费一块）

石刀属性：
  物品类型：[工具]、[刀]、[基础]
  耐久：100（用一次消耗1~3点耐久）
  有石刀后解锁的动作：
    → 砍树（木材+1/次，效率提升3倍）
    → 割肉//剥皮（打猎后处理尸体更快）
    → 雕刻（做木碗等）
```

### 4.2 制作清单

| 制品 | 材料 | 工具需求 | 耗时 | 产物 |
|:-----|:-----|:---------|:-----|:-----|
| 石刀 | 石头×2 | 空手 | 20 Tick | [石刀] |
| 木碗 | 木材×1 | 石刀 | 15 Tick | [木碗] |
| 木矛 | 木材×2 | 石刀 | 25 Tick | [矛]（武器+0.3） |
| 绳索 | 干草×2 | 空手 | 10 Tick | [绳子] |
| 简易篮筐 | 干草×3 | 空手 | 20 Tick | [篮子]（采摘量+2） |

> 石材和木料见 [产业链与物品层级](./产业链与物品层级.md)。

### 4.3 进阶制作（解锁石刀后）

| 制品 | 材料 | 工具 | 耗时 | 产物 |
|:-----|:-----|:-----|:-----|:-----|
| 石斧 | 石头×3+绳子×1+木材×1 | 石刀 | 40 Tick | [石斧]（砍树效率再×2） |

## 五、烹饪

### 5.1 为什么需要烹饪

```
生肉直接吃 → 健康-1，可能感染寄生虫（小概率生病）
生肉烤熟吃 → 健康无损，饥饿度恢复更多

生野果/莓果 → 可以直接吃，安全
生蘑菇 → 需要判定有毒
```

### 5.2 烤肉

```
前提条件：
  有火堆
  手上有生肉

烹饪动作：
  NPC走到火堆旁 → action_cook → cmd_烤肉

  耗时：30 Tick（自动执行）
  效果：生肉[可食用=false]→ 烤肉[可食用=true]，饥饿度恢复比生肉+1
```

## 五-续、火上的肉属于谁（v2.0 新增）

> ⚠️ 物品离开 NPC 物品栏放到火堆上后，系统层面没有"所有者"标记。但 NPC 记得。

### 放肉上烤

```
黄志远.物品栏有生肉×1 → 走到火堆旁 → action_cook:

  1. 从物品栏取出"生肉×1"
  2. 生成临时物品实体在火堆格: 
     { id:"item_fire_meat_01", 名称:"正在烤的兔肉", 位置:[火堆坐标], 所有者:null }
  3. 黄志远.知识库写入:
     { 类型:"事实", 内容:"火堆上有一块兔肉正在烤，那是我的", 来源:"亲身", 可信度:1.0 }

  4. 烤制30 Tick → 生肉变成熟肉

  5. 黄志远取回: 物品栏新增熟肉×1, 临时物品删除
```

### 别人路过

```
许静怡 Step 2: 看到火堆旁有一块熟肉（所有者=null）

许静怡的决策（由性格+生理驱动，不是系统规则）:

  道德底线 >= 7 → 不管多饿都不拿别人的东西
    知识库: "这块熟肉大概是谁的"（推断，不是系统告知）

  道德底线 4~6 + 饥饿度 > 7（非常饿）→ 可能吃
    → 先问一句:"这肉是谁的？"（Step 6 社交）
    → 如果没人回答 → 内心挣扎（压力值+1）→ 可能吃
    → 吃之前会先判断: 黄志远是不是在里面
      如果她经常看到黄志远在这里烤肉 → 推断"这可能是黄志远的"
      → 她如果跟黄志远关系好 → 不会吃
      → 她如果不认识黄志远或者关系差 → 可能偷吃
  
  道德底线 <= 3 → 直接吃
    → 不关心是谁的
  
  如果目击者在场:
    目击者.知识库: "许静怡偷吃了火上的肉"
    → Step 6 口口相传 → 消息可能扩散
    → 被偷的黄志远回来后可能会知道

黄志远回来发现肉没了:
  Step 2: 火堆旁没有肉
  → 知识库对比:"我记得我把肉放这里的" vs "现在没有了"
  → 结论:"我的肉被人拿走了"（亲身经历——对比）
  → Step 6: 问附近的人 "谁看见我的肉了"
  → 如果有人告诉他"许静怡吃了" → 好感度 -10
  → 如果没人说 → 猜疑度上升，但不知道是谁干的
```

## 六、道路形成

### 6.1 踩踏度系统

```
每格土地有属性：
  踩踏度 = 0~100
  已踩踏次数 = 每天走过的不同NPC人次（同一天一人踩多次只算一次）
  
每天结算：
  if 今天有人踩过这格：
    踩踏度 += 1                    // 走一次加一点
  else：
    踩踏度 -= 0.5                  // 没人走就慢慢恢复
    if 下雨：
      踩踏度 -= 1.5               // 雨水冲刷加速恢复
  
  踩踏度 = clamp(0, 100)          // 边界约束
```

### 6.2 视觉效果

| 踩踏度 | 显示 | 说明 |
|:------|:-----|:-----|
| 0~15 | 🌿 正常草地 | 没人走过 |
| 15~35 | 🌱 轻微磨损 | 草变矮，偶尔能看到地面 |
| 35~60 | 🛤️ 土路出现 | 明显路径，草基本没了 |
| 60~85 | 🛤️ 实土路 | 长期使用的路，表面压实 |
| 85~100 | 🧱 硬路 | 雨天也不会泥泞，很坚实 |

### 6.3 路自然形成的条件

```
路最易形成在：
  取水点 ↔ 村庄（每天来回走）
  砍树点 ↔ 建造点（搬运木材）
  狩猎点 ↔ 营地

路不会形成在：
  没人走的地方（草地自然恢复）
  一个人偶然路过的地方（不够频繁）
```

### 6.4 主动修路（进阶）

```
NPC可以选择"铺设道路"：
  材料：石头或砾石
  效果：该格踩踏度直接变为80（基础硬路），且不会被雨水冲刷
  耗时：N Tick，需要工具
  优点：永久道路，雨天不变泥泞
```

## 七、村庄形成

### 7.1 第一个房子的选址

```
NPC选择建房位置时，综合考虑以下因素：

因素1：水源距离
  离水源<20格 → +30分（近水方便）
  离水源>60格 → -20分（太远每天打水累）

因素2：邻居距离
  离最近的房子<5格 → +20分（安全感，挨着别人）
  离最近的房子10~20格 → +5分（不太远但有一定隐私）
  附近有讨厌的人(好感度<-50)→ 减30分以上（想搬家！）
  
因素3：地形
  草地 → +0分（默认）
  靠近森林 → -10分（潮湿、虫多）
  靠近水域 → -15分（洪水风险）
  山地 → -5分（地基不稳）

因素4：已有道路
  贴着路 → +15分（交通方便）
  远离路 → -10分

最终选址 = argmax(各因素加权分)
```

### 7.2 房子的朝向

```
房子的"门"朝向：
  优先级1：朝向已有道路（如果有）
  优先级2：朝向邻居的房子（面对面）
  优先级3：朝南（传统风水原理，采光好）

  不面向：
    → 悬崖/水域
    → 垃圾堆/危险处
```

### 7.3 村庄的有机演化

```
第一阶段：散居
  前几座房子分布松散，各NPC独立建造各自的小棚

第二阶段：小聚落
  取水点附近、沿河平坦处→2~3座房子集中
  因为大家每天都去取水→自然形成小聚落
  
第三阶段：屋子挨屋子
  随着生存稳定+
  更多人建房→位置好的地方挤满了房子
  有人搬到稍远但清净的地方
  
第四阶段：出现"中心"
  火堆/水井/公示栏→成为"村中心"
  中心地段的房子更贵/更受争抢
```

### 7.4 房子等级

| 等级 | 材料 | 建筑耗时 | 效果 | 所需技能 |
|:-----|:-----|:--------|:-----|:--------|
| 简陋草棚 | 木材×5+干草×3 | 1天 | 可睡觉（恢复更快）、遮蔽风雨效果差 | 无门槛 |
| 简易木棚 | 木材×10 | 2天 | 更好的遮风挡雨 | 建筑技能1 |
| 泥墙草屋 | 木材×8+粘土×5+干草×4 | 3~4天 | 保暖好、耐久 | 建筑技能3 |
| 木屋 | 木材×20 | 5天 | 舒适度高、耐久高 | 建筑技能5+石斧 |
| 石基瓦房 | 石头×15+木材×15+粘土×10 | 7~10天 | 最佳住宅 | 建筑技能7+专业工匠 |
