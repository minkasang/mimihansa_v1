# 效果路由表

> 运行时契约文档。统一所有 `{"key": value}` 效果到实际参数的映射。
> ⚠️ 任何系统写效果时必须查本表，用正确的参数名。

---

## 一、路由规则

```
效果格式：{"参数名": 变化值}

引擎读取后：
  1. 查本表 → 找到参数名对应的字段路径
  2. 是NPC参数？ → 写入 NPC.字段路径
  3. 是世界参数？ → 写入 World.字段路径
  4. 是本表未注册的key？ → 丢弃 + 日志警告
```

## 三、引擎读取本表的方式

```typescript
function applyEffect(effect: Record<string, any>, target: Entity, world: WorldState) {
  for (const [key, value] of Object.entries(effect)) {
    const route = EFFECT_ROUTING_TABLE[key];
    if (!route) { logWarning(`未知效果key: ${key}`); continue; }
    
    if (route.target === 'NPC') setNestedValue(target, route.path, value);
    else if (route.target === 'World') setNestedValue(world, route.path, value);
    else if (route.target === 'Animal') setNestedValue(target, route.path, value);
  }
}
```

## 四、与参数总表的一致性

本表所有 key 必须与 `NPC参数总表.md` 中的**参数名逐字一致**。
效果 key 使用中文短名（如 `"饥饿"` 而非 `"饥饿度"`），映射到实际字段路径（如 `生理状态.饥饿度`）的工作由本表完成。

## 五、复合效果类型（v1.1 新增）

> ⚠️ 原有格式 `{"参数名": 变化值}` 只能处理数值加减和物品增减。
> 以下新增的复合效果类型，用于处理标签增删、实体生成、关系变更、知识库写入等。

### 5.1 好感度效果（需要附带target参数）

```json
{
  "好感度": {
    "target": "$目标NPC_ID",
    "value": 20,
    "operation": "add"
  }
}
```

路由目标：`NPC.社会关系.好感度[$目标NPC_ID]`

### 5.2 标签增删效果

```json
{
  "标签": {
    "operation": "add",
    "tags": ["情侣", "夫妻"]
  }
}
```

```json
{
  "标签": {
    "operation": "remove",
    "tags": ["未婚"]
  }
}
```

路由目标：`NPC.标签[]`

### 5.3 实体生成效果

```json
{
  "生成实体": {
    "类型": "建筑",
    "位置": [x, y],
    "属性": { "等级": "草棚", "所有者ID": "$当前NPC_ID" }
  }
}
```

```json
{
  "生成实体": {
    "类型": "火堆",
    "位置": [x, y],
    "属性": { "燃料剩余": 100 }
  }
}
```

```json
{
  "生成实体": {
    "类型": "尸体",
    "位置": [x, y],
    "属性": { "原NPC_ID": "$当前NPC_ID" }
  }
}
```

路由目标：`World.buildings[]` / `World.fires[]` / `World.corpses[]`

### 5.4 知识库写入效果

路由目标：`NPC.知识库[]`

### 5.5 关系变更效果

```json
{
  "关系": {
    "target": "$目标NPC_ID",
    "关系类型": "配偶",
    "operation": "set"
  }
```

### 5.6 家坐标设置效果

```json

  "家坐标": {
    "operation": "set",

  }

```

路由目标：`NPC.家坐标`

### 5.7 复合效果路由注册表

| 效果 key | 写入目标 | 操作类型 | 说明 |
|:---------|:--------|:---------|:-----|
| `"好感度"` | `NPC.社会关系.好感度[target]` | add/set | 需要target参数 |
| `"标签"` | `NPC.标签[]` | add/remove | 批量增删标签 |
| `"生成实体"` | `World.buildings/fires/corpses` | create | 生成新实体 |
| `"知识库"` | `NPC.知识库[]` | add | 写入新知识条目 |
| `"关系"` | `NPC.社会关系.*` | set/remove | 变更亲属/配偶关系 |
| `"家坐标"` | `NPC.家坐标` | set | 设置住所位置 |

## 六、效果结算器扩展逻辑（v1.1 新增）

```typescript
function applyEffect(effect: Record<string, any>, target: Entity, world: WorldState) {
  for (const [key, value] of Object.entries(effect)) {
    // 复合效果类型
    if (key === "好感度" && typeof value === "object") {
      target.社会关系.好感度[value.target] = (target.社会关系.好感度[value.target] || 0) + value.value;
      continue;
    }
    if (key === "标签" && typeof value === "object") {
      if (value.operation === "add") target.标签.push(...value.tags);
      if (value.operation === "remove") target.标签 = target.标签.filter(t => !value.tags.includes(t));
      continue;
    }
    if (key === "生成实体" && typeof value === "object") {
      spawnEntity(world, value.类型, value.位置, value.属性);
      continue;
    }
    if (key === "知识库" && typeof value === "object") {
      target.知识库.push({ id: generateId(), ...value.条目, 时间戳: world.时间.当前Tick });
      continue;
    }
    if (key === "关系" && typeof value === "object") {
      applyRelationChange(target, value);
      continue;
    }
    if (key === "家坐标" && typeof value === "object") {
      target.家坐标 = value.位置;
      continue;
    }

    // 简单效果（原有逻辑）
    const route = EFFECT_ROUTING_TABLE[key];
    if (!route) { logWarning(`未知效果key: ${key}`); continue; }
    if (route.target === 'NPC') setNestedValue(target, route.path, value);
    else if (route.target === 'World') setNestedValue(world, route.path, value);
    else if (route.target === 'Animal') setNestedValue(target, route.path, value);
  }
}
```
