# 角色外观生成规范

> 本文档定义角色外观的设计规范，用于指导AI生成角色精灵图。
> 
> **核心原则**：
> - 设计的是各种各样的人，不是预设好的职业标签
> - 高矮胖瘦、眼睛大小、时髦土气、年轻年老……每个人都不一样
> - 适配2.5D等角视角地图
> - 像素风、Q版大头比例

---

## 一、角色分类维度

### 1.1 设计思路

不是设计"农民""恶霸"这种固定角色，而是从以下几个维度来设计人物：

```
一个人 = 体型 + 样貌 + 穿着 + 气质 + 年龄 + 性别 + 特征 → 组合出各式各样的人
```

### 1.2 设计维度总览

| 维度 | 具体要素 |
|------|----------|
| **体型** | 身高、胖瘦、肩膀、脖子、驼背/挺直 |
| **头部样貌** | 肤色、头型、发色、发型、发量、眼睛、眉毛、鼻子、嘴、耳朵、脸型、额头、颧骨、下巴 |
| **面部细节** | 胡子、痣、雀斑、酒窝、皱纹、眼袋、化妆 |
| **穿着** | 上衣、下装、鞋子、帽子、配饰、颜色、新旧、合身度 |
| **气质** | 表情、眼神、姿态、精气神 |
| **年龄** | 小孩、青年、中年、老年 |
| **性别** | 男、女 |
| **特殊特征** | 伤疤、纹身、工具、肢体特征 |

## 二、体型设计

### 2.1 身高

| 类型 | 视觉描述 | 说明 |
|------|----------|------|
| **矮小** | 腿短，整体矮小，站在高个子旁边只到肩膀高度 | 像小孩或天生矮小 |
| **中等** | 普通身高，最常见的类型 | 大多数人的身高 |
| **高挑** | 腿长，身形修长，在人群中显眼 | 比一般人高半头到一头 |

### 2.2 胖瘦

| 类型 | 视觉描述 | 身体宽度 |
|------|----------|----------|
| **瘦削** | 肩膀窄，腰细，四肢纤细如竹竿，衣服显得宽大晃荡，锁骨突出 | 0.85x |
| **标准** | 肩膀宽度适中，腰不粗不细，四肢匀称，健康结实 | 1.00x |
| **壮实** | 肩膀宽阔如门板，胸肌厚实，手臂粗壮有肌肉线条，腰背厚实 | 1.15x |
| **肥胖** | 肩膀圆润，肚子圆鼓鼓突出，脸部也圆润，脖子粗，整体圆滚滚 | 1.25x |

### 2.3 肩膀

| 类型 | 视觉描述 |
|------|----------|
| **宽肩** | 肩膀宽度明显大于髋部，呈倒三角，显得有力量 |
| **窄肩** | 肩膀宽度小于或等于髋部，显得纤瘦或柔弱 |
| **溜肩** | 肩膀线条倾斜向下，不是水平的，显得柔和 |
| **平肩** | 肩膀线条水平，显得挺拔精神 |

### 2.4 脖子

| 类型 | 视觉描述 |
|------|----------|
| **长颈** | 脖子修长，显得优雅挺拔 |
| **短颈** | 脖子短，头看起来直接连在肩膀上，显得敦实 |
| **粗颈** | 脖子粗壮，跟头部宽度接近，显得强壮 |
| **细颈** | 脖子纤细，显得文弱 |

### 2.5 背部

| 类型 | 视觉描述 | 适合的角色印象 |
|------|----------|----------------|
| **挺拔** | 背脊挺直，胸自然前挺，精神饱满 | 军人、自信的人、年轻人 |
| **微驼** | 背部略微弯曲，肩膀前倾，头略低 | 老人、书呆子、没自信的人 |
| **佝偻** | 背部明显弯曲，驼背严重，身高显矮 | 很老的人、长期劳累的人 |

### 2.6 腿部

| 类型 | 视觉描述 |
|------|----------|
| **长腿** | 腿部占身体比例大，显得修长 |
| **短腿** | 腿部占身体比例小，显得敦实 |
| **粗腿** | 大腿小腿都粗壮，显得结实有力 |
| **细腿** | 腿部纤细，显得文弱或轻盈 |

### 2.7 体型组合效果

| 身高+胖瘦 | 给人的感觉 |
|-----------|------------|
| 矮小+瘦削 | 小巧玲珑，像没长大的孩子 |
| 矮小+肥胖 | 敦实可爱，圆滚滚像球 |
| 矮小+壮实 | 矮壮结实，像推土机一样有力 |
| 中等+瘦削 | 普通身材但偏瘦，文弱感 |
| 中等+标准 | 最普通的体型 |
| 中等+壮实 | 健壮有力，有安全感 |
| 中等+肥胖 | 发福的中年人 |
| 高挑+瘦削 | 竹竿一样又高又瘦，像竹节虫 |
| 高挑+壮实 | 高大威猛，最有压迫感 |
| 高挑+肥胖 | 高大肥胖，像一堵墙 |

## 三、头部样貌设计

### 3.1 肤色

| 肤色 | 色值 | 视觉描述 | 给人的印象 |
|------|------|----------|------------|
| **白皙** | #FFEFE0 | 皮肤白净近乎乳白，隐约能看到皮下血管的青蓝色，容易晒红但不易晒黑 | 少晒太阳的室内人、读书人、养尊处优的人 |
| **暖色** | #F5D0B0 | 自然的米黄色或浅蜜色，健康有光泽，最常见的大众肤色 | 普通老百姓 |
| **麦色** | #E8C4A0 | 小麦色或浅棕色，明显被太阳晒过的痕迹，脸和手臂颜色比身上深 | 户外劳动者、经常晒太阳的人 |
| **深色** | #C49464 | 深棕色或古铜色，天生的深肤色或长期暴晒的结果 | 南方人、海边居民、特殊种族 |

### 3.2 头型

| 类型 | 视觉描述 |
|------|----------|
| **标准头型** | 头型圆润正常，最常见的头型 |
| **大头** | 头部比一般人明显大一号，显得头重脚轻，有点呆萌 |
| **小头** | 头部比一般人明显小一号，显得精干 |
| **扁头** | 后脑勺比较扁平，侧面看头型不圆润 |

### 3.3 发色

| 发色 | 色值 | 视觉描述 | 常见程度 |
|------|------|----------|----------|
| **乌黑** | #1A1A1A | 纯正的黑色，黑得发亮，最常见 | 最常见 |
| **深棕** | #4A2408 | 深褐色，遠看像黑色但在阳光下透出棕色 | 常见 |
| **浅棕** | #8B4513 | 明显的栗子色，温暖柔和 | 较常见 |
| **金黄** | #D4A574 | 金色或亚麻色，明亮醒目 | 较少见 |
| **红色** | #A0522D | 红褐色或铜红色，独特有个性 | 少见 |
| **灰白** | #A0A0A0 | 灰色夹杂白色，老年人或天生银发 | 老年人常见 |
| **花白** | 黑+灰混杂 | 黑色头发中夹杂着灰白头发，半老的人 | 中年人 |
| **全白** | #E8E8E8 | 纯白色或银白色 | 很老的人或天生 |

### 3.4 发量

| 类型 | 视觉描述 |
|------|----------|
| **浓密** | 头发又多又厚，蓬松有体积感 |
| **稀疏** | 头发少而薄，能看到头皮，显得头发贴着头皮 |
| **秃顶** | 头顶头发掉光，只剩两侧和后脑有头发，地中海发型 |
| **光头** | 完全没有头发，头顶光溜溜 |
| **发际线高** | 额头上的发际线靠后，显得额头很宽 |
| **发际线低** | 发际线靠前，额头窄 |

### 3.5 发型

**男性发型**：

| 发型 | 视觉描述 | 适合的感觉 |
|------|----------|------------|
| **板寸** | 头发只有几毫米长，贴着头皮，清爽硬朗 | 精神、军人、硬汉 |
| **短发** | 耳朵以上长度，可以分头路或自然垂落 | 干练、普通男性 |
| **中分** | 头发从中间向两边分开，露出额头 | 文雅、复古 |
| **偏分** | 头发从一侧分开，一边多一边少 | 成熟、斯文 |
| **背头** | 全部头发向后梳，露出整张脸 | 有派头、老板、成功人士 |
| **刘海** | 额前有垂下的头发盖住额头 | 年轻、学生、可爱 |
| **中长发** | 头发到耳朵和肩膀之间，可扎可披 | 文艺、随性 |
| **长发** | 头发过肩，可扎马尾或披散 | 艺术家、浪子 |
| **光头** | 完全没有头发 | 凶悍、和尚、搞笑 |
| **卷毛** | 头发自然卷曲蓬松，像爆炸头或小卷 | 活泼、时髦、可爱 |
| **莫西干** | 中间一排头发竖起来，两边剃光 | 叛逆、朋克 |

**女性发型**：

| 发型 | 视觉描述 | 适合的感觉 |
|------|----------|------------|
| **超短发** | 耳朵以上，露出整个脸和脖子，像男孩一样短 | 干练、假小子、个性 |
| **齐耳短发** | 长度到耳朵下沿，包住耳朵 | 活泼、精神 |
| **学生头** | 齐下巴长度，发尾齐整，有厚重感 | 学生、清纯、乖巧 |
| **中长发披肩** | 肩膀到胸部长度，自然披散 | 温柔、普通女性 |
| **中长发扎起** | 中长发在脑后扎成低马尾或丸子头 | 利落、干练 |
| **长发披肩** | 长发过胸，自然垂落披散 | 女人味、温柔 |
| **高马尾** | 长发在头顶扎成一束，跑步时一晃一晃 | 活泼、有精神 |
| **低马尾** | 长发在脑后低处扎成一束 | 温柔、文静 |
| **双马尾** | 头发分成两束扎在两边耳朵上方 | 可爱、年轻、活泼 |
| **麻花辫** | 头发编成一条或两条辫子，可粗可细 | 朴素、乡村、天真 |
| **盘发/发髻** | 头发完全盘在脑后，露出整个脖子 | 成熟、已婚、优雅 |
| **丸子头** | 头发在头顶团成一个圆球 | 可爱、清爽 |
| **齐刘海** | 额前有整齐的刘海盖住额头 | 可爱、年轻、遮额头 |
| **斜刘海** | 刘海斜向一边，露出一部分额头 | 时尚、遮半额 |
| **碎刘海** | 刘海不规则散碎，不整齐 | 随性、慵懒 |
| **大波浪** | 长发烫成大波浪卷，蓬松有弧度 | 成熟、风情、时髦 |

### 3.6 眉毛

| 类型 | 视觉描述 | 给人的感觉 |
|------|----------|------------|
| **浓眉** | 眉毛粗黑浓密，像两条毛毛虫，非常显眼 | 精神、正直、有男子气概、豪爽 |
| **淡眉** | 眉毛颜色浅，稀疏，几乎看不清 | 文弱、温和、女性 |
| **柳叶眉** | 眉毛细长弯曲如柳叶，弧度优美 | 女性化、温婉、秀气 |
| **剑眉** | 眉毛如剑，前细后宽略上扬，有锐气 | 英气、有魄力、侠客 |
| **一字眉** | 眉毛平直如一字，没有弧度 | 严肃、认真、坚定、固执 |
| **八字眉** | 眉尾下垂呈八字形，看起来像在发愁 | 可怜、委屈、忧郁、搞笑 |
| **挑眉** | 眉毛高高挑起成弧形 | 活泼、惊讶、有个性 |
| **倒八字眉** | 眉头低眉尾高，呈倒八字 | 凶狠、精明、有气场 |
| **断眉** | 眉毛中间有缺口断开 | 有个性、叛逆、坏人 |

### 3.7 眼睛

| 类型 | 视觉描述 | 给人的感觉 |
|------|----------|------------|
| **大眼** | 眼睛占脸部比例大，又大又圆，眼珠明显，白色高光点醒目 | 可爱、天真、有精神、年轻 |
| **小眼** | 眼睛细长细小，只占脸部一小部分，眯着眼 | 精明、沉稳、狡猾、没睡醒 |
| **圆眼** | 眼睛接近正圆形，瞳孔又大又圆 | 可爱、惊讶、单纯、无辜 |
| **细长眼** | 眼睛横向展开很宽，但高度很窄，丹凤眼 | 锐利、聪明、有气质 |
| **下垂眼** | 外眼角低于内眼角，呈现八字形 | 忧郁、可怜、无辜、没精神 |
| **上挑眼** | 外眼角高于内眼角，呈吊梢眼 | 精明、凶悍、有气场、狐媚 |
| **死鱼眼** | 眼神无光，半睁半闭，瞳孔暗淡无神 | 颓废、没干劲、冷漠、看破红尘 |
| **三角眼** | 眼睛呈三角形，上眼睑平直，下眼睑斜向上 | 凶狠、狡猾、阴险 |
| **眯眯眼** | 眼睛眯成一条缝，看不清眼珠 | 爱笑的人、没睡醒、神秘 |
| **大小眼** | 两只眼睛一大一小不对称 | 独特、有辨识度 |

### 3.8 鼻子

| 类型 | 视觉描述 | 给人的感觉 |
|------|----------|------------|
| **高鼻梁** | 鼻梁挺直高耸，侧面看有挺拔的线条 | 好看、立体感、英气 |
| **塌鼻子** | 鼻梁低平，几乎没有高度，正面看两个鼻孔明显 | 普通、扁平、可爱（配圆脸） |
| **尖鼻子** | 鼻头尖尖的，像钩子一样突出 | 精明、刻薄 |
| **大鼻子** | 鼻子整体大，鼻头肉多，占脸部比例大 | 憨厚、粗犷 |
| **小鼻子** | 鼻子小巧精致，占脸部比例小 | 秀气、可爱、女性化 |
| **蒜头鼻** | 鼻头圆润像蒜头，又大又圆 | 憨厚、老实 |
| **鹰钩鼻** | 鼻梁高且中间有凸起，鼻尖向下勾 | 阴险、精明、锐利 |
| **朝天鼻** | 鼻孔朝前上方，从正面能看到鼻孔里面 | 可爱、搞笑 |

### 3.9 嘴巴

| 类型 | 视觉描述 | 给人的感觉 |
|------|----------|------------|
| **薄唇** | 上下嘴唇都很薄，嘴巴线条细 | 冷静、理性、刻薄、能说会道 |
| **厚唇** | 上下嘴唇饱满厚实 | 热情、感性、憨厚 |
| **大嘴** | 嘴巴横向宽大，笑起来占半张脸 | 开朗、豪爽、爱笑 |
| **小嘴** | 嘴巴小巧，像樱桃小口 | 秀气、文静、斯文 |
| **嘴角上扬** | 嘴角天生微微上翘，即使不笑也像在笑 | 亲切、友善、天生笑脸 |
| **嘴角下垂** | 嘴角天生微微向下，看起来不高兴 | 严肃、忧郁、不高兴的样子 |
| **龅牙** | 门牙突出嘴唇关不上，或牙齿露在外面 | 可爱、搞笑、憨厚 |
| **兔牙** | 两颗门牙特别大，像兔子一样 | 可爱、萌 |

### 3.10 耳朵

| 类型 | 视觉描述 |
|------|----------|
| **大耳朵** | 耳朵明显大，像大耳朵图图一样招风 |
| **小耳朵** | 耳朵小巧，贴在头两侧不明显 |
| **招风耳** | 耳朵向外突出，像扇子一样张开 |
| **贴面耳** | 耳朵紧紧贴在头两侧，从正面几乎看不到 |
| **垂耳** | 耳垂大而厚，有福气的象征 |

### 3.11 脸型

| 类型 | 视觉描述 | 给人的感觉 |
|------|----------|------------|
| **圆脸** | 脸部轮廓圆润饱满，从额头到下巴都是弧形，下巴圆润 | 可爱、年轻、亲和、娃娃脸 |
| **方脸** | 下颌方正宽大，额头和下巴宽度接近，轮廓硬朗 | 稳重、正直、可靠、严肃 |
| **长脸** | 脸部纵向明显长于横向，额头到下巴距离大 | 成熟、严肃、精明 |
| **瓜子脸** | 上宽下窄，额头宽下巴尖，轮廓流畅 | 秀气、标准美人、女性化 |
| **梨形脸** | 额头窄，下颌宽，像梨一样上窄下宽 | 稳重、敦实 |

| **心形脸** | 额头宽下巴尖，发际线呈心形，有美人尖 | 好看、甜美 |

### 3.12 额头

| 类型 | 视觉描述 |
|------|----------|
| **宽额头** | 额头横向和纵向都宽，显得聪明开阔 |

| **低额头** | 额头纵向短，发际线靠前，显得头发多 |

### 3.13 颧骨

| 类型 | 视觉描述 |
|------|----------|
| **高颧骨** | 颧骨突出明显，脸部中间最宽，显得有棱角 |
| **平颧骨** | 颧骨不突出，脸部线条流畅 |

### 3.14 下巴

| 类型 | 视觉描述 |
|------|----------|
| **尖下巴** | 下巴尖尖的，像锥子一样收拢 |

| **方下巴** | 下巴方正宽大，有棱角 |

## 四、面部细节设计

### 4.1 胡子（男性）

| 类型 | 视觉描述 | 给人的感觉 |
|------|----------|------------|
| **干净** | 没有胡子，下巴光滑 | 年轻、整洁、斯文 |

## 六、气质设计

### 6.1 表情

| 表情 | 视觉描述 |
|------|----------|
| **温和微笑** | 嘴角微微上扬15度，眉眼舒展柔和，给人友善亲切的感觉 |
| **严肃认真** | 嘴角平直，眉头微皱，眼神专注不飘忽，给人认真可靠的感觉 |
| **开朗大笑** | 嘴巴张开30度露齿，眼睛弯成月牙，眉飞色舞，给人活泼开朗的感觉 |
| **忧郁沉默** | 嘴角微下垂5度，眼神低垂看下方，眉头微蹙，给人内敛有故事的感觉 |
| **高傲冷漠** | 下巴微抬10度，眼神向下斜视，嘴角一侧微翘似笑非笑，给人不好接近的感觉 |
| **呆萌天然** | 嘴巴微张成O型，眼神放空或迷茫，眉头舒展，给人呆萌可爱的感觉 |
| **凶狠** | 眉头紧皱成川字，眼睛瞪大或眯起成缝，嘴巴紧抿或呲牙露齿，给人不好惹的感觉 |
| **害羞** | 脸颊泛红晕，眼神躲闪不敢直视，嘴角紧张地微抿或僵硬微笑，给人害羞内向的感觉 |
| **狡猾** | 眼睛眯起成缝，嘴角一侧上扬坏笑，眉毛上挑，给人奸诈不怀好意的感觉 |
| **委屈** | 嘴巴向下撇成八字，眼睛水汪汪像要哭，眉毛耷拉，给人受委屈的感觉 |
| **傲慢** | 鼻孔朝天看人，嘴角不屑撇向一边，眼睛半睁不睁，看不起人的样子 |
| **惊恐** | 眼睛瞪圆到最大，嘴巴大张成O型，眉毛高高扬起，被吓到的样子 |
| **困倦** | 眼睛半睁不睁，嘴巴打哈欠或微张，眼神涣散无光，没睡醒的样子 |
| **沉思** | 眼神望向远处不聚焦，眉头微皱，嘴巴轻抿，在想事情的样子 |
| **油腻** | 眉毛上挑，嘴角歪斜坏笑，眼神色眯眯，给人不舒服的感觉 |

### 6.2 眼神

| 类型 | 视觉描述 |
|------|----------|
| **明亮有神** | 眼睛里有光，瞳孔清亮，显得有活力有精神 |

| **呆滞** | 眼神固定不动，盯着一个地方发呆，像在想事情或傻了 |
| **高傲** | 眼神从上往下看人，眼珠在眼眶下方，显得瞧不起人 |
| **阴鸷** | 眼神阴沉，从眼皮下斜着看人，显得不怀好意 |

## 十二、技术接入规范（精灵图如何被代码使用）

### 12.1 精灵图在等角地图中的定位

#### 12.1.1 地图瓦片坐标 → 屏幕像素坐标

等角地图使用以下公式将瓦片坐标转为屏幕坐标（定义在 `IsometricMap.ts`）：

```
屏幕X = (瓦片X - 瓦片Y) × 32
屏幕Y = (瓦片X + 瓦片Y) × 16 - 高程 × 4
```

其中地图瓦片尺寸为 **64×32 像素**（菱形瓦片），角色精灵图尺寸为 **32×48 像素**。

#### 12.1.2 精灵图的绘制位置

角色站在瓦片上的位置关系：

```
                   ┌─────────────┐
                   │   角色头部    │   ← 精灵图顶部 (y偏移 -48)
                   │     (16px)   │
                   ├─────────────┤
                   │   角色身体    │   ← 精灵图中部 (y偏移 -32 ~ -16)
                   │     (16px)   │
                   ├─────────────┤
                   │   角色腿部    │   ← 精灵图下部 (y偏移 -16 ~ 0)
                   │     (16px)   │
                   ├──────┬──────┤
                   │  脚  │  脚  │   ← 精灵图底部 (y偏移 0)
                   │  ▓▓  │  ▓▓  │   ← 阴影在此位置
                   └──────┴──────┘
              ┌──────────────────────────┐
              │       瓦片 (64×32)        │   ← 菱形瓦片区域
              └──────────────────────────┘

绘制时：精灵图的底部中心点 = 瓦片的中心点
```

**绘制位置计算公式**：
```
角色屏幕X = 瓦片中心X = (瓦片X - 瓦片Y) × 32
角色屏幕Y = 瓦片中心Y = (瓦片X + 瓦片Y) × 16 - 高程 × 4 - 16
角色绘制Y = 角色屏幕Y - 48 + 16  (精灵图底部对齐瓦片中心)
```

#### 12.1.3 Z序（遮挡关系）

等角地图的绘制顺序必须遵循对角线 Z 序，确保正确的遮挡：

```
// 伪代码：按 sum = x + y 从小到大绘制
for (sum = 0; sum < mapWidth + mapHeight; sum++) {
    for (x = 0; x <= sum; x++) {
        y = sum - x;
        if (在有效范围内) {
            // 1. 绘制地图瓦片
            // 2. 绘制建筑
            // 3. 绘制角色
        }
    }
}
```

**角色在Z序中的位置**：
- 角色应与它所在的瓦片在同一Z层
- 角色绘制在瓦片之后、建筑之前
- 高程越高的角色越晚绘制（靠后显示）

```

  - 背面右脚 → directionIndex=2, frameOffset=1 → 帧索引3
  - 左侧左脚 → directionIndex=4, frameOffset=0 → 帧索引4
  - 左侧右脚 → directionIndex=4, frameOffset=1 → 帧索引5
  - 右侧左脚 → directionIndex=6, frameOffset=0 → 帧索引6
  - 右侧右脚 → directionIndex=6, frameOffset=1 → 帧索引7

裁剪区域：
  x = 帧索引 × 32
  y = 0
  width = 32
  height = 48
```

#### 12.4.2 NPC类的精灵图支持（代码修改方向）

```typescript
// NPC 类中新增的字段和方法（示意）
class Npc {
  // 新增字段
  spriteSheet: HTMLImageElement | null = null;
  spriteConfig = {
    frameWidth: 32,
    frameHeight: 48,
    totalFrames: 8,
  };

  // 新的 draw 方法（用精灵图替换程序化绘制）
  draw(ctx: CanvasRenderingContext2D, scale: number): void {
    if (!this.spriteSheet) return;

    const frameIndex = this.getCurrentFrameIndex();
    const sx = frameIndex * this.spriteConfig.frameWidth;
    const sy = 0;
    const sw = this.spriteConfig.frameWidth;
    const sh = this.spriteConfig.frameHeight;

    // 等角位置计算
    const isoX = (this.x - this.y) * 32;
    const isoY = (this.x + this.y) * 16 - this.elevation * 4 - 16;

    // 绘制阴影
    ctx.fillStyle = "rgba(0,0,0,0.2)";
    ctx.beginPath();
    ctx.ellipse(isoX + 16, isoY + 48, 12, 4, 0, 0, Math.PI * 2);
    ctx.fill();

    // 绘制精灵
    ctx.drawImage(
      this.spriteSheet,
      sx, sy, sw, sh,          // 裁剪源
      isoX, isoY - 48, sw, sh  // 绘制目标
    );
  }

  // 获取当前帧索引
  private getCurrentFrameIndex(): number {
    const dirIndex = { down: 0, up: 2, left: 4, right: 6 }[this.facing];
    return dirIndex + this.walkFrame % 2;
  }
}
```

  public/sprites/*.png    ← 生成的精灵图文件
  public/sprites/index.json  ← 精灵图索引

第二步：代码加载精灵图

       ↓

### 12.6 生成精灵图时的注意事项

| 注意事项 | 说明 |
|----------|------|
| **底部对齐** | 精灵图的底部（脚的位置）必须对齐到瓦片中心点，所以精灵图的"脚"应该在最底部第46-48行 |
| **阴影内置** | 精灵图中**不包含**阴影，阴影由代码在运行时绘制（半透明椭圆） |
| **背景透明** | AI生成时必须确保背景完全透明，否则会遮挡地图 |
| **方向一致性** | 8帧的朝向必须统一，正面的角色要看"镜头"，不能侧面看 |
| **尺寸严格** | 每帧必须是精确的 32×48 像素，不能多不能少 |
| **命名正确** | 文件名必须按规范命名，否则代码无法匹配 |
