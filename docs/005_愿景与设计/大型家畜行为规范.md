# 大型家畜行为规范（牛、羊）

> ⚠️ 规范研究文档。牛和羊是最高价值家畜。圈养后行为极简，价值在于产出。
> 复用人类 GOAP 引擎。驯化前有简单的野生循环，驯化后由人管理。

---

## 一、牛

### 参数

| 素质 | 值 | 说明 |
|:-----|:--:|:-----|
| 移动速度 | 3 | 沉重缓慢 |
| 耐力 | 8 | 能拉犁一整天 |
| 力量 | 9 | 极强——狼不敢单独攻击牛 |
| 视觉 | 15格 | 正常 |
| 听觉 | 20格 | 正常 |
| 嗅觉 | 20格 | 正常 |
| 震动感知 | 8格 | |

### 欲望（野生/自由状态，5条）

```
want_flee_or_defend (优先级 10):
  条件: 感知到威胁
  策略: 母牛带犊→逃跑。公牛/无犊母牛→站住面对威胁、低头亮角
  狼: 3~4只才敢攻击一头牛。少于3只→狼自己退

want_eat (优先级 9):
  条件: 饥饿度 > 5
  目标: 吃草→反刍
  效果: 饥饿度 -6（大型动物吃得极多）

want_drink (优先级 8):
  条件: 口渴度 > 6
  目标: 去水源

want_sleep (优先级 5):
  条件: 疲劳度 > 7
  目标: 卧地反刍+睡觉

默认: want_graze_slow (优先级 2):
  目标: 边走边吃草（一天大部分时间在吃）
```

### 圈养后

- 圈在围栏里 → 不出围栏 → 吃人给的干草
- 人每天挤奶 → 产出牛奶物品
- 人牵牛耕地 → 牛执行 `plow` 动画（田地被耕好）
- 屠宰产大量肉 → 是最高价值的肉食来源

## 二、羊

### 参数

| 素质 | 值 | 说明 |
|:-----|:--:|:-----|
| 移动速度 | 4 | 比牛快 |
| 耐力 | 5 | 中等 |
| 力量 | 3 | 无攻击力 |

### 羊特有的从众行为

```
羊的从众性极强——是所有家畜中最"盲从"的:
  → 领头羊往哪走，全群跟着走（不需要任何通讯）
  → 一只羊受惊跑了，全群都跑（跟鹿的从众式逃跑一样）
  → 所以放羊需要牧羊人/牧羊犬来引导方向
```

### 欲望（5条，与鹿极似）

```
want_flee (优先级 10):
  条件: 感知到威胁 → 整群一起跑
  跟鹿完全一样的从众逃匿机制

want_eat (优先级 9):
  条件: 饥饿度 > 5
  目标: 吃草→反刍
  效果: 饥饿度 -4

want_drink (优先级 8)
want_sleep (优先级 5)

默认: want_follow_herd (优先级 2):
  条件: 附近有同群羊在移动
  目标: 跟着走（这就是羊的"盲从"）
```

### 圈养后

- 人每季剪一次羊毛 → 产出羊毛物品
- 人也可以挤羊奶（但不如牛奶产量大）
- 可以用牧羊犬放羊——狗跑，羊跟着狗跑

## 三、牛和羊的驯化路径

```
野生牛/羊 → 被人类发现 → 围捕/套绳 → 圈起来喂食 → 长期互动 → 驯化成功
  初期（几天）: 动物想逃跑、撞围栏
  中期（1~2周）: 习惯人类在附近 → 开始接受喂食
  后期（1月+）: 完全驯化 → 可以挤奶/剪毛/耕地

驯化判定:
  每天互动加分 = 人类给的食物质量 + 人类的处事方式(温柔/粗暴受性格影响)
  减分 = 人类打它、饿了不给吃、围栏太小
  总分达到阈值 → 驯化成功 → 标签从[野生]变[圈养]
```
