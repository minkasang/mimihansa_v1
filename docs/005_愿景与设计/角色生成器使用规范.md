# 角色精灵图生成器使用规范

## 一、生成器概述

本生成器是一个**商业化级程序化角色精灵图生成工具**，基于Canvas 2D API实现，能够根据用户指定的外观属性生成32×48像素、8帧（4方向×2帧）的角色精灵图。

### 1.1 核心特性
- **程序化生成**：无需外部素材，纯代码绘制
- **属性驱动**：通过11个外观属性控制角色样貌
- **多方向支持**：正面、背面、左面、右面四个方向
- **行走动画**：每个方向2帧走路循环
- **高细节层次**：发型高光、面部阴影、服装褶皱等

## 二、技术规格

### 2.1 精灵图规格
| 项目 | 规格 |
|------|------|
| 单帧尺寸 | 32×48 像素 |
| 总帧数 | 8帧（4方向 × 2帧） |
| 精灵表尺寸 | 256×48 像素 |
| 背景 | 透明（PNG） |
| 色彩深度 | 24位RGB + 8位Alpha |
| 渲染模式 | 像素级精确（关闭抗锯齿） |

### 2.2 帧布局
```
[正面帧0][正面帧1][背面帧0][背面帧1][左面帧0][左面帧1][右面帧0][右面帧1]
   0-31     32-63    64-95   96-127  128-159  160-191  192-223  224-255
```

### 2.3 坐标系
- 角色锚点：脚底中心（16, 46）
- 头部区域：y=4 ~ y=20
- 身体区域：y=20 ~ y=34
- 腿部区域：y=34 ~ y=46

| 发色 | 黑色/深棕/浅棕/金色/红色/灰色 | 头发、眉毛颜色 |
| 发型 | 短发/中长/长发/束发/光头/卷发 | 头发绘制逻辑 |
| 眼睛 | 大眼/中等/小眼/圆眼/细长/下垂/上挑 | 眼睛大小和形状 |
| 脸型 | 圆脸/方脸/长脸/瓜子脸 | 面部轮廓 |
| 表情 | 温和微笑/严肃认真/开朗大笑/忧郁沉默/高傲冷漠/呆萌天然 | 眉毛、嘴巴形状 |

### 3.2 属性组合规则

- **实际可见差异**：约10,000+种肉眼可区分的外观

## 五、绘制层次（从下到上）

### 5.1 绘制顺序
1. **阴影** - 脚底椭圆阴影
2. **腿部** - 裤子/裙子 + 鞋子
3. **身体** - 躯干服装
4. **手臂** - 袖子 + 手部
5. **头部基础** - 面部轮廓
6. **头发** - 后脑勺 → 侧发 → 前发
7. **五官** - 眼睛 → 眉毛 → 鼻子 → 嘴巴
8. **耳朵** - 两侧耳朵
9. **面部细节** - 腮红、皱纹、胡须、雀斑

### 5.2 各部位细节规范

#### 头发绘制
- **短发**：顶部蓬松椭圆 + 侧面碎发 + 刘海像素点
- **中长**：顶部层次 + 两侧垂发10px + 发尾阴影 + 发丝高光
- **长发**：顶部层次 + 两侧垂发16px + 内侧阴影 + 多组发丝高光
- **束发**：顶部头发 + 刘海 + 后脑发髻（多层圆形）+ 发髻装饰
- **卷发**：蓬松顶部 + 多个小椭圆卷发团 + 高光卷发团
- **光头**：不绘制头发

#### 眼睛绘制（6层）
1. 眼白椭圆（#ffffff）
2. 眼白阴影（#f5f5f5）
3. 上眼睑线（rgba(0,0,0,0.3)）
4. 虹膜（#2d5016）+ 虹膜高光
5. 瞳孔（#1a1a1a）+ 瞳孔内圈
6. 主高光（#ffffff）+ 次高光（rgba(255,255,255,0.7)）

#### 服装绘制
- 主体色（primary）填充
- 右侧阴影（secondary）增加立体感
- 左侧高光条纹（accent + highlight）
- 下摆褶皱（3-4个像素点）
- 领口/袖口细节
- 腰带/纽扣（讲究/华丽风格）

## 六、使用方法

### 6.1 网页界面操作
1. 打开 `character-generator.html`
2. 在左侧控制面板选择属性（或保持"随机"）
3. 点击"生成"按钮生成角色
4. 点击"全随机"快速生成随机角色
5. 点击"下载"保存PNG精灵表
6. 在底部批量生成区域可一次生成8个角色

### 6.2 代码调用
```javascript
// 创建生成器实例
const generator = new CharacterSpriteGenerator();

// 定义外观属性
const appearance = {
  性别: "男",
  年龄: "青年",
  身高: "中等",
  体型: "标准",
  肤色: "暖色",
  发色: "黑色",
  发型: "短发",
  眼睛: "大眼",
  脸型: "圆脸",
  表情: "开朗大笑",
  穿衣风格: "普通"
};

// 生成精灵表
const spriteSheet = generator.generateSpriteSheet(appearance);
// spriteSheet 是一个 HTMLCanvasElement
// 尺寸：256×48 像素，透明背景
```

### 6.3 提取单帧
```javascript
// 提取正面第0帧
function getFrame(spriteSheet, direction, frame) {
  const dirIndex = ["down", "up", "left", "right"].indexOf(direction);
  const x = (dirIndex * 2 + frame) * 32;
  const canvas = document.createElement("canvas");
  canvas.width = 32;
  canvas.height = 48;
  const ctx = canvas.getContext("2d");
  ctx.drawImage(spriteSheet, x, 0, 32, 48, 0, 0, 32, 48);
  return canvas;
}
```

## 七、等角地图集成

### 7.1 坐标转换
```javascript
// 瓦片坐标 → 屏幕坐标
function tileToScreen(tileX, tileY) {
  const screenX = (tileX - tileY) * 32;
  const screenY = (tileX + tileY) * 16;
  return { x: screenX, y: screenY };
}

// 角色绘制位置（脚底中心对齐瓦片中心）
function drawCharacter(ctx, spriteSheet, tileX, tileY, direction, frame) {
  const pos = tileToScreen(tileX, tileY);
  const dirIndex = ["down", "up", "left", "right"].indexOf(direction);
  const frameX = (dirIndex * 2 + frame) * 32;

  // 角色锚点偏移（脚底中心）
  const drawX = pos.x - 16;
  const drawY = pos.y - 44;

  ctx.drawImage(spriteSheet, frameX, 0, 32, 48, drawX, drawY, 32, 48);
}
```

### 7.2 Z-Order排序
角色必须按屏幕Y坐标排序后绘制，以确保正确的遮挡关系：
```javascript
characters.sort((a, b) => a.screenY - b.screenY);
```

## 八、性能优化

### 8.1 生成性能
- 单角色生成时间：< 5ms（现代浏览器）
- 建议预生成常用角色，避免运行时生成

### 8.2 渲染性能
- 精灵表一次性生成，运行时仅drawImage
- 使用离屏canvas缓存精灵表
- 避免每帧重新生成精灵图

### 8.3 内存优化
- 相同外观的角色共享精灵表
- 使用对象池管理精灵表
- 及时释放不再使用的canvas

## 九、扩展指南

### 9.1 添加新发型
1. 在 `drawHairFront`/`drawHairBack`/`drawHairSide` 中添加新case
2. 使用基础色 + 阴影色 + 高光色三层绘制
3. 确保四个方向都有对应绘制逻辑

### 9.2 添加新服装
1. 在 `CLOTHING_PALETTES` 中添加新配色方案
2. 在 `drawBody` 中添加新服装类型的特殊绘制逻辑
3. 确保配色包含 primary/secondary/accent/shadow/highlight

### 9.3 添加新表情
1. 在 `drawEyebrowShape` 中添加眉毛形状
2. 在 `drawMouth` 中添加嘴巴形状
3. 确保与现有眼睛类型兼容
