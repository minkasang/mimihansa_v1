# 参考项目与竞品分析

> 整理现有的开源 NPC 自主生活模拟项目，供设计参考和技术选型。
> 所有项目均为**纯算法驱动**，无 LLM 依赖。

---

## 一、生态/生命模拟类

### 1. Simbiosis - 人工生命模拟

| 项目 | 信息 |
|:-----|:-----|
| **简介** | 基于自主智能体和过程行为的生态系统模拟 |
| **语言** | C++ |
| **仓库** | https://github.com/Ignat99/simbiosis |
| **特点** | 强调智能体的自主决策和生态互动 |

---

### 2. Project Genesis (Open Genesis) - 生态系统模拟

| 项目 | 信息 |
|:-----|:-----|
| **简介** | 模拟完整的生态系统，生物/NPC 可以觅食、生存和繁殖 |
| **特点** | 包含社交互动和进化机制 |
| **仓库** | https://github.com/OpenGenesis/OpenGenesis |

---

### 3. EcoSim - 生态模拟

| 项目 | 信息 |
|:-----|:-----|
| **简介** | 生物可以相互交流、居住和适应 |
| **语言** | C++ |
| **特点** | 自发的行为稳定，纯算法驱动 |
| **仓库** | https://github.com/permutation/Ecosim |

---

### 4. Lenia - 连续细胞自动机

| 项目 | 信息 |
|:-----|:-----|
| **简介** | 基于自组织、人工生命的数学模型 |
| **特点** | 完全纯算法，像"数字生命" |
| **仓库** | https://github.com/chakazul/Lenia |
| **独特性** | ⭐ 非常独特的生命形式模拟 |

---

## 二、智能体/社会模拟类

### 5. Evoplex - 智能体模型平台 ⭐推荐

| 项目 | 信息 |
|:-----|:-----|
| **简介** | 基于图的社会系统和智能体建模 |
| **特点** | 支持可视化、自定义规则和行为逻辑 |
| **可视化** | 界面友好，适合快速原型 |

| **推荐理由** | 纯算法驱动，文档较好，上手快 |

## 三、经典平台/工具

### 8. NetLogo

| 项目 | 信息 |
|:-----|:-----|
| **简介** | 专门为智能体模拟设计的语言和平台 |
| **特点** | 完全纯算法，大量社会/生态模拟示例 |

|:-----|:-----|

## 五、与沙畔项目的对比

| 维度 | 现有开源项目 | 沙畔 (Shapan) |
|:-----|:-----------|:--------------|
| **驱动方式** | 纯算法 | 纯算法 |
| **NPC 复杂度** | 简单-中等 | 高（34维性格） |
| **社会关系** | 基础 | 完整（恋爱/婚姻/家族/好感度） |
| **生命周期** | 简单 | 完整（婴儿→老年） |
| **职业系统** | 无/简单 | 完整链条 |
| **经济系统** | 无/简单 | 市场/交易/雇佣 |
| **建造系统** | 无 | 从草棚到瓦房 |
| **数据驱动** | 部分 | 完全（JSON配置） |
| **渲染** | 2D/无 | 等距2.5D/WebGL |
| **目标用户** | 研究者/爱好者 | 游戏玩家 |

## 六、可借鉴的技术点

### 6.1 从 Evoplex 借鉴
- 图结构的社会关系建模
- 可视化调试界面设计
- 规则配置系统

### 6.2 从 Mesa 借鉴
- 智能体建模的模块化设计
- 社会经济模型的实现模式
- 批量模拟和数据分析

### 6.3 从 openc2e 借鉴
- 神经网络驱动的行为决策
- 遗传算法进化机制
- 生物的"学习"和"适应"

### 6.4 从 NetLogo 借鉴
- 快速原型验证方法
- 参数调优的可视化
- 教学示例的设计

## 七、推荐学习路径

| 目标 | 推荐项目 | 原因 |
|:-----|:---------|:-----|
| **最快上手** | Evoplex / Mesa | 文档好，Python/C++ 熟悉 |
| **最底层控制** | EcoSim / Lenia | C++ 实现，算法透明 |
| **社会模拟参考** | Mesa / NetLogo | 大量社会模型示例 |
| **进化机制参考** | openc2e / OpenGenesis | 神经网络 + 遗传算法 |
| **可视化参考** | Evoplex / NetLogo | 界面友好，调试方便 |
