## 二、狼的参数（行为数据）

狼作为"弱化版 NPC"，复用人类引擎的参数结构，但与狼无关的维度全部填默认值（1 或 0），运行时不会被读取——因为狼的欲望库不会引用那些维度。

```
狼在人类引擎中的有效参数:

  生理状态（完整使用）:
    饥饿度, 口渴度, 疲劳度, 健康度, 性欲值(发情用)

  素质（完整使用）:
    力量（决定攻击力）
    身手敏捷（决定先手和逃跑速度）
    移动速度
    耐力（体力上限，追逐用）
    体力（当前体力）

  性格（绝大部分=1，仅少数有意义）:
    胆魄气量_勇气阈值 ← 决定"面对比自己大的猎物敢不敢攻击"
    胆魄气量_风险规避 ← 决定"受伤后还敢不敢继续战斗"
    人际关系_忠诚度 ← 决定"对首领和小狼的照顾意愿"
    其他31维: 全部 = 1（狼的欲望库不引用它们，不参与计算）

  技能（无）: 全部 = 0

  知识库（极简——只有3~5条）:
    类型:"地点", 名称:"水源", 位置:[x,y]
    类型:"地点", 名称:"巢穴", 位置:[x,y]
    类型:"事实", 内容:"我是首领" ← 或"我是Beta"、"我是Omega"
    类型:"事实", 内容:"最近这里有鹿出没", 位置:[大致区域]

  狼群专属数据:
    狼群ID: 属于哪个群
    狼群角色: "首领" | "Beta" | "Omega" | "幼崽"
    进食顺序: 1~N（数字越小越先吃）
    狩猎经验: 0~100（每参与一次狩猎+1~3，越高狩猎成功率越高）
```

## 三、狼的社会结构

```
一个狼群: 3~8只狼

等级:
  首领 (Alpha, 通常1公1母):
    - 只有首领有繁殖权
    - 进食时最先吃，吃最好的部位
    - 决定狼群去哪里、什么时候狩猎
    - 走在队伍最前面

  次级 (Beta, 1~3只):
    - 首领的助手
    - 进食顺序第二
    - 帮忙看护幼崽
    - 如果首领死亡/衰老 → 最强Beta接替

  底层 (Omega, 1~2只):
    - 最后进食（吃剩的）
    - 经常被其他成员轻咬耳朵驱赶
    - 承担群体压力——但不会被咬死（这是狼群的"社会缓冲"）
    - 如果狼群分裂 → Omega是最可能被驱逐的

  幼崽 (0~1岁):
    - 跟着母狼，不进等级
    - 1岁后自动进入最低等级（排在Omega之后或替代Omega）

狼群总数限制:
  - 猎物充足 → 最多8~10只
  - 猎物短缺 → 弱势成员饿死或被驱逐
  - 超过8只 + 有两只以上的成年狼野心大 → 可能分裂成两个狼群
```

## 四、狼的日常作息

```
06:00~08:00（清晨）——狩猎窗口:
  首领 wake → want_hunt 触发 → 嚎叫集合
  狼群集结 → 扇形搜索 → 围猎 → 击杀 → 按等级进食

08:00~16:00（白天）——休息:
  在巢穴/树荫下睡觉
  幼崽在巢穴附近活动
  偶尔起身去水源喝水
  首领可能起身巡逻领地边缘

16:00~20:00（黄昏）——第二次狩猎窗口:
  如果上次狩猎失败 → 再次尝试
  如果已吃饱 → 可能不狩猎，只巡逻

20:00~06:00（夜晚）——休息:
  大部分时间睡觉
  狼群轮流保持浅睡（警觉状态）
  有危险 → 最先察觉的狼嚎叫示警

醒来时的优先顺序:
  饿了 → 出发狩猎
  不饿 → 巡逻领地
  领地安全 → 跟随首领游荡
```

## 五、狼的单体欲望（用 GOAP 引擎跑）

```
狼的欲望库 (Wolf_Desires_Library.json):

want_eat_from_kill (优先级 10, 最高):
  条件: 感知范围内有新鲜动物尸体 + 轮到自己吃了
       （进食顺序: 自己前面的人都吃过了）
  目标: action_eat
  效果: 饥饿度-6, 开心值+2

want_hunt (优先级 9):
  条件: (首领发出狩猎信号 OR 饥饿度>5) + 附近有猎物感知
  目标: action_hunt_pack
  效果: 可能获得食物(狩猎成功)

want_drink (优先级 8):
  条件: 口渴度 > 6
  目标: action_go_to_water
  效果: 口渴度-5

want_sleep (优先级 6):
  条件: 疲劳度 > 7 + 距离巢穴 < 50格 OR 在安全区域
  目标: action_sleep
  效果: 疲劳度-4

want_howl (优先级 5):
  条件: (与狼群距离 > 30格 走散了) OR (发现大型猎物需要帮手)
  目标: action_howl
  效果: 产生听觉事件(半径50格), 同群狼成员收到后向嚎叫位置移动

want_follow_leader (优先级 4):
  条件: 首领在移动 且 自己没有更高优先级目标 且 不是首领自己
  目标: action_follow
  效果: 向首领位置移动，保持3~5格距离

want_patrol (优先级 3):
  条件: 不饿(饥饿度<5) + 不困(疲劳度<6) + 距上次巡逻>半天
  目标: action_patrol
  效果: 沿领地边缘走一圈，沿途留下气味标记

默认: want_wander (优先级 1):
  条件: 无
  目标: 随机游荡（半径10格内）
```

## 六、集体狩猎的完整流程

```
阶段1: 发起
  首领在清晨/黄昏 → want_hunt 触发
  → 首领执行 action_howl（狩猎集合嚎叫）
  → 听觉事件: { 类型:"狼嚎", 来源:首领ID, 内容:"狩猎集合", 半径:50格 }

阶段2: 集合
  狼群成员 Step 2 感知到嚎叫 → want_follow_leader 触发
  → 所有成年狼向首领移动 → 形成松散队伍

阶段3: 搜索
  狼群在领地内扇形散开（间隔5~10格）
  每只狼用视觉(22格)+嗅觉(40格)扫描猎物
  → 狼A 嗅到鹿的气味 → 嚎叫:
      { 类型:"狼嚎", 来源:狼A, 内容:"发现猎物", 目标位置:[120,85] }
  → 全群收到 → 向目标位置移动

阶段4: 围猎
  多只狼从不同方向包围猎物
  策略分配:
    速度最快的狼 → 侧翼截断逃跑路线
    体力最好的狼 → 正面驱赶
    首领 → 致命攻击位置
  猎物（鹿）→ 感知到被包围 → 试图从空隙逃跑
  → 如果空隙有狼 → 被拦住 → 体力和压力持续上升

阶段5: 击杀
  猎物体力耗尽 → 无法有效逃跑
  → 首领/最近狼 执行攻击 → 力量判定 → 命中
  → 小猎物(兔): 一击必杀
  → 中猎物(鹿): 2~3击
  → 危险猎物(野猪): 需要多人围攻，可能有狼受伤

阶段6: 进食（按等级顺序）
  猎物死亡 → 尸体生成（死亡系统 §3.1.6）
  
  进食顺序:
    第1轮: 首领吃 → 饥饿度恢复满
    第2轮: Beta 吃 → 饥饿度恢复
    第3轮: Omega 吃 → 吃剩的
    如果还有剩 → 带回巢穴给幼崽

  如果有人抢在首领之前吃:
    首领执行"惩罚" → 那只狼受到轻伤(HP-1) + 往后排队
    → 那只狼的知识库: "不能抢在首领之前吃"（亲身经历）

阶段7: 返回巢穴
  吃饱 → 返回巢穴 → 休息/睡觉
  狩猎失败 → 如果还饿 → 黄昏再试
```

## 七、进食顺序的机器实现

```
进食顺序不是系统强制的——是每只狼自己"知道"自己的位置:

狼群在尸体旁时:
  每 Tick:
    每只狼的 want_eat_from_kill 条件检查:
      
      我是首领? → 直接吃（条件满足）
      
      我是Beta? → 检查:
        首领的饥饿度 < 3?（首领吃饱了？）
        → Step 2 感知: 看到首领在睡觉/离开尸体 → 首领吃完了
        → 条件满足 → 吃
        首领还在吃? → 条件不满足 → 等
      
      我是Omega? → 检查:
        首领走了 且 Beta也走了?
        → 条件满足 → 吃
        还有狼在吃? → 等
      
    这种"等待"不是系统强制——是每只狼自己的欲望条件判断。
    狼不需要"知道"其他狼的等级——每只狼只知道"我应该等谁吃完"。
```

## 八、领地与气味标记

```
领地区域:
  = 以巢穴为中心，半径50~80格的区域
  由狼群的 patrol 行为自然定义

气味标记:
  狼巡逻时 → 在领地边缘留标记
  → World.grid[x][y].气味标记.push({ 狼群ID, 时间 })
  → 气味每过一天衰减，30天后消失

入侵检测:
  狼 A 巡逻时闻到其他狼群的气味 → 知识库:
    "领地边缘有其他狼群的气味"
  
  如果发现入侵狼 B（视觉感知到其他狼群的狼在领地内）:
    嚎叫示警 → 其他狼过来 → 集体驱赶入侵者
    数量优势 → 攻击 → 入侵者逃跑或战斗
    数量劣势 → 保持距离跟踪 → 不轻易开战
```

## 九、繁殖与幼崽养育

```
繁殖:
  只在首领对之间
  发情季: 每年冬季一次
  
  母狼 发情 → 首领公狼 交配
  → 孕期: 63天（游戏时间）
  → 孕期行为: 母狼减少狩猎参与，多休息
  
  分娩:
    在巢穴进行 → 调用 NPCFactory.createChild()
    每窝: 2~6只幼崽
    幼崽标签: [幼狼][狼群XX成员]

幼崽 0~2个月:
  在巢穴里不出门
  靠母乳 + 成年狼带回的肉（由母狼或Omega喂食）
  走 Step 2 感知 + Step 3.5 本能反射（哭=微弱嚎叫）

幼崽 2~6个月:
  出巢穴探索
  跟着成年狼在附近活动
  学习: Step 2 感知 → 看到成年狼狩猎 → 知识库缓慢积累
  → 知识库: "猎物长这样"、"狩猎时要从侧面包抄"

幼崽 6~12个月:
  开始跟队狩猎（跟在队伍后面看，不参与）
  学会嚎叫: 听到成年狼嚎叫 → 模仿 → 知识库积累

1岁:
  进入等级系统 → 排在Omega之后（或成为新的Omega）
  开始参与简单狩猎
```

## 十、狼群的分裂与合并

```
分裂条件:
  狼群 >= 8只 + 有至少2只 Beta 狼 + 猎物持续不足
  → 最强Beta挑战首领
  → 如果Beta赢: 首领让位（或死亡）
  → 如果首领赢: Beta被驱逐 → 可能带走1~2只追随者 → 自立新群

合并条件:
  两个狼群在领地边缘相遇
  一方的首领死亡，群内只剩2~3只 → 可能被另一方吸收
  或在猎物极度丰富时，两个群可能共享领地（罕见）

狼群 ID 的维护:
  每只狼: 狼群ID 字段
  一只狼离开 → 狼群ID 改为新群ID 或 null
  首领死亡 → 自动从成员中找到最高 Beta → 提升为首领
```

## 十一、一只狼的生命周期

```
年龄 0      → 出生（在巢穴里）
年龄 0~2月  → 母乳+喂食期，不出巢穴
年龄 2~6月  → 幼崽期，出巢穴探索，学习
年龄 6~12月 → 少年期，跟队看狩猎，学嚎叫
年龄 1岁    → 进入等级系统（Omega），参与狩猎
年龄 2~5岁  → 巅峰期，可能是Beta或挑战首领
年龄 6~8岁  → 衰老：体力/速度微降（-10%~-20%）
年龄 8~10岁 → 自然死亡或被年轻狼取代
```

## 十二、与人类引擎的衔接

狼使用同一个 GOAP 循环：

| Step | 狼的处理 |
|:-----|:---------|
| Step 1 (时间) | 共用 |
| Step 2 (感知) | 用狼的感知参数（视觉22/听觉45/嗅觉40） |
| Step 2.5 (动物推进) | 生理状态更新 + 狼群专属逻辑（等级、进食顺序检查） |
| Step 3 (生理) | 共用 |
| Step 3.5 (本能) | 仅用于幼崽（0~2月），成年狼跳过 |
| Step 4 (欲望) | 加载 Wolf_Desires_Library.json（7条），走 GOAP 打分 |
| Step 5 (行动) | 加载 Wolf_Actions_Library.json，走 GOAP 规划 |
| Step 6 (关系) | 狼没有社交——跳过 |
| Step 7~9 | 共用 |

**狼的性格维度绝大部分=1（默认值）**，不会拖累计算——因为狼的欲望库不引用它们，条件评估器不会去读这些维度。
