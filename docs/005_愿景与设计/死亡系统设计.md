## 一、寿命：NPC能活多久

### 1.1 基础寿命

每个NPC出生时，根据体质量生成一个**基础寿命上限**：

```
基础寿命 = 50 + random(-10, 30)   // 范围40~80岁

体质影响：
  健康值（0-10）映射到寿命：
    健康10 → +15岁
    健康5  → +0岁
    健康1  → -15岁

最终寿命上限 = clamp(基础寿命 + 健康映射, 20, 100)
  // 最短活到20岁，最长100岁
```

### 1.2 减寿因素（实际寿命 < 上限寿命）

| 减寿因素 | 减寿量 | 触发方式 |
|:---------|:------:|:---------|
| **长期营养不良** | -1岁/年饥饿状态 | 连续多日饥饿度>7 |
| **长期生病未愈** | -2岁/次大病 | 连续多日生病状态 |
| **受重伤** | -3岁/次 | 战斗/事故重伤 |
| **瘟疫中感染** | -5岁 | 感染致命瘟疫 |
| **极度悲伤/压力** | -0.5岁/年 | 连续多日开心值<2 |
| **过量劳动** | -0.5岁/年 | 疲劳度持续>8 |

### 1.3 增寿因素（实际寿命 > 上限寿命）

| 增寿因素 | 增寿量 | 条件 |
|:---------|:------:|:-----|
| **优渥生活** | +1岁/年 | 长期食物充足+有房产+无压力 |
| **医术治疗** | +2~5岁 | 被高级医生治疗过 |
| **修仙** | +X岁 | 未来扩展 |

## 二、死因

### 2.1 老死（自然死亡）

```
触发条件：年龄 >= 实际寿命上限
判定：到达年龄上限后，每月判定一次
  死亡概率 = min((年龄 - 实际寿命上限) / 5, 1.0) × 100%
  → 超龄后平均多活2~3个月就走了

死亡过程：
  年龄到了 → 身体逐渐虚弱（体力/精力恢复速度-50%）
  → 最终在睡梦中去世（不痛苦）或某天倒地不起
```

### 2.2 饿死

```
触发条件：饥饿度 = 10 且 持续 N 天无人喂食
  成年人 N = 7天
  儿童   N = 5天
  婴儿   N = 3天（没人喂死得更快）

死亡标记：[饿死]
```

### 2.3 病死

```
疾病致死判定：
  生病状态下，健康值持续下降
  健康值降到 0 → 死亡
  
疾病类型（先做三种）：
  轻病（感冒）：健康每天-0.1，自愈概率20%/天，致死率低
  重病（瘟疫）：健康每天-0.5，自愈概率5%/天，可能致死
  瘟疫感染：健康每天-1.0，需要药物/医生介入才能活

致命判定：
  健康值 <= 0 → 死亡
  死亡标记：[病死]
```

### 2.4 被杀（预留，战斗系统完善后启用）

```
触发条件：战斗中被生物击杀
判定：当前生命值(HP) <= 0
死亡标记：[被杀]
```

### 2.5 意外死亡（预留，灾害系统完善后启用）

```
触发条件：自然灾害/事故
  地震/建筑倒塌 → 小概率
  野兽袭击 → 战败
  溺水 → 极小概率
```

##三、死亡后的处理

### 3.1 尸体生成（v2.0 重写）

> ⚠️ 尸体必须保持生前外观特征——不能变成通用模型。

```
Step 7 检测到 NPC 死亡 → 事件总线回调执行（Step 7.5）：

  1. NPC 本体标记 [已死亡]
     → UI动画状态改为"倒地不动"
     → 保留生前外观（体型/身高/发色/服装/性别）
       这些数据从NPC数据中读取，不是从通用尸体贴图

  2. 生成尸体实体:
     corpse = {
       id: "corpse_" + npc.id,
       原NPC_ID: npc.id,
       位置: npc.当前位置,           // 死在原地
       外观快照: {                   // ← 保持生前特征
         体型: npc.外貌.体型,
         身高: npc.外貌.身高,
         发色: npc.外貌.发色,
         服装: npc.外貌.服装状态,
         性别: npc.性别
       },
       腐烂阶段: "新鲜",             // 新鲜→肿胀→腐烂→白骨
       腐烂计时: 0,                   // 每天+1，N天后到白骨阶段
       被掩埋: false
     }
     → 写入 World.尸体[]

  3. 地面标记: World.grid[尸体位置].尸体ID = corpse.id
```

### 3.1.5 腐烂系统（v2.1 新增）

> 尸体不是静态的——它会随着时间腐化。人类和动物尸体共用同一个腐烂系统。

```
腐烂阶段:

  新鲜 (Day 0~2):
    外观: 和生前一样（人脸完整/动物毛皮完整）
    可采集: 全部掉落物（肉、皮毛、角、骨）
    气味: 无 → NPC 只能通过视觉感知

  肿胀 (Day 2~5):
    外观: 腹部膨胀、皮肤变色
    可采集: 皮毛、角、骨（肉已腐败不可食用）
    气味: 微弱 → 嗅觉半径 5格内 NPC 可以闻到
    效果: 看到/闻到尸体的 NPC 开心值-2

  腐烂 (Day 5~10):
    外观: 严重腐化、蝇虫围绕
    可采集: 骨（肉和皮毛已完全腐败）
    气味: 强烈 → 嗅觉半径 15格内 NPC 可以闻到
    效果: 看到/闻到尸体的 NPC 开心值-5，可能触发 want_bury

  白骨 (Day 10+):
    外观: 只剩枯骨
    可采集: 骨骼（最后的产出）
    气味: 无
    效果: 不再引起恐慌/悲伤

  消失 (Day 30+ 或 被掩埋后):
    Step 9 清理任务检测 → 删除尸体实体 → 清除地面标记

腐烂计时:
  每过一天（游戏内一天），腐烂计时 +1
  被掩埋 → 腐烂速度 -50%（埋在土里，腐化较慢）
  暴露在阳光下 → 腐烂速度 +30%（细菌繁殖快）
  如果是冬天 → 腐烂速度 -80%（低温防腐）
```

### 3.1.6 动物尸体生成（v2.1 新增）

> 动物死亡后走与人类相同的尸体生成流程。唯一区别是"掉落物"字段预先从物种库中读取。

```
事件总线收到"动物死亡"事件 → 回调执行:

  corpse = {
    id: "corpse_" + animal.id,
    类型: "动物尸体",
    原ID: animal.id,
    原名称: animal.物种,          // "野兔"、"野鹿"
    外观快照: {
      物种: animal.物种,
      体型: animal.体重,           // "小型"/"中型"/"大型"
      毛色: animal.毛色
    },
    腐烂阶段: "新鲜",
    死亡时间: World.时间.当前Tick,
    腐烂计时: 0,
    掉落物: 查询物种库获取,        // 见 动物系统 §屠宰产出
    已采集: false,
    采集人: [],
    位置: animal.当前位置,
    被掩埋: false
  }
  → 写入 World.尸体[]  ← 与人类尸体同一个数组

采集尸体 (action_butcher):
  NPC 移动到尸体旁 → 工具=石刀效率更好，徒手也可
  → 尸体.已采集 = true → 尸体.采集人.push(npc.id)
  → npc.物品栏 新增对应数量的产出物
  → npc.知识库: "我从尸体上采集到了 X"
  
  腐烂阶段限制:
    新鲜: 可采全部（肉+皮毛+角+骨）
    肿胀: 不可采肉（NPC 知识库里知道"肉应该坏了"）
    腐烂: 仅骨
    白骨: 仅骨
```

### 3.2 遗产继承（v2.0 重写）

> ⚠️ 遗产转移由事件总线回调执行——这是"天地规则"，不是 NPC 行动。

```
事件总线收到"NPC死亡"事件 → 回调执行遗产结算:

  物品栏:
    1. 配偶在世 → 全部转会配偶.物品栏
    2. 配偶已死 → 平均分配给在世成年子女（>=15岁）
    3. 无在世直系 → 在尸体位置生成地上物品（item.所有者ID=null）

  金钱:
    1. 配偶在世 → 全部转会配偶.金钱
    2. 配偶已死 → 平均分配给在世成年子女
    3. 无在世直系 → 充公（如果有村落金库）/散落

  房屋:
    房屋.所有者ID → 改为配偶.id
    如果配偶也不在了 → 改为最年长在世子女.id
    如果没有任何在世直系 → 房屋."继承待定"（等待NPC认知处理）
  
  注：房子只有继承人有"家坐标=此位置"的认知。其他NPC不知道房子是谁的
  除非通过感知或口口相传了解。
```

### 3.3 丧礼与下葬（v2.0 新增）

#### 3.3.1 主持人优先级

```
谁主持下葬？（按优先级往下找，找到第一个在世的人）

  优先级1: 配偶（生存配偶.社会关系.配偶ID == 死者ID）
  优先级2: 直系长辈 → 父亲 → 母亲 → 祖父 → 祖母（按此顺序）
  优先级3: 直系成年子女 → 按年龄从大到小，>=15岁
  优先级4: 兄弟姐妹 → 按年龄从大到小
  优先级5: 知识库中标记"此人是我亲属"的附近NPC
  优先级6: 附近同理心最高的NPC（道德水准_同理心 > 7）

注：关系判定由引擎按 社会关系.父母ID/子女ID/配偶ID 查找。
但葬礼流程里主持人的行为由他自己的认知驱动——他必须先在Step 2感知到尸体。
```

#### 3.3.2 下葬流程

```
Tick N: 主持人 Step 2 感知到尸体
  → 引擎内存匹配: 尸体.system_id → 主持人的辨识符映射
  → 知识库现有条目更新: "xxx一动不动躺在地上"（亲眼看到）

Step 4 欲望计算（主持人）:
  感知结果: "熟人死了" + 知识库: "这是我家人"
  → 触发欲望: want_bury_dead（想安葬逝者，优先级=8）

下葬行动序列（跨多个Tick）:

  ① 提议埋葬:
      主持人向附近有相同认知的亲属发出提议
      → Step 6 社交对话（不是系统群发）
  
  ② 准备棺椁（可选）:
      主持人 道德水准_规则遵守 > 5 → 想做棺椁
      → 砍树: 需要工具（石斧）或徒手（极慢）
      → 获取木材 × N → 制作简易棺椁
  
  ③ 选择墓地:
      主持人找安静、离家不太远、非道路的地方
      → 移动过去 → 设置目标位置
  
  ④ 挖坑:
      执行"挖土"动作（消耗体力），持续多个Tick
      需要: 工具（石刀/石铲）或徒手（慢）
      体力消耗大 → 可能需要休息 → 全流程跨多个Tick
  
  ⑤ 搬运尸体:
      主持人 + 帮手把尸体搬到墓地（多人协作）
  
  ⑥ 填土 + 立碑:
      完成掩埋 → World.grid 上标记 坟墓
      墓碑: 主持人 道德水准_规则遵守 > 5 → 找石头刻字
      道德低 → 不立碑，仅标记位置
  
  ⑦ 完成:
      主持人.知识库: "xxx已被安葬"（亲身经历）
      尸体实体: 被掩埋 = true → Step 9 清理时不再处理
```

### 3.4 社会传播（v2.0 重写）

```
死亡消息传播——只通过感知和口口相传，系统不广播：

  1. 在场的人 Step 2 感知到尸体 → 知识库写入亲眼所见
  2. 在场的人聊天时告诉别人 → 信息传播（Step 6）
  3. 扩散速度取决于社交网络密度
  4. 有人可能很久都不知道（如果不在社交网络中）
  
  死者社会关系的处理:
    - 社会关系保留（历史记录——死者依然在子女的"父母ID"中）
    - 其他NPC知识库里关于此人的条目不会自动变更
    - 只有感知到了死亡事实的NPC，才会更新自己的认知
    - 没有"配偶自动变丧偶"——只有配偶亲眼看到/听到才算
```

### 3.5 墓地

```
简易处理：
  有人掩埋 → World.grid 标记坟墓 + 可选墓碑
  无人掩埋 → 尸体按腐烂阶段最终变为白骨 → Step 9 清理时删除
```

## 四、相关标签（v2.0 审计）

> ⚠️ v2.0 重大修正：系统不能给 NPC 贴认知类标签。以下仅保留系统数据标签。

| 标签 | 类型 | 说明 |
|:-----|:-----|:-----|
| `[已死亡]` | 系统数据 | NPC的最终状态标记，引擎内部用 |
| `[老死]` `[饿死]` `[病死]` `[被杀]` | 系统数据 | 死因标记，引擎内部用 |
| `[尸体]` | 世界实体 | 尸体实体的标签，不是NPC标签 |

**已删除的违规标签（v2.0）：**
| 旧标签 | 删除原因 | 替代方案 |
|:-----|:---------|:---------|
| ~~[丧偶]~~ | ❌ 认知标签——系统不能贴 | NPC通过 Step 2 感知配偶死亡 → 自己的知识库更新认知 |
| ~~[孤儿]~~ | ❌ 认知标签——系统不能贴 | 孩子不知道父母死就不是孤儿。只有他通过感知知道了才是 |
| ~~[饿死风险]~~ | ❌ 不属于NPC标签数组 | 改为事件总线的内部事件标记，发给死亡检测模块 |
