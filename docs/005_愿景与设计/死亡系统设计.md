## 一、寿命：NPC能活多久

### 1.1 基础寿命

每个NPC出生时，根据体质量生成一个**基础寿命上限**：

```
基础寿命 = 50 + random(-10, 30)   // 范围40~80岁

体质影响：
  健康值（0-10）映射到寿命：
    健康10 → +15岁
    健康5  → +0岁
    健康1  → -15岁

最终寿命上限 = clamp(基础寿命 + 健康映射, 20, 100)
  // 最短活到20岁，最长100岁
```

### 1.2 减寿因素（实际寿命 < 上限寿命）

| 减寿因素 | 减寿量 | 触发方式 |
|:---------|:------:|:---------|
| **长期营养不良** | -1岁/年饥饿状态 | 连续多日饥饿度>7 |
| **长期生病未愈** | -2岁/次大病 | 连续多日生病状态 |
| **受重伤** | -3岁/次 | 战斗/事故重伤 |
| **瘟疫中感染** | -5岁 | 感染致命瘟疫 |
| **极度悲伤/压力** | -0.5岁/年 | 连续多日开心值<2 |
| **过量劳动** | -0.5岁/年 | 疲劳度持续>8 |

### 1.3 增寿因素（实际寿命 > 上限寿命）

| 增寿因素 | 增寿量 | 条件 |
|:---------|:------:|:-----|
| **优渥生活** | +1岁/年 | 长期食物充足+有房产+无压力 |
| **医术治疗** | +2~5岁 | 被高级医生治疗过 |
| **修仙** | +X岁 | 未来扩展 |

## 二、死因

### 2.1 老死（自然死亡）

```
触发条件：年龄 >= 实际寿命上限
判定：到达年龄上限后，每月判定一次
  死亡概率 = min((年龄 - 实际寿命上限) / 5, 1.0) × 100%
  → 超龄后平均多活2~3个月就走了

死亡过程：
  年龄到了 → 身体逐渐虚弱（体力/精力恢复速度-50%）
  → 最终在睡梦中去世（不痛苦）或某天倒地不起
```

### 2.2 饿死

```
触发条件：饥饿度 = 10 且 持续 N 天无人喂食
  成年人 N = 7天
  儿童   N = 5天
  婴儿   N = 3天（没人喂死得更快）

死亡标记：[饿死]
```

### 2.3 病死

```
疾病致死判定：
  生病状态下，健康值持续下降
  健康值降到 0 → 死亡
  
疾病类型（先做三种）：
  轻病（感冒）：健康每天-0.1，自愈概率20%/天，致死率低
  重病（瘟疫）：健康每天-0.5，自愈概率5%/天，可能致死
  瘟疫感染：健康每天-1.0，需要药物/医生介入才能活

致命判定：
  健康值 <= 0 → 死亡
  死亡标记：[病死]
```

### 2.4 被杀（预留，战斗系统完善后启用）

```
触发条件：战斗中被生物击杀
判定：当前生命值(HP) <= 0
死亡标记：[被杀]
```

### 2.5 意外死亡（预留，灾害系统完善后启用）

```
触发条件：自然灾害/事故
  地震/建筑倒塌 → 小概率
  野兽袭击 → 战败
  溺水 → 极小概率
```

##三、死亡后的处理

### 3.1 尸体

```
NPC死亡后：

1. 在原位置生成"尸体"（临时对象）
2. 尸体在N天后腐烂消失
3. 如果附近有人：
   - 家人 → 心情暴跌-30，触发"悲痛"状态
   - 朋友 → 心情-10
   - 路人 → 可能掩埋（取决于道德）
```

### 3.2 遗产

```
死者财产的流向（按优先级）：
  1. 有配偶 → 配偶继承全部
  2. 无配偶，有子女 → 子女平分
  3. 无配偶无子女 → 归还家族（父母/兄弟姐妹）
  4. 完全无亲属 → 充公（如果有政府）/ 散落（无政府，路人可能会捡）
```

### 3.3 房屋与土地

```
死者的房子/土地：
  1. 有继承人 → 自动归继承人（和遗产规则一样）
  2. 无继承人 → 房子变成"无主建筑"，可以被任何人占用/拆毁
```

### 3.4 社会传播

```
死亡消息传播（通过口口相传，不是系统广播）：
  1. 在场的人最先知道
  2. 告诉其他人 → 慢慢扩散
  3. 过一段时间，全村都知道"某某死了"
  4. 死者的朋友列表 → 自动从朋友.json中移除
  5. 配偶变[丧偶]标签
```

### 3.5 墓地（可选）

```
简易处理：
  有人掩埋 → 在死亡位置生成一个小墓碑
  无人掩埋 → 尸体腐烂消失后，什么都不留
```

## 四、相关标签

| 标签 | 说明 |
|:-----|:-----|
| `[已死亡]` | NPC的最终状态标记 |
| `[老死]` `[饿死]` `[病死]` `[被杀]` | 死因标记 |
| `[丧偶]` | 配偶死亡后的状态 |
| `[孤儿]` | 父母双亡（已存在） |
| `[尸体]` | 死亡后的临时对象标签 |
| `[饿死风险]` | 饥饿度>8，濒临饿死 |
