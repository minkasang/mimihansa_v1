# 沙畔 (Shapan) - 智能 NPC 生活模拟引擎

> 一个基于 GOAP（目标导向动作规划）和效用 AI 的 NPC 自主行为模拟系统。
> NPC 拥有完整的生理需求、性格特征、社会关系，在开放世界中自主决策、生活、交互。

---

## 项目简介

沙畔是一个**纯观察式**的 NPC 生活模拟引擎。玩家作为观察者，观看由 AI 驱动的 NPC 在虚拟世界中自主生活：

- 🏠 **建造家园** - 从简易草棚到石基瓦房
- 🌾 **农耕劳作** - 开垦、种植、收获、应对季节变化
- 💕 **恋爱婚姻** - 好感度积累、表白、结婚、生育
- 💼 **职业发展** - 学徒→工匠→店主，完整的职业链条
- ⚔️ **战斗冲突** - 切磋或生死斗，永久死亡机制
- 🗣️ **信息传播** - NPC 之间口口相传，形成社交网络
- 📚 **教育成长** - 从婴儿到老年，完整生命周期

---

## 核心特性

### 1. 通用 NPC 行为引擎

引擎不区分业务领域——所有系统（吃饭/恋爱/工作/建房/战斗）都通过统一的决策循环运转：

```
[感知世界] → [评估欲望] → [效用打分] → [GOAP规划] → [执行指令] → [效果结算]
```

### 2. 34 维性格系统

每个 NPC 拥有 34 个性格维度（勤劳/懒惰、勇敢/胆怯、色欲/冷淡等），性格影响：
- 动作选择的优先级
- 对话内容的生成
- 与其他 NPC 的关系发展

### 3. 数据驱动架构

新增玩法只需修改 3 个 JSON 文件，**无需改动引擎代码**：
- `Desires_Library.json` - 定义"想做什么"
- `Actions_Library.json` - 定义"怎么做"
- `Brains_Library.json` - 定义"性格如何影响选择"

### 4. 完整生命周期

| 阶段 | 年龄 | 关键事件 |
|:-----|:-----|:---------|
| 婴儿 | 0-2岁 | 需要照料、无自主行动 |
| 幼儿 | 2-6岁 | 开始学习走路、说话 |
| 学龄 | 6-12岁 | 入学、受教育 |
| 青少年 | 13-17岁 | 情窦初开、学徒工作 |
| 成年 | 18+岁 | 独立生活、恋爱、工作 |
| 老年 | 60+岁 | 退休、可能失能 |

    └── map-demo/           # 前端游戏演示
        ├── src/
        │   ├── engine/     # 核心引擎（GOAP/感知/时间/事件）
        │   ├── systems/    # 游戏系统（对话/任务/天气）

## 核心引擎模块

| 模块 | 文件 | 说明 |
|:-----|:-----|:-----|
| 条件评估器 | `engine/ConditionEvaluator.ts` | 支持 15+ 种操作符的条件判断 |
| 欲望评估器 | `engine/DesireEvaluator.ts` | 遍历欲望库，筛选可触发欲望 |
| 效用打分器 | `engine/ScoreCalculator.ts` | 34 维性格加权打分 |
| GOAP 规划器 | `engine/GOAPPlanner.ts` | 目标拆解为指令序列 |
| 时间系统 | `engine/TimeSystem.ts` | Tick/昼夜/季节/年份转换 |
| 事件总线 | `engine/EventBus.ts` | 跨系统事件触发机制 |
| NPC 管理器 | `engine/NPCManager.ts` | NPC 实例生命周期管理 |
| 感知系统 | `engine/Perception.ts` | 视觉/听觉/嗅觉范围检测 |

## 标签体系

全项目使用统一的标签系统来标记 NPC 状态：

| 区号 | 类别 | 示例 |
|:-----|:-----|:-----|
| A | 年龄阶段 | `[婴儿]` `[学龄]` `[成年]` |
| S | 社会身份 | `[学生]` `[孤儿]` `[流浪者]` |
| ST | 当前状态 | `[口渴]` `[战斗中]` `[休息中]` |
| H | 身体/健康 | `[生病]` `[受伤]` `[健康]` |
| EM | 情绪极端 | `[狂怒]` `[极度悲伤]` `[狂喜]` |
| AM | 暧昧状态 | `[独处]` `[夜晚]` `[室内]` |
| P | 生育相关 | `[经期中]` `[排卵窗口]` `[怀孕中]` |

> 完整标签定义见：[标签体系统一规范](docs/005_愿景与设计/标签体系统一规范.md)
